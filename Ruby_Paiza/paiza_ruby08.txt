### メソッド
  Array#max / Array#min    配列の最大値 / 最小値を返す
  Integer#odd?             奇数なら true を返す

### 構文・記法
  s[i][j]                  文字列の配列から行・列を指定して1文字を取り出す
  data[行][列]             2次元配列（配列の配列）への行・列アクセス
  n.times.map { gets.split(" ").map(&:to_i) }   n行の入力を2次元配列に変換する
  data.map { |row| row[2] }.max   各行の特定列だけを取り出して最大値を求める
  h.times do |i| / w.times do |j|  2重ループで2次元グリッド全体を走査する

### 知識・パターン
  2次元配列の作り方        n.times.map { gets.split(" ").map(&:to_i) } で行×列の配列を作る
  グリッド走査パターン     h.times / w.times の入れ子で全マスを i, j で参照する
  s[i][j] で文字判定       文字列の配列を「行」として扱い、[j] で列（文字）を取り出す
  特定列の集計             data.map { |row| row[n] } で列を抽出してから max/min/sum
  先頭・末尾行へのアクセス data[0][0]（先頭）/ data[n-1][1]（末尾）

h, w = gets.split(" ").map(&:to_i)      # 縦、横の数値を半角スペース区切りで入力する 

s = h.times.map { gets.chomp }      # 縦の数の分、文字列（"oxo"など）を配列として入力していく（["o", "x", "o"]）

points = h.times.map { gets.split(" ").map(&:to_i) }        # 縦の数の分、半角スペース区切りの数列を配列にし、一つ一つできた配列を大きな一括りの配列に組み込んでいく。

total_score = 0

h.times do |i|
    w.times do |j|
        
        if s[i][j] == "o"
            total_score += points[i][j]
        end
    end
end

puts total_score

## このコードの仕組み

h行 w列のグリッドがあり、"o" のマスの点数だけ合計する問題。

### データ構造

  h = 2, w = 3 のとき

  s（正解フラグのグリッド）:
    s[0] = "oxo"   # 1行目
    s[1] = "oox"   # 2行目

  points（点数のグリッド）:
    points[0] = [3, 1, 4]   # 1行目の各点数
    points[1] = [1, 5, 9]   # 2行目の各点数

### s[i][j] の意味

s は文字列の配列。s[i] で i 行目の文字列を取り出し、さらに [j] で j 番目の文字を取り出す。

  s[0]    #=> "oxo"
  s[0][0] #=> "o"
  s[0][1] #=> "x"
  s[0][2] #=> "o"

### 入れ子ループの動き

h.times（行）と w.times（列）の2重ループで全マスを走査する。

  i=0, j=0 → s[0][0]="o" → points[0][0]=3 を加算
  i=0, j=1 → s[0][1]="x" → スキップ
  i=0, j=2 → s[0][2]="o" → points[0][2]=4 を加算
  i=1, j=0 → s[1][0]="o" → points[1][0]=1 を加算
  i=1, j=1 → s[1][1]="o" → points[1][1]=5 を加算
  i=1, j=2 → s[1][2]="x" → スキップ

  total_score = 3 + 4 + 1 + 5 = 13

### points の作り方

  points = h.times.map { gets.split(" ").map(&:to_i) }

h 行分の入力を受け取り、各行をスペース区切りで整数の配列にする。
結果は「配列の配列（2次元配列）」になる。

  points[行][列] でその位置の点数を取り出せる。

## data = n.times.map { gets.split(" ").map(&:to_i) } の仕組み

n行分の入力を受け取って、「配列の配列（2次元配列）」を作る。

### 流れ

  n = 3 のとき、以下の3行を入力するとする
  入力:
    100 200 250 80
    200 300 350 150
    300 250 400 100

  n.times.map { gets.split(" ").map(&:to_i) }
  # 1回目: "100 200 250 80"  → split → ["100","200","250","80"]  → map(&:to_i) → [100, 200, 250, 80]
  # 2回目: "200 300 350 150" → split → ["200","300","350","150"] → map(&:to_i) → [200, 300, 350, 150]
  # 3回目: "300 250 400 100" → split → ["300","250","400","100"] → map(&:to_i) → [300, 250, 400, 100]

  data => [[100,200,250,80], [200,300,350,150], [300,250,400,100]]

### data[行][列] でアクセスする

  data[0]    #=> [100, 200, 250, 80]   1行目全体
  data[0][0] #=> 100                   1行目の1列目
  data[n-1][1] #=> 250                 最終行の2列目

### data.map { |row| row[2] }.max の意味

  data.map { |row| row[2] }  # 各行の3列目だけを取り出して配列にする
  #=> [250, 350, 400]

  .max  #=> 400   その中の最大値を取得
