■ 入力の受け取り方
  gets.to_i                   → 1行を整数として受け取る
  gets.chomp                  → 1行を文字列として受け取る（末尾の改行を除去）
  gets.split                  → 1行をスペース区切りで配列にする
  gets.split.map(&:to_i)     → スペース区切りの数値を整数の配列にする
  a, b = gets.split           → 1行をスペース区切りで複数変数に同時代入

■ 配列操作
  配列 << 値                  → 配列の末尾に要素を追加
  配列.include?(値)           → 配列に値が含まれるか（true/false）
  配列.sum                    → 配列の合計値を返す
  配列.length / 配列.size     → 配列の要素数を返す

■ 文字列操作
  文字列.chars                → 文字列を1文字ずつの配列に分割
  文字列.chars.sort           → 文字を並び替え（アナグラム判定に使う）
  文字列[-1]                  → 最後の文字を取得（-1で末尾から数える）
  文字列[0]                   → 最初の文字を取得
  文字列.gsub("a", "b")      → 文字列中の"a"を全て"b"に置換
  文字列.gsub(正規表現, "b")  → 正規表現にマッチした部分を"b"に置換
  文字列.split(':')           → ':'で区切って配列にする

■ 数値操作
  数値.ceil                   → 小数点以下を切り上げ（例: 3.1 → 4）
  数値.to_f                   → 整数を小数として扱う（割り算の精度を上げる）

■ 正規表現
  /-+/                        → ハイフンが1個以上連続するパターン
  / ... /                     → 正規表現はスラッシュで囲む
  +                           → 直前の文字が1回以上繰り返す

■ 制御構文
  unless 条件                 → 条件が偽のときだけ実行（if !条件 と同じ）
  exit                        → プログラムをその場で終了する
  next                        → ループの残り処理をスキップして次のループへ

■ よく使うパターン・こつ
  アナグラム判定              → s.chars.sort == t.chars.sort
  時間を分に変換             → 時 * 60 + 分（計算後に / 60 と % 60 で戻す）
  平均を切り上げ             → (合計.to_f / 個数).ceil
  連続文字の圧縮             → gsub(/-+/, '-') のように正規表現を使う
  しりとり判定               → 前の単語[-1] != 次の単語[0]
  株売買ロジック             → 条件で買い/売りを判断して money/stocks を更新

ceil（セイル）は、「小数点以下をすべて切り上げる（上の整数にする）」ためのメソッド（機能）だよ！

英語の天井（ceiling）からきている言葉で、「数字を上に引っ張り上げる」イメージをすると分かりやすいよ。

どういうふうに動く？
割り算をしたときに、小数点が出てきたら強制的に次の整数に繰り上げる動きをするよ。

(7.0 / 2) の計算結果は 3.5

これに .ceil を使うと → 4 になる！

(2.0 / 2) の計算結果は 1.0 （もともと小数点が無い状態ならそのまま）

これに .ceil を使うと → 1 のまま！

基本の書き方
Ruby
文字列.gsub("探す文字", "置き換える文字")
例えば、文章の中の「りんご」を「みかん」に全部変えたいときはこう書くよ：

Ruby
text = "私はりんごが好きです。りんごは美味しい。"
result = text.gsub("りんご", "みかん")

puts result
# 出力結果： 私はみかんが好きです。みかんは美味しい。
（「りんご」がすべて「みかん」に変わるよ！）

応用：今回の問題で使った「正規表現」のパターン
さっきのファイル名の問題（C143:ファイル名の統一）では、ただの文字じゃなくて「ルール」を指定して置き換えていたんだ。

Ruby
ans = s.gsub(/-+/, '-')
/-+/ 部分（ルール）

/ ... / で囲まれた部分は正規表現（ルールブック）と呼ばれるもの。

- は「ハイフン」、+ は「それが1回以上連続している」という意味。

つまり 「ハイフンががっつり繋がっているカタマリ」 を見つけてね、という指定になるよ。

'-' 部分（置き換え先）

見つけた「連続したハイフンのカタマリ」を、すべて 「ハイフン1個 ('-')」 にしなさい、という意味。

これのおかげで、--- や -- のような長さがバラバラな連続ハイフンも、一発で綺麗に - 1個に圧縮できたんだよ！

n = gets.split.map(&:to_i)

days = n[0]
input_1 = n[1]
input_2 = n[2]


money = 0
stocks = 0

days.times do |i|
    invests = gets.to_i
    
    if i == days - 1
        money += stocks * invests
        stocks = 0
        next
    end
    
    
    if input_1 >= invests
        stocks += 1
        money -= invests
    elsif input_2 <= invests
        money += stocks * invests
        stocks = 0
    end
end

puts money
