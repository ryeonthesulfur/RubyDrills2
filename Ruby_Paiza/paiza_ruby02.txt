■ 入力の受け取り方
  gets.split.map(&:to_i)         → 1行スペース区切りの数値を整数配列にする（横並びデータ向け）
  n.times.map { gets.to_i }      → n行分を1行ずつ読んで整数配列にする（縦並びデータ向け）
  n.times.map { gets.chomp }     → n行分を1行ずつ読んで文字列配列にする
  t, d, x = gets.split           → 1行をスペース区切りで複数変数に同時代入

■ 配列操作
  配列.uniq.size                  → 重複を除いた要素数を返す
  配列.max / 配列.min             → 最大値 / 最小値を返す
  配列.sort                       → 昇順に並べ替える
  配列.join(' ')                  → 配列を空白区切りの文字列に変換

■ ハッシュ操作
  配列.tally                      → 各要素の出現回数をハッシュで返す（例: {"a"=>2, "b"=>1}）
  ハッシュ.values.max             → ハッシュの値の中から最大値を取得
  ハッシュ.select { |k, v| 条件 } → 条件に合う要素だけ絞り込む
  ハッシュ.keys                   → キーだけを配列で取得
  ハッシュ.max_by { |k, v| v }[0] → 値が最大のキーを取得

■ 文字列操作
  文字列.count('文字')            → 文字列の中に指定文字が何個あるか数える
  文字列.split('+')               → 指定文字で区切って配列にする
  数値.to_s.reverse.to_i          → 数値の桁を逆順にする（例: 123 → 321）

■ 制御構文
  loop do ... break end           → 条件を満たすまで無限ループ（while trueと同じ）
  (n - 2).times do |i|           → 配列を3つ同時に参照するときの安全なループ範囲

■ よく使うパターン・こつ
  連続パターン判定               → k[i]==1 && k[i+1]==1 && k[i+2]==2（範囲は (n-2).times）
  出現回数の最多を取得           → 配列.tally.max_by { |k, v| v }[0]
  最多が複数ある場合に昇順出力   → .select { |k,v| v==max }.keys.sort
  数字の回文チェック             → n.to_s.reverse.to_i == n
  時間またぎの計算               → m[0] + m[1] + (24 - m[2]) で日付をまたぐ時間を算出

----------------------------------------------------------------------------

    gets.split.map(&:to_i) の動き
これは「1行の中にスペース区切りで並んでいるデータ」をまとめて配列にするための書き方です。
（例：1 4 6 2 1 が1行にすべて書かれている場合）今回のようにデータが縦にバラバラの行で送られてくる場合、
1回目の gets で最初の 5 しか読み取れないため、残りのデータを取りこぼしてしまいます。

    n.times.map { gets.to_i } の動き
これなら「次の行」「その次の行」と、縦に並んだ $N$ 行分のデータを1行ずつ順に取得して配列にできるため、
今回の入力形式にぴったり合います。

names = n.times.map {gets.chomp}

puts names.tally.max_by { |name, count| count }[0]

----------------------------------------------------------------------------
names = n.times.map { gets.chomp }先ほどと同じように、
縦に並んだ $N$ 行分の名前をすべて配列 names に取得します（末尾の改行を取り除くため chomp を使っています）。
names.tally配列の中身を自動で集計し、「どの名前が何票あるか」というデータ（ハッシュ）を作ってくれます。
例：{"sato" => 1, "suzuki" => 3, "takahashi" => 1}.max_by { |name, count| count }集計した中から、
票数（count）が最も大きい（maximum）要素を取り出します。
[0]見つかったペア（["suzuki", 3] など）の最初の要素、つまり名前の文字列だけを取り出して puts で出力します。

q = gets.to_i

left_weight = 0
right_weight = 0

q.times do
    
    t, d, x = gets.split
    t = t.to_i  #「t」は選択肢
    x = x.to_i  #「x」はおもり
    
    if t == 1
        if d == 'L'
            left_weight += x
        else
            right_weight += x
        end
    elsif t == 2
        if d == 'L'
            left_weight -= x
        else
            right_weight -= x
        end
    elsif t == 3
        if d == 'L'
            left_weight -= x
            right_weight += x
        else
            left_weigth += x
            right_weight -= x
        end
    end

    if left_weight > right_weight
        puts '>'
    elsif left_weight < right_weight
        puts '<'
    else
        puts '='
    end
end

n = gets.to_i

# 1. 各IDの出現回数を集計する
counts = m.tally

max_count = counts.values.max   
#.values を挟むことで、「出現回数（値）の部分だけ」を取り出して、
# その中から最大値を見つけることができます。

ans = counts.select { |id, cnt| cnt == max_count }.keys.sort

--------------------------------------------------

counts.select { |id, cnt| cnt == max_count }

日本語訳: 「counts（それぞれのIDと登場回数がセットになったデータ）の中から、登場回数（cnt）が一番多い数（max_count）とぴったり一致するものだけを選び出す」
解説: これにより、最多登場のIDが複数ある場合でも、そのグループだけを綺麗に絞り込むことができます。

.keys

日本語訳: 「残ったデータの中から、IDの番号（キー）だけを取り出す」
解説: ここまでだと「IDと回数」のセットになっているため、出力したいIDの数字だけを取り出すために .keys を使っています。

.sort

日本語訳: 「取り出したIDを、小さい順（昇順）に並べ替える」
解説: 問題の条件に「一番多く出現するプレイヤー ID が複数ある場合は 昇順 に全て出力して下さい」とあるため、ここで綺麗に並び順を整えています。
