### メソッド
  String#chars          文字列を1文字ずつの配列に分解する
  Array#join            配列を連結して1つの文字列にする
  Range#to_a            範囲オブジェクトを配列に変換する（例: (1..5).to_a → [1,2,3,4,5]）
  Array#push            末尾に要素を追加する
  Integer#odd?          奇数なら true を返す

### 構文・記法
  leet_map[c] || c      ハッシュにキーがあれば変換値、なければ元の値をそのまま使う
  a[l-1], a[r-1] = ...  多重代入で2つの要素を同時に入れ替える（一時変数不要）
  result += "1"         文字列に1文字ずつ追加して結果を組み立てる
  map do...end          ブロックが複数行のときは { } の代わりに do...end を使う

### 知識・パターン
  ハッシュによる文字変換    leet_map = {"A"=>"4", ...} を用意して chars.map で一括変換
  カードシャッフル処理      前半・後半に分けて交互に push して並べ直す
  配列インデックスで入れ替え a[l-1], a[r-1] = a[r-1], a[l-1]（1始まり入力を -1 で変換）
  ソート済み判定            a == a.sort で昇順になっているか確認
  縦方向の集計              lines.each で各行の同じ位置の文字を数える（列ごとの集計）
  排他的論理和              各桁の 1 の個数が奇数なら 1、偶数なら 0 を出力する

s = gets.chomp

leet_map = {
    "A" => "4",
    "E" => "3",
    "G" => "6",
    "I" => "1",
    "O" => "0",
    "S" => "5",
    "Z" => "2"
}

result = s.chars.map { |c| leet_map[c] || c }.join

puts result

## result = s.chars.map { |c| leet_map[c] || c }.join の解説

### 流れ

  s = "HELLO"
  s.chars  #=> ["H", "E", "L", "L", "O"]

  .map { |c| leet_map[c] || c }
  # c = "H" → leet_map["H"] は nil → nil || "H" → "H"
  # c = "E" → leet_map["E"] は "3" → "3" || "E" → "3"
  # c = "L" → leet_map["L"] は nil → nil || "L" → "L"
  # c = "L" → 同上 → "L"
  # c = "O" → leet_map["O"] は "0" → "0" || "O" → "0"
  #=> ["H", "3", "L", "L", "0"]

  .join  #=> "H3LL0"

### leet_map[c] || c の意味

ハッシュにキーが存在すれば変換後の値を使い、なければ元の文字をそのまま使う。

  leet_map["E"]  #=> "3"   → 変換あり → "3" を使う
  leet_map["H"]  #=> nil   → 変換なし → c（元の "H"）を使う

|| は「左が nil または false なら右を使う」という意味。
ハッシュに存在しないキーを指定すると nil が返るので、この書き方で「なければ元の文字」を表現できる。

m, n = gets.split(" ").map(&:to_i)

cards = (1..m).to_a

n.times do
    
    first_half = cards[0...m/2]
    second_half = cards[m/2...m]
    
    new_cards = []
    
    (m/2).times do |i|
        new_cards.push(second_half[i])
        new_cards.push(first_half[i])
    end
    
    cards = new_cards
end

puts cards.join(" ")

## .to_a の解説

範囲オブジェクト（Range）を配列に変換するメソッド。

  (1..5).to_a   #=> [1, 2, 3, 4, 5]
  (1...5).to_a  #=> [1, 2, 3, 4]   （5を含まない）

### このコードでの使われ方

  cards = (1..m).to_a

m = 6 なら `(1..6).to_a` → `[1, 2, 3, 4, 5, 6]` という配列になる。
カードの番号を1からm番まで順番に並べた配列を作るのに使っている。

### to_a を使わないと

  (1..6)  # これは範囲オブジェクトで、配列ではない
  # each でループはできるが、[i] でインデックス指定ができない

to_a で配列にすることで、`cards[0]` や `cards[m/2]` のようなインデックス操作ができるようになる。

ここでは排他的論理和(xor) と呼ばれる計算を使って入力データのミスを検出しようとしました。
排他的論理和(xor) は各桁において、1 が奇数個あれば 1、そうでないならば 0 を出力します。

入力する N 個のデータに対して、排他的論理和(xor) を取って出力をしてください。
入力例 1 の場合は、各桁に対して以下のように計算されます。


n = gets.to_i
lines = n.times.map { gets.chomp }

result = ""

4.times do |i|
    count = 0
    
    lines.each do |line|
        if line[i] == "1"
            count += 1
        end
    end
    
    if count.odd?
        result += "1"
    else
        result += "0"
    end
end

puts result
