## result = t.chars.map do |char| ... end.join の仕組み

### ステップ①: t.chars
文字列を1文字ずつに分解して配列にする。

  t = "bca"
  t.chars   #=> ["b", "c", "a"]

### ステップ②: .map do |char| ... end
各文字に対して処理をして、結果の配列を作る。
ブロック内の最後の値が新しい配列の要素になる。

  ["b", "c", "a"].map do |char|
    idx = char.downcase.ord - 'a'.ord  # "b" → 1, "c" → 2, "a" → 0
    s[idx]                              # s の idx 番目の文字を取り出す
  end
  #=> [s[1], s[2], s[0]]  のような配列

### ステップ③: .end.join
mapで作った配列を文字列に連結する。

  ["X", "Y", "Z"].join   #=> "XYZ"

### 全体の流れ（例）
  s = "xyz"
  t = "bca"

  "b" → idx = 1 → s[1] = "y"
  "c" → idx = 2 → s[2] = "z"
  "a" → idx = 0 → s[0] = "x"

  result = "yzx"

t の各文字をアルファベット順のインデックスとして使い、s から文字を取り出して並べ直す処理。

----------------------------------------------------------------------------
ordは、1文字の文字列に対して、その文字の文字コード(整数値)を返すメソッドです。逆の変換をするメソッドがchr(整数→文字)です。


'a'.ord  # => 97
'b'.ord  # => 98
'z'.ord  # => 122
'A'.ord  # => 65
このコードでは、


idx = char.downcase.ord - 'a'.ord
という形で使われています。これは「charがaから数えて何番目のアルファベットか」を0始まりで求める定番のイディオムです。

char.downcase : 大文字が来ても小文字に揃える
.ord : その文字の文字コードを取得(例: 'c'.ord → 99)
- 'a'.ord : 'a'の文字コード(97)を引くことで、a→0, b→1, c→2, ... z→25という0始まりの番号(idx)に変換する
こうして求めたidxをs[idx]のように使うことで、
「tの各文字を、アルファベット順に対応するsの文字に置き換える」という換字表(暗号のシーザー式変換に似た仕組み)を実現しています。

----------------------------------------------------------------------------
.zip メソッドの解説
基本の動き
2つの配列を「横に並べて、同じ位置の要素をペアにする」メソッド。


a = [1, 2, 3]
b = [10, 20, 30]

a.zip(b)
#=> [[1, 10], [2, 20], [3, 30]]
インデックス0同士、1同士、2同士がペアになって、入れ子配列になる。
----------------------------------------------------------------------------
----------------------------------------------------------------------------

各行の意味
    left = a[0...mid].reverse

a = [1, 2, 3, 4, 5, 6]
mid = 3

a[0...mid]   #=> [1, 2, 3]  （先頭からmid-1まで、midは含まない）
.reverse     #=> [3, 2, 1]  （それを逆順にする）
0...mid（3点）は mid を含まない スライス。0..mid（2点）だと mid を含むので注意。
----------------------------------------------------------------------------

    right = a[mid..-1]

a[mid..-1]   #=> [4, 5, 6]  （mid番目から最後まで）
-1 は「最後の要素」を意味する。a[3..-1] は「インデックス3から末尾まで」。

----------------------------------------------------------------------------

    a = left.zip(right).map { |l_val, r_val| l_val + r_val }
zip は2つの配列を要素同士でペアにして、入れ子配列を作る。


left  = [3, 2, 1]
right = [4, 5, 6]

left.zip(right)
#=> [[3, 4], [2, 5], [1, 6]]
.map { |l_val, r_val| l_val + r_val } は各ペアの2つを足す。


[[3, 4], [2, 5], [1, 6]].map { |l, r| l + r }
#=> [7, 7, 7]
ブロック引数 |l_val, r_val| は、サブ配列 [3, 4] を 自動で展開 して2変数に受け取ってくれる。
----------------------------------------------------------------------------

全体の流れ（k回繰り返す）

元の配列: [1, 2, 3, 4, 5, 6]
          ↓ 前半を逆順に
left  = [3, 2, 1]
right = [4, 5, 6]
          ↓ zip で対応する要素を足す
a = [7, 7, 7]
「配列を前後に分けて、逆順にした前半と後半を要素ごとに足す」という操作を k 回繰り返す処理。

n = gets.to_i
h = gets.split(" ").map(&:to_i)

energy = 0
can_reach = true

h.each do |val|
    
    if val < 0
        energy += -val
    else
        energy -= val
    end
    
    if energy < 0
        can_reach = false
        break
    end
end


if can_reach
    puts "YES"
else
    puts "NO"
end
