### メソッド
  Array#push           末尾に要素を追加する（<< と同じ）
  Array#shift          先頭の要素を取り出す（元の配列から削除）
  Array#pop            末尾の要素を取り出す（元の配列から削除）
  Array#unshift        先頭に要素を追加する
  Array#empty?         配列が空なら true を返す
  Array#min            配列の中で最小の値を返す
  Array#include?       指定の値が含まれているか true/false で返す
  each_with_index      各要素とインデックスを同時に取得するループ

### 構文・記法
  array << 値          push と同じ（短縮形）
  [a, b].min           2つの値を配列にして小さい方を取り出すパターン
  from = a - 1         入力値（1始まり）を配列インデックス（0始まり）に変換

### 知識・パターン
  フラグ＋empty?パターン      bingo.empty? で「何も該当しなかった」ときに -1 を出力
  キューパターン              push で追加 → shift で先頭から取り出す（先入れ先出し）
  配列インデックスで共通化    ペアになるデータは「配列番号」で揃えて管理する
  min で上限チェック          [手持ち, 渡したい数].min で「持っている以上は渡せない」を表現

n, k = gets.split(" ").map(&:to_i)

winning_numbers = gets.split(" ").map(&:to_i)
votes = gets.split(" ").map(&:to_i)

bingo = []

votes.each_with_index do |v, i|
    vote_id = i + 1
    
    if winning_numbers.include?(v)
        bingo.push(vote_id)
    end
end

if bingo.empty?
    puts -1
else
    bingo.each do |id|
        puts id
    end
end

## 配列への追加・取り出しメソッド

### 末尾に追加
  array.push(値)   # 末尾に追加
  array << 値      # push と同じ（よく使われる短縮形）

  a = [1, 2, 3]
  a.push(4)   #=> [1, 2, 3, 4]
  a << 5      #=> [1, 2, 3, 4, 5]

### 先頭に追加
  array.unshift(値)  # 先頭に追加

  a = [1, 2, 3]
  a.unshift(0)   #=> [0, 1, 2, 3]

### 末尾から取り出す
  array.pop   # 末尾の要素を取り出す（元の配列から削除される）

  a = [1, 2, 3]
  a.pop   #=> 3
  a       #=> [1, 2]

### 先頭から取り出す
  array.shift   # 先頭の要素を取り出す（元の配列から削除される）

  a = [1, 2, 3]
  a.shift   #=> 1
  a         #=> [2, 3]

### まとめ

  末尾に追加  → push / <<
  先頭に追加  → unshift
  末尾から取り出し → pop
  先頭から取り出し → shift

キューのように「先に入れたものを先に取り出す」なら push で追加して shift で取り出す。

n = gets.to_i   #プレイヤー数

s = n.times.map { gets.to_i }   #それぞれが最初に持っているボールの数

m = gets.to_i   #パス回しの回数

m.times do
    a, b, x = gets.split(" ").map(&:to_i)
    
    from = a - 1
    to = b - 1
    
    min_balls = [s[from], x].min   # 手持ちのボールと実際に宣言した渡す数を比較し、少ない方を「min_balls」に代入する。
    
    s[from] -= min_balls
    s[to] += min_balls
end

s.each do |balls|
    puts balls
end

***上のコードについて***
2つ以上の要素のデータがペアになっている場合は、
要素自体でやりくりしようとするのではなく、配列番号で揃えることで共通化し、扱いやすくする。

一つの要素がもう一つの要素とペアになっている時、
前者の要素を配列番号として扱う（前者の要素 - 1）ことで、
後者の要素も配列として扱うとき、その前者の要素数の分、配列番号として扱うことができる。

２つ以上の要素がペアになっている時のデータの扱い方は、それらに共通する配列番号で見るといい。

## [s[from], x].min の解説

### .min とは
配列の中で一番小さい値を返すメソッド。

  [3, 1, 2].min  #=> 1
  [10, 5].min    #=> 5

### このコードでの使われ方

  min_balls = [s[from], x].min

「手持ちのボール数」と「渡したい数」を配列にして、小さい方を取る。

  s[from] = 3  （手持ち3個）
  x       = 5  （渡したい5個）

  [3, 5].min  #=> 3  ← 3個しか持っていないので3個しか渡せない

手持ちより多く渡すことはできないので、どちらか小さい方が実際に渡せる数になる。
