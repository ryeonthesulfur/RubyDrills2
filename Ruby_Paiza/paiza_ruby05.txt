## { } と &: の使い分け

map にブロックを渡す方法は2種類あり、どちらも同じ意味になる。

  # { } でブロックを書く（中の処理を自分で書く）
  m.times.map { gets.to_i }

  # &: でシンボルを渡す（既存メソッドを名前で渡す）
  gets.split(" ").map(&:to_i)

-----

&:to_i は { |x| x.to_i } の短縮形。この2つは同じ意味。

  array.map { |x| x.to_i }
  array.map(&:to_i)          # 上と同じ

-----

&: はメソッド名1つしか渡せないので、gets.to_i のような
「2つのメソッドの組み合わせ」は { } に書くしかない。

  &:to_i      # OK（メソッド1つ）
  &:gets.to_i # NG（そんな書き方はない）

-----

まとめ：
  既存のメソッド1つを呼ぶだけ → &:メソッド名
  自分で処理を書く             → { }

## sort メソッド

配列の要素を昇順（小さい順）に並べ替えた新しい配列を返す。

  [3, 1, 2].sort      #=> [1, 2, 3]
  ["c", "a", "b"].sort  #=> ["a", "b", "c"]  文字列はアルファベット順

### このコードでの使われ方

  s.chars.sort == t.chars.sort

s と t をそれぞれ1文字ずつに分解して、同じ順番に並べてから比較している。
並べ替えることで「同じ文字が同じ数だけ含まれているか」を確認できる。

  s = "abc" → s.chars → ["a","b","c"] → sort → ["a","b","c"]
  t = "bca" → t.chars → ["b","c","a"] → sort → ["a","b","c"]
  # 同じなので YES

  s = "abc" → sort → ["a","b","c"]
  t = "xyz" → sort → ["x","y","z"]
  # 違うので NO
