### メソッド
  Float#ceil           小数点以下を切り上げて整数にする（例: 2.5.ceil → 3）
  Array#rotate         配列の先頭をn個末尾に移した新しい配列を返す
  Array#rotate!        rotate の破壊的版（元の配列自体を書き換える）
  Array#count          条件を満たす要素の数を返す（ブロックつき）
  String#include?      文字列が指定の文字を含むか true/false で返す
  Array.new(n, 0)      n個の要素をすべて0で初期化した配列を作る
  Integer#times        n回繰り返す（|val| でインデックスを受け取れる）
  exit                 プログラムをその場で終了する

### 構文・記法
  (0..100).each        範囲オブジェクトに each でループ
  (a-1..b-1).each      入力値を0始まりのインデックスに変換して範囲ループ
  ブロック変数 |val|   times や each がインデックス・要素を渡す受け皿
  配列同士の ==        配列の内容が一致するか比較できる

### 知識・パターン
  通常変数とブロック変数の違い   自分で代入する変数 vs メソッドが値を渡すブロック変数
  フラグ変数パターン             match = false → 条件で true にして break
  found = false パターン         ループ後に「一つも見つからなかった」を検出する
  順位づけパターン               count { |x| x > score } + 1 で自分より上の人数＋1
  破壊的メソッド（!）            元のオブジェクトを直接書き換える（rotate! など）

n, c = gets.split(" ").map(&:to_i)
a = gets.split(" ").map(&:to_i)

majority = (n / 2.0).ceil

(0..100).each do |k|
    count = 0

    n.times do |val|
        result = a[val] + k
        
        if result >= c
            count += 1
        end
    end

    if count >= majority
        puts k
        exit
    end
end

**通常の変数**
自分が意図した数値を自由に入れたり書き換えたりできる箱（例: `k = 0` や `count = 0`）。

**ブロック変数（`|val|`）**
メソッド（`n.times`）から、代入した変数の中の値の分が、配列番号（インデックス）に置き換わり、
`0, 1, 2...` と値が置き換わっていく受け皿。

n = gets.to_i
ages = n.times.map { gets.to_i }
beans = Array.new(n, 0)

m = gets.to_i

m.times do
    a, b, c = gets.split.map(&:to_i)
    
    (a - 1..b - 1).each do |i|
        beans[i] += c
        
        if beans[i] > ages[i]
            beans[i] = ages[i]
        end
    end
end

beans.each do |b|
    puts b
end

## .rotate! メソッド

### rotate の基本
配列の要素を「左にずらす（先頭を末尾に移す）」メソッド。

  a = ["a", "b", "c", "d"]
  a.rotate(1)   #=> ["b", "c", "d", "a"]  （先頭1つが末尾へ）
  a.rotate(2)   #=> ["c", "d", "a", "b"]  （先頭2つが末尾へ）

### ! がつく意味
rotate は元の配列を変えない。rotate! は元の配列自体を書き換える（破壊的メソッド）。

  a = ["a", "b", "c"]
  a.rotate(1)   #=> ["b", "c", "a"]  ← 元の a はそのまま
  a             #=> ["a", "b", "c"]  ← 変わっていない

  a.rotate!(1)  #=> ["b", "c", "a"]
  a             #=> ["b", "c", "a"]  ← 書き換わっている

### このコードでの使われ方
文字列を1文字ずつの配列にして、1文字ずつローテーションしながら別の文字列と一致するか調べている。

  m = ["b", "c", "d"]  （調べたい文字列）
  l = ["c", "d", "b"]  （一致させたい文字列）

  1回目: m.rotate!(1) → ["c", "d", "b"]  ← l と一致！→ "Yes"

「文字列を回転させると別の文字列と同じになるか」を調べる問題で使われているパターン。

## rank = m.count { |x| x > score } + 1 の解説

### m.count { |x| x > score } とは
ブロックとは { |x| x > score } の部分のこと。
{ } の中に「1要素ずつに対してやる処理」を書く。それがブロック。
count はそのブロックを使って「true になった回数」を返す。
|x| に m の要素が1つずつ入り、x > score が true の回数を数える。

  m = [90, 70, 85]
  score = 70

  m.count { |x| x > 70 }
  # x=90 → 90 > 70 → true
  # x=70 → 70 > 70 → false
  # x=85 → 85 > 70 → true
  #=> 2

### + 1 する理由
「自分より高い点数が2人いる」= 自分は3位。
自分より上の人数に +1 すれば自分の順位になる。

---

### 「m { |x| }」と書くと配列の中身がブロック変数に入るの？

「ブロック変数に入る」は正しいけど、「m { }」だけでは入らない。
m.each や m.count のように、メソッドが配列を1つずつブロックに渡している。

  m.each   { |x| }   # each が m の要素を1つずつ |x| に渡す
  m.count  { |x| }   # count が m の要素を1つずつ |x| に渡す
  m.map    { |x| }   # map   が m の要素を1つずつ |x| に渡す

ブロック変数（|x|）は「受け取る箱」で、メソッド側が「何を渡すか」を決めている。
配列のメソッドなら「要素1つずつ」、each_with_index なら「要素＋番号」を渡す。
