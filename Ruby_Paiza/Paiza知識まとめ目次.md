## 入力の受け取り方

| 書き方 | 意味 |
|:-------|:-----|
| `gets.to_i` | 1行を整数として受け取る |
| `gets.chomp` | 1行を文字列として受け取る（末尾の改行を除去） |
| `gets.split` | 1行をスペース区切りで配列にする |
| `gets.split.map(&:to_i)` | スペース区切りの数値を整数の配列にする |
| `a, b = gets.split` | 1行をスペース区切りで複数変数に同時代入 |
| `n.times.map { gets.to_i }` | n行分を1行ずつ読んで整数配列にする（縦並びデータ向け） |
| `n.times.map { gets.chomp }` | n行分を1行ずつ読んで文字列配列にする |

## 配列操作

| メソッド | 意味 |
|:---------|:-----|
| `配列 << 値` | 末尾に要素を追加（push と同じ） |
| `配列.select { \|x\| 条件 }` | 条件を満たす要素だけを残した新しい配列を返す |
| `Range#to_a` | 範囲オブジェクトを配列に変換する（例: `(1..5).to_a` → `[1,2,3,4,5]`） |
| `配列.push(値)` | 末尾に要素を追加 |
| `配列.shift` | 先頭の要素を取り出す（元の配列から削除） |
| `配列.pop` | 末尾の要素を取り出す（元の配列から削除） |
| `配列.unshift(値)` | 先頭に要素を追加 |
| `配列.include?(値)` | 指定の値が含まれるか true/false で返す |
| `配列.sum` | 合計値を返す |
| `配列.length / .size` | 要素数を返す |
| `配列.empty?` | 配列が空なら true を返す |
| `配列.sort` | 昇順に並べ替えた新しい配列を返す |
| `配列.max / .min` | 最大値 / 最小値を返す |
| `配列.uniq.size` | 重複を除いた要素数を返す |
| `配列.join(' ')` | 配列を指定区切りの文字列に変換 |
| `配列.rotate(n)` | 先頭をn個末尾に移した新しい配列を返す |
| `配列.rotate!(n)` | rotate の破壊的版（元の配列を書き換える） |
| `[a, b].min` | 2つの値を配列にして小さい方を取り出す |
| `Array.new(n, 0)` | n個の要素をすべて0で初期化した配列を作る |

## 文字列操作

| メソッド | 意味 |
|:---------|:-----|
| `文字列.chars` | 文字列を1文字ずつの配列に分解 |
| `文字列.chars.sort` | 文字を並べ替え（アナグラム判定に使う） |
| `文字列[-1]` | 最後の文字を取得（-1 で末尾から数える） |
| `文字列.gsub("a", "b")` | 文字列中の "a" をすべて "b" に置換 |
| `文字列.gsub(正規表現, "b")` | 正規表現にマッチした部分を置換 |
| `文字列.split(':')` | 指定文字で区切って配列にする |
| `文字列.count('文字')` | 指定文字が何個含まれるか数える |
| `文字列.include?(文字)` | 指定の文字を含むか true/false で返す |

## 数値操作

| メソッド | 意味 |
|:---------|:-----|
| `数値.ceil` | 小数点以下を切り上げ（例: 3.1 → 4） |
| `数値.floor` | 小数点以下を切り捨てる |
| `数値.to_f` | 整数を小数として扱う（割り算の精度を上げる） |
| `数値.abs` | 絶対値を返す |
| `数値.odd?` | 奇数なら true を返す |
| `数値.to_s` | 整数を文字列に変換する（include? を使う前に必要） |
| `数値.to_s.reverse.to_i` | 数値の桁を逆順にする（例: 123 → 321） |

## ハッシュ操作

| メソッド | 意味 |
|:---------|:-----|
| `配列.tally` | 各要素の出現回数をハッシュで返す |
| `ハッシュ.values.max` | ハッシュの値の中から最大値を取得 |
| `ハッシュ.select { \|k, v\| 条件 }` | 条件に合う要素だけ絞り込む |
| `ハッシュ.keys` | キーだけを配列で取得 |
| `ハッシュ.max_by { \|k, v\| v }[0]` | 値が最大のキーを取得 |

## 正規表現

| 書き方 | 意味 |
|:-------|:-----|
| `/-+/` | ハイフンが1個以上連続するパターン |
| `/ ... /` | 正規表現はスラッシュで囲む |
| `+` | 直前の文字が1回以上繰り返す |

## 制御構文

| 書き方 | 意味 |
|:-------|:-----|
| `unless 条件` | 条件が偽のときだけ実行（`if !条件` と同じ） |
| `exit` | プログラムをその場で終了する |
| `next` | ループの残り処理をスキップして次のループへ |
| `break` | ループをその場で抜ける |
| `loop do ... break end` | 条件を満たすまで無限ループ（while true と同じ） |

## ブロック・イテレータ

| 書き方 | 意味 |
|:-------|:-----|
| `array.map { \|x\| x.to_i }` | 各要素に処理を適用して新しい配列を作る |
| `array.map(&:to_i)` | 上と同じ意味の短縮形 |
| `array.map do ... end` | ブロックが複数行のときの map の書き方。最後の行の値が集められる |
| `array.each_with_index { \|v, i\| }` | 要素と番号を同時に取得するループ |
| `array.count { \|x\| 条件 }` | 条件を満たす要素の数を返す |
| `(0..100).each` | 範囲オブジェクトに each でループ |

## よく使うパターン・こつ

| パターン | 内容 |
|:---------|:-----|
| アナグラム判定 | `s.chars.sort == t.chars.sort` |
| フラグ変数 | `flag = false` → 条件で `true` にして `break` |
| found パターン | `found = false` → ループ後に `unless found` で未検出を処理 |
| キューパターン | `push` で追加 → `shift` で先頭から取り出す（先入れ先出し） |
| 順位づけ | `m.count { \|x\| x > score } + 1` で自分より上の人数＋1 |
| 時間を分に変換 | `時 * 60 + 分`（戻すときは `/ 60` と `% 60`） |
| 平均を切り上げ | `(合計.to_f / 個数).ceil` |
| 連続文字の圧縮 | `gsub(/-+/, '-')` のように正規表現を使う |
| min で上限チェック | `[手持ち, 渡したい数].min` で「持っている以上は渡せない」を表現 |
| 配列インデックスで共通化 | ペアデータは配列番号で揃えて管理する（`a - 1` で0始まりに変換） |
| 出現回数の最多を取得 | `配列.tally.max_by { \|k, v\| v }[0]` |
| 連続3要素の判定 | `k[i]==1 && k[i+1]==1 && k[i+2]==2`（ループは `(n-2).times`） |
| 文字の回転チェック | `m.rotate!(1)` で1文字ずつずらして比較 |
| ハッシュによる文字変換 | `hash[c] \|\| c` でハッシュに変換ルールがあれば使い、なければ元の文字を使う |
| 2次元配列の作り方 | `n.times.map { gets.split(" ").map(&:to_i) }` で行×列の配列を作る |
| グリッド走査パターン | `h.times / w.times` の入れ子で `s[i][j]` を参照して全マスを走査する |
| 特定列の集計 | `data.map { \|row\| row[n] }.max` で列を抽出してから max/min/sum |
| 約数の求め方 | `(1...n).select { \|i\| n % i == 0 }` で1からn-1の約数を取得 |
| マイナス防止 | `[0, value].max` で0より小さくならないようにする |
| 連続カウント＋break | `consecutive` を更新して閾値以上になったらループを抜ける |
| n.each はエラー | 整数に each は使えない → `(1..n).each` を使う |
| map do...end の最後の値 | ブロックの最後の行だけが map に集められる（途中の処理は捨てられない） |
| FizzBuzz発展パターン | `rules = [[倍数, 文字列], ...]` を用意して動的に判定・出力する |
