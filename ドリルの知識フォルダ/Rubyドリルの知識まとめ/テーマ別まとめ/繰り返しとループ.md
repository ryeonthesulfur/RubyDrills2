## 1. each

```ruby
配列.each do |u| ... end       # 配列の要素を1つずつ処理する
```

### 入れ子 each

```ruby
配列.each do |name, prices|    # 内側の配列を2つの変数に自動で分解して受け取れる
  sum = 0                      # 各要素ごとに合計をリセットするために外側ループの中で初期化
  prices.each { |p| sum += p }
end
```

### ハッシュをインデックスつきで配列に登録するパターン

入力を受け取りながら `id` などの番号を自動で振りたいときに使う。

```ruby
users = []

3.times do |i|
  name = gets.chomp
  users << { id: i + 1, name: name }
end

# 入力: "taro", "hanako", "jiro" のとき
# users => [{id: 1, name: "taro"}, {id: 2, name: "hanako"}, {id: 3, name: "jiro"}]
```

`i` は 0始まりなので `i + 1` で1始まりの id にする。
`<<` でハッシュをそのまま配列に追加していく。

## 2. times

```ruby
10.times do |i| ... end        # 0〜9 の i で10回ループ
i + 1                          # times の i は 0 始まりなので、1〜10 にするには +1 する
sum += i + 1                   # 合計に加算していくパターン
ループの外で puts              # 途中経過を出さず、最後の合計だけ出力するときはループの外に書く
```

## 3. each_with_index

```ruby
配列.each_with_index do |値, インデックス| ... end
                               # 値とインデックス（0始まり）を同時に取得しながらループ
index + 1                      # 0始まりを1始まりに直す
return                         # メソッド内で見つかった時点でループを抜けて終了する
```

**例：番号付きの一覧表示**

```ruby
foods = ["ラーメン", "カレー", "うどん"]
foods.each_with_index do |food, i|
  puts "#{i + 1}. #{food}"
end
# 1. ラーメン
# 2. カレー
# 3. うどん
```

## 4. 範囲演算子での each

```ruby
(1..max_num).each do |num|     # 1 から max_num までを順に処理する
(開始..終了)                   # 範囲演算子（終了値を含む）
(開始...終了)                  # 終了値を含まない（... は3つ）
```

## 5. while

```ruby
while 条件 do
  処理
  num = num + 1                # ループ内でカウンタを手動で増やす
end
```

## 6. while true + exit（無限ループ）

終了条件が外部入力に依存するとき（メニューアプリなど）の定番パターン。

```ruby
while true do
  puts "1: 処理A  0: 終了"
  input = gets.to_i
  if input == 1
    処理A
  elsif input == 0
    exit                       # プログラムをその場で終了する
  end
end
```

## 7. while でバリデーション繰り返し

`if` だと1回しかチェックできない。何度でも再入力させたいときは `while` を使う。

```ruby
def validate_power(power)
  while power > 100
    puts "100以下の数字を入力してください"
    power = gets.to_i
  end
  return power                 # 正常値になったら返す
end
```

## 8. for 文

Ruby では `times` や `each` が慣習的だが、添字を使うソート等では `for` も使われる。

```ruby
for i in 0..length - 1        # 0 から length-1 まで繰り返す
  for j in 0..length - 2      # 入れ子ループ
    # 処理
  end
end
```

### バブルソートの例

```ruby
data = [3, 1, 4, 1, 5]
length = data.length

for i in 0..length - 1
  for j in 0..length - 2
    if data[j] > data[j + 1]
      data[j], data[j + 1] = data[j + 1], data[j]  # 隣と交換
    end
  end
end

p data  #=> [1, 1, 3, 4, 5]
```

**入れ子ループの動き：**

```
外側 i=0 → 内側 j=0,1,2... → 外側 i=1 → 内側 j=0,1,2...
外側1回につき内側が全件回る
```
