## 1. Date クラス（標準ライブラリ）

```ruby
require "date"                 # Date クラスを使うために必要な読み込み
Date.today.wday                # 今日の曜日を 0（日）〜 6（土）の整数で取得
```

### 配列で曜日名を管理するパターン

`wday` は曜日を数字で返すだけなので、名前にするには配列と組み合わせる。

```ruby
require "date"

wdays = ["日曜日", "月曜日", "火曜日", "水曜日", "木曜日", "金曜日", "土曜日"]
day   = Date.today.wday

puts wdays[day]                # day の数値で曜日名を取り出す
```

**流れの整理：**
1. `Date.today.wday` で曜日を**数字**として取得（例：月曜なら `1`）
2. その数字を配列のインデックスとして使い、曜日**名**を取り出す

## 2. Time クラス

```ruby
Time.new                       # 現在時刻を取得する
now = Time.new

now.year   #=> 2026  （年）
now.month  #=> 6     （月）
now.day    #=> 20    （日）
now.wday   #=> 0〜6  （曜日。0=日曜、1=月曜、...、6=土曜）
```

`Date.today.wday` と `Time.new.wday` はどちらも 0〜6 で曜日を返す。

## 3. %w 記法（文字列配列の省略記法）

`"` や `,` を書かずにスペース区切りで文字列配列を作れる。

```ruby
week = %w[日 月 火 水 木 金 土]
# 通常の書き方と同じ結果
week = ["日", "月", "火", "水", "木", "金", "土"]
```

文字列配列専用（数値の配列には使えない）。

## 4. 閏年の判定ロジック

```
① year % 4 == 0               → 4で割り切れる → 閏年の可能性あり
② year % 100 == 0 かつ year % 400 != 0
                               → 100で割り切れて400で割り切れない → 閏年ではない（例: 1900年）
③ 上記以外で4の倍数            → 閏年（例: 2000年、2024年）
```

**覚え方：** 「4の倍数 → 閏年。ただし100の倍数は除く。ただし400の倍数は含む」

### 月ごとの日数配列

```ruby
month_days = [31, 28, 31, 30, 31, 30, 31, 31, 30, 31, 30, 31]
month_days[month - 1]          # 月は1始まりなので -1 してインデックスに変換
```

2月は閏年のときだけ 29 日になるので、`month == 2` のときだけ閏年判定を追加する。
