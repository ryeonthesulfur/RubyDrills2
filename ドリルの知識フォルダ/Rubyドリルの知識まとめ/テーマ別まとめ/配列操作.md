## 1. 要素の検索・判定

```ruby
配列.include?(値)              # 配列に値が含まれるか（true/false）

配列.all? { |n| 条件 }        # 全要素が条件を満たすとき true を返す
[1,2,3].all? { |n| 配列.include?(n) }
                               # 複数の値が全て含まれるかを一行でチェック
```

## 2. 集計

```ruby
配列.sum                       # 配列の全要素を合計する
sum += price                   # ループで1つずつ足していく基本パターン

配列.count(値)                 # 配列内に指定した値が何個あるか返す
```

### カウントの基本パターン

```ruby
count = 0
配列.each do |n|
  count += 1 if n.even?
end                            # 条件を満たす要素の数を数える基本パターン
```

## 3. 入れ子配列の処理

```ruby
配列.each do |name, prices|   # 内側の配列を2つの変数に自動で分解して受け取れる
fruit[0] / fruit[1]           # インデックスで要素を取り出す方法（別解）
sum = 0 をループの外に        # 各要素ごとに合計をリセットするために外側ループの中で初期化
```

**例：**

```ruby
fruits = [["りんご", 100, 120], ["バナナ", 80, 90]]

fruits.each do |name, price1, price2|
  avg = (price1 + price2) / 2
  puts "#{name}: 平均#{avg}円"
end
```

## 4. 重複除外のパターン

「同じ値が2個以上あれば除外」＝ 出現回数が1のものだけ合計する。

```ruby
unique = []
nums.each do |n|
  count = 0
  nums.each do |m|
    count += 1 if n == m       # 同じ値の個数を数える
  end
  unique << n if count < 2    # 1回しか出てこない数値だけを別配列に集める
end

sum = 0
unique.each { |n| sum += n }  # 集めた配列を合計する
```

## 5. その他の操作

```ruby
配列.shuffle                   # 配列の要素をランダムに並び替えた新しい配列を返す
配列 << 要素                   # 配列の末尾に要素を追加する
配列.empty?                    # 配列が空なら true、要素があれば false
```

### empty? の使い方

```ruby
unless cart.empty?             # カートが空でない時だけ処理する
  puts "合計: #{total_price}円"
end
```

## 6. 配列を引数で渡して戻り値で受け取るパターン

```ruby
def post_item(a_cart)
  # ... a_cart に要素を追加 ...
  return a_cart                # 変更した配列を返す
end

cart = post_item(cart)         # 戻り値で cart を上書きする（意図が明確）
```

## 7. インスタンスを配列に入れるパターン

ハッシュではなくオブジェクトを配列に入れる設計。

```ruby
class Food
  @@foods = []
  attr_reader :name, :calory

  def self.input
    food = Food.new(name, calory)   # インスタンスを作って
    @@foods << food                 # クラス変数の配列に追加
  end
end

# 取り出すときは .メソッド で値を読む（ハッシュの [:key] とは違う）
@@foods.each do |food|
  puts food.name    # food[:name] ではなく food.name
  puts food.calory
end
```
