## 5. 絶対値

```ruby
(a - b).abs                    # a と b の差の絶対値（負になっても正に直す）
                               # 例: (1 - 3).abs → 2、(3 - 1).abs → 2
```

### 距離の比較パターン

```ruby
x = (a - b).abs                # a と b の距離
y = (b - c).abs                # b と c の距離
z = (a - c).abs                # a と c の距離
# それぞれ変数に入れてから条件分岐すると読みやすい
```

## 6. 10の倍数との距離判定

```ruby
num % 10 <= 2                  # 10の倍数から2以内の右側（例: 10, 11, 12）
num % 10 >= 8                  # 10の倍数から2以内の左側（例: 18, 19, 20）
# 両方を || でつなぐ → 「差が2以内」を表現する
```

### こつ：「近い方の距離」の考え方

```ruby
num = total % 10               # 合計値の一の位
if num <= 5
  # 右が近い → num がそのまま差
else
  # 左が近い → 10 - num が差
end
```

## 7. バイナリーサーチ（2分割検索）

ソート済みの配列で使う高速な検索アルゴリズム。

```
① 左端(left)と右端(right)の中央(center)を求める
② center の値が target と一致 → その位置を返す
③ center の値が target より小さい → 右半分を探す（left = center + 1）
④ center の値が target より大きい → 左半分を探す（right = center - 1）
⑤ left > right になったら見つからない → -1 を返す
```

```ruby
center = (left + right) / 2   # 整数除算で中央位置を求める
return -1                      # 「存在しない」を -1 で表すパターン
result == -1 で分岐            # 戻り値で存在チェック
```

## 12. 範囲演算子の総和

```ruby
(n..m).sum                     # n 以上 m 以下の整数を全部合計する（Ruby らしい書き方）
```

`while` で書く基本パターン（他の言語でも共通する書き方）：

```ruby
total = 0
while n <= m
  total += n
  n += 1                       # カウンタを進める（忘れると無限ループ）
end
```

## 13. バブルソートのアルゴリズム

隣り合う要素を比べて、大きい方を右に送ることを繰り返す。

```ruby
length = data.length

for i in 0..length - 1
  for j in 0..length - 2
    if data[j] > data[j + 1]          # 昇順：左が大きければ交換
      data[j], data[j + 1] = data[j + 1], data[j]  # 多重代入で一時変数なしに交換
    end
  end
end
```

**降順にするには：**

```ruby
if data[j] < data[j + 1]             # 比較の向きを逆にするだけ
```

### 多重代入で値を交換する

```ruby
data[j], data[j + 1] = data[j + 1], data[j]
# Ruby では一時変数不要でこの1行で交換できる
# PHP/Java では temp 変数が必要
```

## 14. 曜日計算（days % 7）

総日数を7で割った余りが曜日インデックスになる。

```ruby
weeks = ["日", "月", "火", "水", "木", "金", "土"]
weeks[days % 7]                # 総日数 % 7 → 0〜6 の曜日インデックス
```
