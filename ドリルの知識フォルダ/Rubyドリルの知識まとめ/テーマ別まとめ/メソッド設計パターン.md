## 1. メソッドの基本定義

```ruby
def メソッド名(引数) ... end   # メソッドの定義
return 値                      # 値を返す（返すだけで出力はしない）
puts メソッド名(引数)          # メソッドの戻り値を出力する
```

## 2. 引数の渡し方

```ruby
def multiple(num1, num2)       # 仮引数を2つ受け取るメソッド
  return num1 * num2
end

multiple(3, 4)                 # 呼び出し時に実引数を渡す
```

## 3. メソッド名に ? をつける慣習

`true` / `false` を返すメソッドには `?` をつけるのが Ruby の慣習。

```ruby
def include_cat_and_dog?(str)
  str.include?("cat") && str.include?("dog")
end

puts include_cat_and_dog?("I have a cat and dog")  #=> true
```

`include?`, `empty?`, `even?`, `end_with?` など標準メソッドもこの慣習に従っている。

## 4. 条件によって演算を切り替えるパターン

```ruby
def calculate(num, count)
  if count <= 3
    num / count                # 条件Aのときは割り算
  else
    num * count                # 条件Bのときは掛け算
  end
end
```

## 5. バリデーション（入力値の検証）

入力と検証を分離し、専用メソッドを作るのがきれいな設計。

```ruby
def validate_power(power)
  while power > 100
    puts "100以下の数字を入力してください"
    power = gets.to_i
  end
  return power                 # 正常値になったら返す
end

punch = validate_power(gets.to_i)  # 入力を検証メソッドに通してから変数に入れる
```

**こつ：** `if` だと1回しかチェックできない → 何度でも再入力させたいなら `while`

## 6. 再帰呼び出し

自分自身を呼び出すことでループの代わりに繰り返す。

```ruby
def complete(total_price)
  puts "金額を入力してください"
  payment = gets.to_i
  if payment >= total_price
    puts "お釣り: #{payment - total_price}円"
  else
    puts "金額が足りません"
    complete(total_price)      # 不足のとき自分自身を呼び出して再入力させる
  end
end
```

## 7. 登録→一覧→詳細の層構造パターン

アプリの処理を役割ごとにメソッドに切り出す設計。

### 3層構造（基本パターン）

```
register_data   → ハッシュを作って配列に追加
show_data_list  → each_with_index で番号付き一覧 → 番号入力 → 詳細へ
show_data       → 選択されたハッシュの中身を表示
```

```ruby
# 一覧から選択して詳細を見るパターン
data[input - 1]                # 1始まりの番号入力を 0始まりのインデックスに変換
```

### 4層構造（発展パターン）

```
register_data       → データ登録
confirm_data_list   → 一覧表示 → 番号入力
confirm_data        → 詳細表示 → 追加入力
calculate_xxx       → 計算・出力
```

前のメソッドが次のメソッドを呼ぶ連鎖構造。処理ごとに役割を分けることでコードが読みやすくなる。
