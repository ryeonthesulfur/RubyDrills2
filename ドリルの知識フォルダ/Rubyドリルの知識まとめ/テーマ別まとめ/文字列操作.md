## 2. 文字列の検索・判定

```ruby
str.include?(".")              # 文字列に指定した文字が含まれるか（true/false）
str.include?(" ")              # 半角スペースが含まれるかのチェック
str.end_with?("abc")          # 文字列が "abc" で終わるか（true/false）
```

### 複合条件での検索

```ruby
str.include?("xyz") && !str.include?(".xyz")
                               # "xyz" を含む かつ ".xyz" を含まない
str.include?("cat") && str.include?("dog")
                               # 両方の文字列が含まれるかを AND でチェック
```

### scan と index

```ruby
str.scan("hi")                 # "hi" を全て探して配列で返す（例: ["hi", "hi"]）
str.scan("hi").length          # 見つかった数を取得（配列の要素数）

str.index("code")              # "code" が最初に出現する位置を 0 始まりで返す
                               # 見つからない場合は nil を返す
```

### nil チェックのパターン

```ruby
pos = str.index("code")
if pos                         # pos が nil でなければ実行（nil は false 扱い）
  puts pos + 1                 # index は 0 始まりなので +1 で「何文字目」に変換
end
# nil + 1 はエラーになるので nil チェックは必須
```

## 3. 文字列の切り出し（slice）

### インデックスで取り出す

```ruby
str[0]                         # 先頭の1文字
str[0..1]                      # 先頭から2文字（0番目〜1番目）
str[2..-1]                     # 3文字目から末尾まで（-1 は最後の文字）
str[開始..終了]                # 範囲指定で部分文字列を取り出す
```

### 末尾からの指定（負のインデックス）

```ruby
str.slice(-2, 2)               # 末尾から2文字目を起点に2文字取り出す
str.slice(-3..-1)              # 末尾から3文字目〜末尾を取り出す
str.slice(-n..-1)              # 末尾 n 文字を取り出すパターン
```

### 応用：先頭2文字を末尾に移動する

```ruby
str[2..-1] + str[0..1]         # 3文字目以降 + 先頭2文字 で入れ替え
```

## 6. 破壊的メソッド（!）

```ruby
str.slice!(n - 1)              # n番目（1始まり）の文字を元の文字列から直接削除する
                               # ! がつく「破壊的メソッド」：元のデータ自体を変える
                               # n - 1 はインデックスが 0 始まりのため
```

**! なし vs ! あり の違い：**

```ruby
str.slice(0)    # 元の str は変わらない。取り出した値を返すだけ
str.slice!(0)   # 元の str から直接削除する
```

gsub, sort なども同様に `!` あり・なしで挙動が変わる。

## 7. 改行コード

```ruby
\n              # 改行を表す特殊文字
puts            # 自動で末尾に改行をつける
print           # 改行をつけない（PHP の echo に近い動き）
```

## 8. gsub（文字列置換・削除）

```ruby
str.gsub(/[\s]/, "")           # 半角空白を空文字に置換（= 削除）
str.gsub(/[\s　]/, "")         # 半角空白 + 全角空白を両方削除
```

**正規表現の基本：**

```
\s          → 半角スペース・タブ・改行などを表す
[...]       → [] の中のどれか1文字にマッチする
　（全角スペース）  → \s では拾えないので [] の中に明示的に追加する
```

---

## 9. メソッドチェーン

複数のメソッドを `.` でつなげて1行で書くことができる。

```ruby
text.gsub(/[\s　]/, "").upcase  # 空白削除 → 大文字変換 を1行で
```

左から順に処理される。読み書きのしやすさを考えて使う。
