## 1. 基本の書き方と取得

```ruby
{ one: 1, two: 2 }            # シンボルをキーにしたハッシュの書き方
hash[:one]                     # 値の取得（シンボルキー）

hash.keys                      # キーだけを配列で取得
hash.values                    # 値だけを配列で取得
```

---

## 2. ネストしたハッシュ・配列

```ruby
u[:user][:profile][:name]      # ネストしたハッシュを順番にたどって値を取得
u.dig(:user, :profile, :name)  # dig メソッドで同じことを1行で書ける（別解）
```

`dig` はキーが途中で `nil` でもエラーにならず `nil` を返すので安全。

---

## 3. キーの種類：シンボル vs 文字列

```ruby
{"title" => "ハリーポッター"}  # 文字列キー：取り出しは hash["title"]
{title: "ハリーポッター"}      # シンボルキー：取り出しは hash[:title]
# ※キーの型を間違えると値が取得できないので注意
```

### to_sym：文字列をシンボルに変換

```ruby
gets.chomp.to_sym              # 文字列入力をシンボルに変換する
                               # シンボルキーのハッシュを入力で操作するときに必要
```

**例：**

```ruby
movie = { title: "ハリーポッター", year: 2001 }

print "取得するキーを入力: "
key = gets.chomp.to_sym        # "title" と入力 → :title に変換
puts movie[key]                #=> "ハリーポッター"
```

## 4. ハッシュを引数で渡す

```ruby
def movie_info(movie, info)
  puts movie[info]             # ハッシュとキーを引数で受け取って値を取り出す
end

movie_info({title: "ハリポタ"}, :title)  #=> "ハリポタ"
```

## 5. 配列にハッシュを追加するパターン

```ruby
book = { author: author, title: title, price: price }
data << book                   # ハッシュを作って配列に追加
```

複数件のデータを管理するときの基本パターン。

---

## 6. ハッシュへの動的な代入

リテラルで一括定義せず、後からキーに値を代入していく書き方。

```ruby
student = {}                   # 空のハッシュを作る
student[:name]  = gets.chomp   # キーに直接値を代入
student[:age]   = gets.to_i
student[:score] = gets.to_i
```

`{ name: ..., age: ..., score: ... }` と一括定義するのと同じ結果になる。

---

## 7. ハッシュのキー設計（利益計算の例）

後で計算に使う値は「計算結果も一緒に保存しておく」設計にすると楽。

```ruby
item[:price]       = gets.to_i  # 販売価格
item[:cost_price]  = gets.to_i  # 仕入れ値

# 後で利益を計算するときに両方のキーが必要
item[:profit]      = item[:price] - item[:cost_price]
item[:profit_rate] = item[:profit].to_f / item[:cost_price].to_f
```

info = {

}
