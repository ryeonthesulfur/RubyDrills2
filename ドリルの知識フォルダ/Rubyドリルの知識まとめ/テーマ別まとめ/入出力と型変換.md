## 1. キーボード入力の受け取り

```ruby
gets                           # キーボードから1行入力を受け取る（末尾に \n がつく）
gets.chomp                     # 入力の末尾の改行を取り除く（安全な受け取り方）
```

### 複数の入力を受け取る

```ruby
num1 = gets.to_i
num2 = gets.to_i               # 2回 gets を使って別々の変数に受け取る
```

## 2. 型変換

```ruby
gets.to_i                      # 入力を整数として受け取る
gets.chomp.to_f                # 小数（Float）として受け取る（身長・体重など）
output(gets.to_i)              # 入力を受け取りながらメソッドに直接渡す書き方

"title".to_sym                 # 文字列をシンボルに変換する
gets.chomp.to_sym              # 文字列入力をシンボルに変換（シンボルキーのハッシュ操作に必要）

整数.to_f                      # 整数を小数に変換（整数 / 整数 は切り捨てになるため）
# to_f は割られる側か割る側どちらか1つに付けても OK
profit_rate = profit.to_f / cost.to_f
```

## 3. return と puts の使い分け

```ruby
return num                     # 値を返すだけ（出力しない）→ 呼び出し元で puts する
puts "#{num1 * num2}"          # メソッド内で直接出力する
```

**どちらを使うか：**

- `return` の方が汎用性が高い。返した値を計算に使ったり条件に使ったりできる。
- `puts` で出力してしまうと、その値を「再利用」できなくなる。
- 基本的には `return` で値を返すメソッドを作り、呼び出し元で `puts` するのが良い設計。

```ruby
# returnで返す（汎用性が高い）
def multiply(a, b)
  return a * b
end
puts multiply(3, 4)   # 呼び出し元で puts

# putsで直接出力（再利用できない）
def multiply(a, b)
  puts a * b          # この結果を他の計算に使えない
end
```
