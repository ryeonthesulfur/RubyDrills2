## 1. 基本の定義

```ruby
class クラス名 ... end         # クラスの定義
クラス名.new(引数)             # インスタンスの生成（initialize が自動で動く）
```

---

## 2. initialize メソッド

```ruby
def initialize(引数) ... end   # .new 時に自動実行される初期化メソッド
引数なしの initialize          # 空の箱を作るだけ。後からセッターで値をセット
initialize(attributes = {})    # ハッシュをまとめて受け取る書き方（Rails の params に対応）
```

---

## 3. インスタンス変数 @

```ruby
@変数名                        # クラス内どこからでも使えるインスタンス固有の変数
```

- `@` なし → そのメソッド内だけで使えるローカル変数
- `@` あり → そのインスタンスが存在する間ずっと使える

---

## 4. ゲッター・セッター・attr_*

```ruby
# 手書きの場合
def author; @author; end        # ゲッター：外から値を読み取る
def author=(v); @author=v; end  # セッター：外から値を書き換える

# 自動生成（推奨）
attr_reader :name               # ゲッターを自動生成（読み取り専用）
attr_writer :name               # セッターを自動生成（書き込み専用）
attr_accessor :name             # ゲッター・セッター両方を自動生成
```

---

## 5. self

```ruby
self.author = 値               # initialize 内でセッターを呼ぶときに使う
                               # self = 今まさに作られているインスタンス自身
```

`self.author = 値` と `@author = 値` の違い：
- `self.author =` → セッターメソッドを経由する（バリデーションなどを挟める）
- `@author =` → インスタンス変数に直接代入

---

## 6. インスタンスメソッド

```ruby
class Article
  def show
    puts "著者：#{@author}"   # クラス内は @変数 で直接参照できるのでゲッター不要
  end
end
```

---

## 7. クラスメソッド（def self.）

```ruby
def self.メソッド名 ... end    # クラスメソッドの定義
クラス名.メソッド名            # クラスメソッドの呼び出し（インスタンスなしで呼べる）
```

**例：**

```ruby
class Fruit
  def self.fresh
    puts "新鮮です"
  end
end

Fruit.fresh   # インスタンスを作らなくても呼べる
```

---

## 8. クラスメソッドとインスタンスメソッドの使い分け

```ruby
# クラスメソッドの中では @変数 は使えない
# → @変数 はインスタンスが持つもの。インスタンスなしに @変数 は存在しない

# インスタンスからクラスメソッドは呼び出せない
student = Student.new("太郎")
student.クラスメソッド名  # => エラー！
```

---

## 9. 継承（<）

```ruby
class 子クラス < 親クラス      # 親クラスのプロパティ・メソッドを引き継ぐ
class Student < Person         # Student は Person の initialize と @name / @age を受け継ぐ
```

**メリット：** 共通の処理を親クラスにまとめることで、子クラスに重複して書かなくて済む。

```ruby
class Person
  def initialize(name, age)
    @name = name
    @age  = age
  end
end

class Student < Person
  # initialize を書かなくても Person のものが動く
end

s = Student.new("太郎", 20)   # Person の initialize が自動で動く
```

## 10. クラス変数（@@）

```ruby
@@type = "犬"                  # クラス全体で共有される変数。全インスタンスで同じ値
```

| 変数 | 範囲 | 例 |
|:-----|:-----|:---|
| `@name` | そのインスタンスだけ | `dog1.name` と `dog2.name` は別々の値 |
| `@@type` | クラス全体（全インスタンス共通） | どのインスタンスから見ても同じ値 |

```ruby
class Dog
  @@type = "犬"

  def info
    puts "種別：#{@@type}"    # インスタンスメソッド内からも @@ でアクセスできる
  end
end
```

## 11. クラス変数で配列を管理する設計

今まで：配列を外に置いて引数で持ち回る（引数リレー）
今回：配列をクラス変数として持つ（引数不要）

```ruby
class Food
  @@foods = []                 # クラス変数として配列を持つ
  attr_reader :name, :calory

  def initialize(name, calory)
    @name   = name
    @calory = calory
  end

  def self.input
    # ...入力受付...
    food = Food.new(name, calory)
    @@foods << food            # 引数なしで直接追加できる（return も不要）
  end

  def self.show_all_calory
    @@foods.each do |food|
      puts "#{food.name}：#{food.calory}kcal"  # attr_reader のゲッターで取り出す
    end
  end
end

# 使う側はシンプル
Food.input
Food.show_all_calory
```
