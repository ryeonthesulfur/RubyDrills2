## 1. if / elsif / else

```ruby
if 条件A
  # A が true のとき
elsif 条件B
  # B が true のとき
else
  # どれにも当てはまらないとき
end
```

---

## 2. unless

```ruby
unless 条件                    # 条件が偽のときだけ実行（if !条件 と同じ）
unless a + b <= 0              # 「a+b が 0 以下でない = 0 より大きい」の書き方
```

---

## 3. 条件を書く順番のこつ

**狭い条件（より限定的なもの）を先に、広い条件を後に書く。**

```ruby
# 悪い例（広い条件が先だと狭い条件に到達しない）
if num <= 10
  puts "10以下"
elsif num <= 0
  puts "0以下"  # ← num が -1 でも「10以下」に引っかかってここに来ない
end

# 良い例
if num <= 0
  puts "0以下"
elsif num <= 10
  puts "10以下"
end
```

## 4. 論理演算子

```ruby
&&                             # AND：両方が true のとき true
||                             # OR：どちらか一方が true のとき true
!a                             # NOT：true なら false、false なら true

(a && b) || (!a && !b)         # 「両方 true」または「両方 false」のパターン（一致判定）

talking && (hour < 7 || hour > 20)
                               # boolean 引数をそのまま条件に使える
                               # () で OR の範囲を明示してから && でつなぐ
```

### 短絡評価

```ruby
# && は左辺が false なら右辺を評価しない
# || は左辺が true なら右辺を評価しない
# → エラーになりうる右辺を左辺で守るときに使う
```

## 5. boolean 引数の使い方

```ruby
def calculate_point(point, is_birthday)
  point = point * 5 if is_birthday   # true/false を引数で受け取りそのまま条件に使う
  point
end
```

## 6. % 演算子（モジュロ）と FizzBuzz

```ruby
num % 3 == 0                   # 3で割り切れる（余りが0）= 3の倍数
```

### FizzBuzz の判定順

```ruby
if num % 15 == 0
  puts "FizzBuzz"              # 15の判定を必ず先に書く（3と5の両方に引っかかるため）
elsif num % 3 == 0
  puts "Fizz"
elsif num % 5 == 0
  puts "Buzz"
else
  puts num
end
```

## 7. case / when

`if/elsif` の代わりに使える。選択肢が多いときに読みやすい。

```ruby
case gets.to_i
when 0
  処理A
when 1
  処理B
when 2
  exit
else
  puts "無効な値です"
end
```

### case の中での return

```ruby
def menu(input)
  case input
  when 3
    complete(total_price)
  when 4
    return                       # case の中でも return でメソッドを抜けられる
  end
end
```

## 8. ランク分けパターン

**大きい方から順に判定する**のが重要（小さい方から書くと誤判定になる）。

```ruby
if total >= 300
  rank = "A"
elsif total >= 200
  rank = "B"
elsif total >= 100
  rank = "C"
else
  rank = "D"
end
```

`total >= 300` を先に書くことで、300以上のときに B や C に誤って入らないようにできる。
