【PHPの主要な文字列操作関数】概説

このガイドでは、よく使われるPHPの文字列操作関数について、それぞれの役割を簡潔に解説します。

==================================================

### `substr`

-   **役割**: 文字列の**一部分を切り出す（substring）**。
-   **使い方**: `substr($str, $start, $length)`
    -   `$str`    : 切り出し元の文字列
    -   `$start`  : 切り出し開始位置（0始まり）
    -   `$length` : 切り出す文字数
-   **例**:
    ```php
    $str = "kitten";
    echo substr($str, 1, 3); //-> "itt"（1番目から3文字）
    echo substr($str, -2);   //-> "en" （末尾から2文字）
    ```

---

### `substr_replace`

-   **役割**: 文字列の**一部分を別の文字列で置き換える**（削除にも使える）。
-   **使い方**: `substr_replace($str, $replacement, $start, $length)`
    -   `$str`         : 元の文字列
    -   `$replacement` : 置き換える文字列（`''` にすると削除）
    -   `$start`       : 置き換え開始位置（0始まり）
    -   `$length`      : 置き換える文字数
-   **例**:
    ```php
    $str = "kitten";
    echo substr_replace($str, '', 0, 1); //-> "itten"（先頭1文字を削除）
    echo substr_replace($str, 'a', 0, 1); //-> "aitten"（先頭1文字を'a'に置換）
    ```

---

### `substr_count`

-   **役割**: 文字列の中に、指定した文字列が**何回出現するかを数える**。
-   **使い方**: `substr_count($str, $search)`
    -   `$str`    : 調べる対象の文字列
    -   `$search` : 数えたい文字列
-   **例**:
    ```php
    $str = "hihi hello hi";
    echo substr_count($str, "hi"); //-> 3
    ```

---

### `strtolower`

-   **役割**: 文字列に含まれるアルファベットを**すべて小文字に変換する**。
-   **使い方**: `strtolower($str)`
-   **例**:
    ```php
    $str = "Hello WORLD";
    echo strtolower($str); //-> "hello world"
    ```

---

### `strlen`

-   **役割**: 文字列の**長さ（文字数）を取得する**。
-   **使い方**: `strlen($str)`
-   **例**:
    ```php
    $str = "Hello";
    echo strlen($str); //-> 5
    ```

---

### `str_ends_with`

-   **役割**: ある文字列が、指定した文字列で**終わっているかどうか**をチェックする（true/false）。
-   **使い方**: `str_ends_with($str, $search)`
    -   `$str`    : 調べる対象の文字列
    -   `$search` : 末尾にあるか確認したい文字列
-   **例**:
    ```php
    $str = "Hello World";
    var_dump(str_ends_with($str, "World")); //-> bool(true)
    var_dump(str_ends_with($str, "Hello")); //-> bool(false)
    ```

---

### `strpos`

-   **役割**: 文字列の中に、指定した文字列が**最初に出現する位置（インデックス）**を返す。見つからない場合は `false` を返す。
-   **使い方**: `strpos($str, $search)`
    -   `$str`    : 調べる対象の文字列
    -   `$search` : 探したい文字列
-   **例**:
    ```php
    $str = "aaacodebbb";
    var_dump(strpos($str, "code")); //-> int(3)（3番目に見つかった）
    var_dump(strpos($str, "xyz"));  //-> bool(false)（見つからなかった）
    ```
-   **注意**: `if ($pos !== false)` で判定する（`if ($pos)` はNG）

---

### `str_contains`

-   **役割**: 文字列の中に、指定した文字列が**含まれているかどうか**をチェックする（true/false）。
-   **使い方**: `str_contains($str, $search)`
    -   `$str`    : 調べる対象の文字列
    -   `$search` : 含まれているか確認したい文字列
-   **例**:
    ```php
    $str = "abcxyz";
    var_dump(str_contains($str, "xyz"));  //-> bool(true)
    var_dump(str_contains($str, ".xyz")); //-> bool(false)
    ```
-   **Rubyとの対応**: Rubyの `include?` に相当。
