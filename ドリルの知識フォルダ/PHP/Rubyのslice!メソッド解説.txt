【解説】Rubyの破壊的メソッド「slice!」について

`slice!`は、文字列や配列から一部分を「切り取って取り除く」ためのメソッドです。
このメソッドを理解する上で最も重要なのは、末尾に `!` (エクスクラメーションマーク) が付いている点です。


### 1. 「!」が付くメソッドは「破壊的メソッド」

Rubyでは、`!` が付くメソッドは「**破壊的メソッド**」と呼ばれます。
これは、「**元のデータ（レシーバ）そのものを直接変更してしまう**」という意味です。

「このメソッドを使うと元のデータが変わっちゃうから、気をつけてね！」というプログラマーへの警告サインだと考えてください。



### 2. `slice!` の具体的な動き

`slice!` は2つのことを同時に行います。

1.  指定された部分を、元の文字列から**完全に取り除きます**。
2.  そして、**取り除いた部分の文字列を返します**（戻り値）。

```ruby
str = "kitten"

# 1番目の文字（インデックスは0）を削除
removed_char = str.slice!(0)

puts "返り値: #{removed_char}" #=> 返り値: k  （取り除かれた文字が返ってくる）
puts "元の変数: #{str}"       #=> 元の変数: itten （元の文字列が変更されてしまっている）
```



### 3. `slice` (非破壊的) との比較

`!` が付かない `slice` メソッドは「非破壊的」です。
これは、元のデータを変更せず、指定された部分をコピーして返すだけです。

```ruby
str = "kitten"

copied_char = str.slice(0)

puts "返り値: #{copied_char}" #=> 返り値: k
puts "元の変数: #{str}"       #=> 元の変数: kitten （元の文字列は一切変わらない）
```



### 4. ドリルのコード解説

```ruby
def missing_char(str, n)
  str.slice!(n - 1)
  puts str
end
```

1.  `missing_char('kitten', 1)` が呼ばれると、`str`は`"kitten"`、`n`は`1`になります。
2.  `str.slice!(n - 1)` は `str.slice!(0)` となり、`"kitten"` の0番目の文字 `'k'` を削除します。
3.  この時点で、変数 `str` の中身そのものが `"itten"` に書き換わります。
4.  次の行の `puts str` は、書き換わった後の `"itten"` を出力します。

このように、`slice!`が元の文字列を直接変更する性質を利用して、問題を解いているわけですね。
