【なぜ`self.author`?】セッター呼び出しとインスタンス変数への直接代入の違い

`initialize`メソッドの中で、なぜ`@author = ...`ではなく`self.author = ...`と書くのか？
これは、Rubyのオブジェクト指向における非常に重要な概念を理解するための鍵となります。

==================================================
1. 結論：これは「メソッド呼び出し」である
==================================================

まず結論から言うと、この2つの書き方は全く違う意味を持ちます。

-   `self.author = "阿部"`
    これは、**セッターメソッド `def author=(value)` を呼び出す**ための、Rubyの特別な書き方（シンタックスシュガー）です。

-   `@author = "阿部"`
    これは、**インスタンス変数 `@author` に直接値を代入する**処理です。

`self.author = "阿部"` と書くと、Rubyは裏側で `self.author=("阿部")` と解釈し、
あなたが手書きした、あるいは`attr_accessor`で作られた以下のセッターメソッドを探して実行します。

```ruby
def author=(new_author)
  @author = new_author
end
```

==================================================
2. なぜ `initialize` の中でセッターを呼ぶのか？
==================================================

「結局どちらもインスタンス変数に値を入れているなら、同じじゃないの？」と思うかもしれません。
しかし、セッターメソッドを呼び出すことには、**「一貫性と安全性を保つ」**という大きなメリットがあります。

例えば、`author`には空の文字列を許可したくない、というルールを追加したとします。
セッターメソッドにバリデーション（検証）ロジックを追加してみましょう。

```ruby
class Article
  def author=(new_author)
    # バリデーションロジック
    if new_author.nil? || new_author.empty?
      puts "エラー：著者名は空にできません。"
      return # 代入せずに処理を終了
    end
    @author = new_author
  end

  def initialize(attributes = {})
    # ここでセッターを呼ぶ！
    self.author = attributes[:author]
  end
end
```

もし`initialize`の中で `@author = attributes[:author]` と直接代入してしまうと、このバリデーションロジックは**完全に無視されてしまいます**。
なので、本来はセッターの役割も持ってる initialize メソッドのセッターの部分だけをあえて分離させてルールを記述する。
そして、initializeメソッド内で「self.ゲッターメソッド」でセッターを呼び出す。

`self.author = attributes[:author]` と書くことで、インスタンスが作られる最初の瞬間から、必ずこのバリデーションロジック（公式な窓口）を通るようになります。
これにより、不正なデータを持つインスタンスが作られるのを防ぐことができるのです。

==================================================
まとめ
==================================================

-   **`self.author = ...` （セッター呼び出し）**
    -   **推奨される書き方。**
    -   公式な窓口（セッターメソッド）を通るため、バリデーションなどのロジックを一元化できる。
    -   コードの安全性が高まり、仕様変更にも強くなる。

-   **`@author = ...` （直接代入）**
    -   裏口から直接インスタンス変数を書き換える行為。
    -   セッターに書かれたロジックを無視するため、意図しないバグの原因になりやすい。
    -   通常は、そのクラスの外部からは実行できず、内部でのみ可能。
