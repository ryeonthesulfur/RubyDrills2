【PHPのprivateキーワード（アクセス修飾子）とは？】

`private $name;` という一行は、クラスの設計において非常に重要な「カプセル化（隠蔽）」という考え方を実現するためのものです。

この一行を2つのパーツに分解して見ていきましょう。

1.  **`private`**: アクセス修飾子
2.  **`$name`**: プロパティ（インスタンス変数）

==================================================
1. `private` : 「関係者以外立ち入り禁止」の札
==================================================

`private`は「アクセス修飾子」の一つで、そのプロパティ（変数）やメソッドに、どこからアクセスできるかを制限する役割を持ちます。

`private`が付いていると、そのプロパティは**そのクラスの内部からしかアクセスできなくなります。**

`Student`クラスで例えると、`$name`は`Student`クラスの「プライベートルーム」のようなものです。

-   **OK**: `setName()`や`introduce()`のように、同じクラスに所属するメソッドは、このプライベートルームに自由に出入りして`$name`を読み書きできます。
-   **NG**: クラスの外のコードが `$student->name = "鈴木";` のように、プライベートルームに直接侵入して値を書き換えようとすると、PHPが「アクセス権がありません！」とエラーを出します。

### なぜ隠す必要があるのか？

データを`private`で保護（カプセル化）することで、予期せぬ場所からデータが書き換えられてしまうのを防ぎ、クラスの安全性を高めることができます。

例えば、「名前は必ず3文字以上にしてください」というルールを設けたい場合、`setName()`メソッドの中で文字数チェックを行うことができます。もし`$name`が`private`でなければ、誰でも自由に短い名前を直接代入できてしまい、ルールが意味をなさなくなってしまいます。

==================================================
2. `$name` : 個々のインスタンスが持つデータ
==================================================

`$name`は、クラスの「プロパティ」（Rubyでいう**インスタンス変数 `@name`**）を宣言しています。

これは、`new Student()`によって作られる個々の学生インスタンスが、それぞれ自分の名前を保管するための「データボックス」です。

-   山田さんのインスタンスは、`$name`ボックスに「山田太郎」を保管します。
-   鈴木さんのインスタンスは、`$name`ボックスに「鈴木花子」を保管します。

このように、インスタンスごとに独立したデータを保持するのがプロパティの役割です。

==================================================
まとめ
==================================================

`private $name;`

この一行は、

**「`Student`クラスから作られる個々のインスタンスは、`$name`という名前のデータボックスを持つ。ただし、このボックスは`private`（非公開）なので、中身の読み書きは`Student`クラス内部のメソッドを通してのみ行うこと」**

という、厳格なルールを宣言しているのです。

```php
class Student {
    private $name; // このクラスの中からしかアクセスできない、名前を保管する場所

    // privateな$nameに値をセットするための「公式な窓口」
    public function setName($name) {
        $this->name = $name;
    }
}
```
