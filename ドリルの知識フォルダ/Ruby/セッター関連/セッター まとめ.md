## 1. セッターとは何か

**セッター** とは、インスタンス変数に値をセットするためのメソッドのこと。

```ruby
# 手書きのセッター
def author=(new_author)
  @author = new_author
end
```

これを定義しておくと、外からこう書いて値をセットできる。

```ruby
article.author = "阿部"
```

ちなみに **ゲッター** は逆で、中の値を読み取るためのメソッド。

```ruby
# 手書きのゲッター
def author
  @author
end

article.author  #=> "阿部"
```

---

## 2. `attr_accessor` が裏でやっていること

毎回手書きするのは面倒なので、`attr_accessor` を使うと自動生成してくれる。

```ruby
attr_accessor :author
```

これは内部的に以下の2つを自動で定義しているだけ。

```ruby
def author       # ゲッター（読み取り）
  @author
end

def author=(v)   # セッター（書き込み）
  @author = v
end
```

`:author` はシンボル（ただの名前ラベル）で、「この名前でゲッターとセッターを作ってね」という指示を渡しているだけ。

---

## 3. `self.author =` と `@author =` の違い

ここが一番混乱しやすいポイント。

```ruby
self.author = "阿部"   # セッターメソッドを呼び出している
@author = "阿部"       # インスタンス変数に直接代入している
```

**`@author =`（直接代入）** は、インスタンス変数に裏口から直接書き込む。

**`self.author =`（セッター呼び出し）** は、`def author=(v)` というメソッドを呼び出している。`=` がついた変数への代入のように見えるが、実はメソッド呼び出し。

---

## 4. セッターにルールを追加する方法

`attr_accessor` が自動生成するセッターは、ただ値を入れるだけでルールを追加できない。  
ルールを加えたい場合は、**セッターを手書きで上書きする**。

```ruby
class Article
  attr_reader :author, :title  # ゲッターは自動生成におまかせ

  # authorだけ、ルールを加えて手書きセッターを定義
  def author=(new_author)
    raise "著者名は空にできません" if new_author.nil? || new_author.empty?
    @author = new_author
  end

  def initialize(author, title)
    self.author = author  # ← セッターメソッドを呼んでいる（ルールが通る）
    @title = title        # ← titleはルールなしなので直接代入でOK
  end
end
```

`initialize` の中で `self.author =` を使っているのは、**インスタンスを作る瞬間からルールを通したい**から。  
`@author =` と直接代入してしまうと、手書きセッターのルールが完全に無視されてしまう。

### まとめ

| 書き方 | 動き |
|:-------|:-----|
| `@author = "阿部"` | 裏口から直接代入。セッターのルールは無視される |
| `self.author = "阿部"` | セッターメソッドを呼ぶ。ルールがある場合はそこを必ず通る |
| `attr_accessor :author` | ゲッター＋シンプルなセッターを自動生成。ルール追加はできない |
| `def author=(v) ... end` | ルールを入れたいときは手書きでセッターを上書きする |
