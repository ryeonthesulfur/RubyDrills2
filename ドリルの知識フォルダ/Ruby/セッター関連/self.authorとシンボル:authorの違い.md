# `self.author` の `author` はメソッド？ シンボル？ 徹底解説

「`self.author` の `author` はゲッターメソッドの `author`？それともシンボルの `:author` のこと？」

これは非常に鋭い質問です。結論から言うと：

- `self.author` の `author` は、**ゲッターメソッド `def author` のこと**
- `self.author = ...` の `author` は、**セッターメソッド `def author=` を呼び出すためのキーワード**

どちらも、シンボル `:author` そのものではありません。

## 1. シンボル `:author` の役割：「メソッドを作るための設計図の名前」

シンボル `:author` は、それ自体がメソッドなのではなく、**「メソッドやハッシュのキーに付ける、ただの名前（ラベル）」** だと考えてください。

```ruby
attr_accessor :author
```

このコードは、「Rubyさん、`:author` という名前のラベルを使って、ゲッターとセッターのメソッドを自動で作ってください」という**お願い**です。

このお願いを受けて、Rubyは内部的に以下の2つのメソッドを生成します。

```ruby
# :author というシンボルから作られたゲッターメソッド
def author
  @author
end

# :author というシンボルから作られたセッターメソッド
def author=(new_author)
  @author = new_author
end
```

---

## 2. `self.author` の役割：「作られたメソッドを呼び出すスイッチ」

`self.author` や `self.author = ...` は、上記で**作られたメソッドを呼び出すためのスイッチ**の役割を果たします。

- `puts self.author`  
  → 「自分自身（`self`）の、`author` という名前の**ゲッターメソッド**を呼び出せ！」という命令

- `self.author = "田中"`  
  → 「自分自身（`self`）の、`author=` という名前の**セッターメソッド**を呼び出せ！」という命令

### `initialize` の中での使われ方

`initialize(attributes = {})` の中の `self.author = attributes[:author]` というコードは、この関係性を非常によく表しています。

```ruby
self.author = attributes[:author]
#    (A)    =       (B)
```

| | 役割 |
|:--|:-----|
| **(A) `self.author`（左辺）** | **セッターメソッド `author=` を呼び出す**スイッチ |
| **(B) `attributes[:author]`（右辺）** | `attributes` というハッシュの中から、**`:author` というシンボルをキーにして**値を取り出す |

このように、左辺と右辺で元は同じ `:author` というシンボルから派生したものが使われていますが、その役割は「メソッド呼び出しのキーワード」と「ハッシュのキー」として、全く異なっています。

## まとめ

| 段階 | 要素 | 役割 |
|:-----|:-----|:-----|
| ① | シンボル `:author` | メソッドを作るための「**名前のラベル**」 |
| ② | `attr_accessor` | そのラベルを元に `def author` と `def author=` という「**メソッドの実体**」を作る |
| ③ | `self.author` / `self.author = ...` | 作られたメソッドの実体を呼び出す「**スイッチ**」 |

この3段階の関係性を理解すると、Rubyのクラスの動きがよりクリアになります。
