# `slice!` メソッドの解説（破壊的メソッド）

`slice!` は、文字列や配列から一部分を「切り取って取り除く」ためのメソッド。  
このメソッドを理解する上で最も重要なのは、末尾に `!` が付いている点。

---

## 1. `!` が付くメソッドは「破壊的メソッド」

Rubyでは、`!` が付くメソッドを**破壊的メソッド**と呼ぶ。  
「**元のデータそのものを直接変更してしまう**」という意味で、プログラマーへの警告サイン。

---

## 2. `slice!` の具体的な動き

`slice!` は2つのことを同時に行う。

1. 指定された部分を、元の文字列から**完全に取り除く**
2. 取り除いた部分の文字列を**返す**（戻り値）

```ruby
str = "kitten"

removed_char = str.slice!(0)  # インデックス0（先頭）の文字を削除

puts "返り値: #{removed_char}"  #=> 返り値: k       （取り除かれた文字が返ってくる）
puts "元の変数: #{str}"         #=> 元の変数: itten  （元の文字列が変更されている）
```

---

## 3. `slice`（非破壊的）との比較

`!` が付かない `slice` は非破壊的。元のデータを変更せず、指定部分をコピーして返すだけ。

```ruby
str = "kitten"

copied_char = str.slice(0)

puts "返り値: #{copied_char}"  #=> 返り値: k
puts "元の変数: #{str}"        #=> 元の変数: kitten  （元の文字列は変わらない）
```

| | `slice` | `slice!` |
|:--|:--------|:---------|
| 元のデータ | 変わらない | **変わる** |
| 戻り値 | 切り出した部分 | 切り取った部分（同じ） |

---

## 4. ドリルのコード解説

```ruby
def missing_char(str, n)
  str.slice!(n - 1)
  puts str
end
```

`missing_char('kitten', 1)` が呼ばれたときの動き：

1. `str` は `"kitten"`、`n` は `1`
2. `str.slice!(n - 1)` → `str.slice!(0)` となり、`"kitten"` の0番目の `'k'` を削除
3. この時点で `str` の中身が `"itten"` に書き換わる
4. `puts str` で書き換わった後の `"itten"` を出力する

`slice!` が元の文字列を直接変更する性質を利用して、指定した位置の文字を消した残りを出力している。
