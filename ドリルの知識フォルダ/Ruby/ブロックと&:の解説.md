# ブロックと &: の解説

---

## ブロックとは

メソッドに渡す「処理のかたまり」のこと。`{ }` または `do ~ end` で書く。

```ruby
["1", "2", "3"].map { |x| x.to_i }
#               ↑↑↑↑↑↑↑↑↑↑↑↑↑↑↑↑
#               これがブロック
```

---

## `|x|` とは

配列の要素が1つずつ入る箱。`map` が配列から要素を取り出して `|x|` に渡してくれる。

```ruby
["1", "2", "3"].map { |x| x.to_i }
# 1回目: x に "1" が入る → "1".to_i → 1
# 2回目: x に "2" が入る → "2".to_i → 2
# 3回目: x に "3" が入る → "3".to_i → 3
# 結果: [1, 2, 3]
```

`x` は変数名なので何でもいい。`|n|` でも `|num|` でも動く。

---

## `|x|` が不要なとき

配列の要素を使わない場合は `|x|` を書かなくていい。

```ruby
3.times.map { gets.to_i }
```

これは配列の要素を取り出しているのではなく、キーボードから新しく入力を受け取っている。
`gets` が入力を持ってくるので `|x|` は不要。

```ruby
# 3回キーボード入力を受け取って配列にする
# 入力: "10" → 10
# 入力: "20" → 20
# 入力: "30" → 30
# 結果: [10, 20, 30]
```

---

## `{ }` と `(&:to_i)` の違い

`map(&:to_i)` は `map { |x| x.to_i }` の短縮形で、全く同じ意味。

```ruby
["1", "2", "3"].map { |x| x.to_i }  # 普通の書き方
["1", "2", "3"].map(&:to_i)          # 短縮形（同じ結果）
```

`gets.to_i` は「`gets`」と「`to_i`」の2つのメソッドの組み合わせなので `&:` では書けない。
`{ }` に直接書くしかない。

```ruby
&:to_i      # OK（メソッド1つ）
&:gets.to_i # NG（そんな書き方はない）
```

---

## `{ }` はハッシュじゃないの？

使う場所によって意味が変わる。

```ruby
h = { "name" => "taro" }   # 変数に代入 → ハッシュ
array.map { |x| x.to_i }   # メソッドの直後 → ブロック
```

---

## まとめ

```ruby
# パターン1: 配列の要素を変換する（|x| あり）
["1", "2", "3"].map { |x| x.to_i }  #=> [1, 2, 3]
["1", "2", "3"].map(&:to_i)          #=> [1, 2, 3]  ← 上と同じ

# パターン2: 1行入力をスペースで分割して変換する
gets.split(" ").map(&:to_i)          # "1 2 3" → [1, 2, 3]

# パターン3: キーボードから複数回入力を受け取る（|x| なし）
3.times.map { gets.to_i }            # 3回入力 → 整数の配列
```
