# `rand` メソッドの解説

---

## 書き方

```ruby
rand(n)   # 0 以上 n 未満の整数をランダムに返す
rand      # 引数なし：0.0 以上 1.0 未満の小数を返す
```

---

## コード例

```ruby
rand(10)  #=> 0〜9 のどれかの整数
rand(6)   #=> 0〜5 のどれかの整数
rand      #=> 0.0〜1.0 未満の小数（例: 0.5423...）
```

---

## ポイント

- 引数 `n` を渡すと、**0 以上 n 未満**の整数を返す（`n` 自体は含まない）
- 下限は常に `0` 固定
- `1〜6` のサイコロを作りたい場合は `+1` する必要がある

```ruby
dice = rand(6) + 1  # rand(6) は 0〜5 なので +1 して 1〜6 にする
puts dice           #=> 1〜6
```
