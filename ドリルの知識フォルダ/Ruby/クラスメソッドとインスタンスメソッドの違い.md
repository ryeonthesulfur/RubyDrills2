## 1. 登場人物の紹介（クラスとインスタンス）

まず、基本となる2つの登場人物を理解しましょう。

- **クラス（Class）**：設計図です。例えば `Student` というクラスは、「学生」という概念の設計図になります。「学生は名前（`@name`）を持つ」といった情報を定義します。

- **インスタンス（Instance）**：設計図から作られた「実体」です。`student = Student.new` のようにして作られた `student` は、山田さんや鈴木さんのような、具体的な一人の学生を表します。インスタンスはそれぞれが独立したデータ（名前など）を持つことができます。

---

## 2. インスタンスメソッド（個人の能力）

インスタンスメソッドは、**インスタンス（個々の学生）が使う能力**です。

```ruby
class Student
  # インスタンスメソッド
  def set_name(name)
    @name = name
  end

  # インスタンスメソッド
  def introduce
    puts "私の名前は#{@name}です。"
  end
end

student = Student.new

# initialize じゃないので、データを入れる際はこのように分けて記述する
student.set_name("山田太郎")

student.introduce #=> 私の名前は山田太郎です。
```

### 特徴

| 項目 | 内容 |
|:-----|:-----|
| 所属 | インスタンス（個々の実体） |
| 役割 | `@name` などのインスタンス変数を操作・使用する。山田さんの `introduce` は山田さんの名前を言い、鈴木さんの `introduce` は鈴木さんの名前を言う |
| 呼び出し方 | `インスタンス.メソッド名` |
| 定義方法 | `def メソッド名`（普通に定義） |

---

## 3. クラスメソッド（組織全体の能力）

クラスメソッドは、**クラス（組織全体）が使う能力**です。個々の学生ではなく、「学生という概念全体」に関する能力です。

```ruby
class Student
  # クラスメソッド
  def self.description
    puts "このクラスは学生の設計図です。"
  end
end

Student.description #=> このクラスは学生の設計図です。
```

### 特徴

| 項目 | 内容 |
|:-----|:-----|
| 所属 | クラス（設計図）そのもの |
| 役割 | クラス全体に関わる処理を行う。例：「今までに何人の学生インスタンスが作られたか」を記録・表示する。**個々のインスタンスのデータ（`@name` など）は知らないし、使えない** |
| 呼び出し方 | `クラス名.メソッド名` |
| 定義方法 | `def self.メソッド名`（`self.` を付けて定義） |

---

## 4. なぜエラーが起きたのか？

以下のコードがエラーになる理由を確認しましょう。

```ruby
class Student
  def self.introduce  # クラスメソッドとして定義されている
    puts "私の名前は#{@name}です。"  # クラスメソッド内からインスタンス変数を使おうとしている
  end
end

student = Student.new
student.introduce  # インスタンスからクラスメソッドを呼び出そうとしている
```

エラーの原因は、以下の3つの矛盾点です。

**① 定義の矛盾**  
`self.introduce` は「クラス全体」の能力として定義されています。しかし、その中で「個人の名前（`@name`）」を使おうとしています。クラス全体には特定の個人の名前はないため、`@name` は `nil`（空っぽ）になってしまいます。

**② 呼び出しの矛盾**  
`student.introduce` は「個人の能力」として `introduce` を呼び出そうとしています。しかし `self.introduce` は「クラス全体の能力」なので、個人の `student` は「そんな能力は知らない」となります。これが `NoMethodError` の直接的な原因です。

**③ 役割の矛盾**  
「自己紹介（introduce）」は、山田さんや鈴木さんといった「個人（インスタンス）」が行うべき行動です。「学生という概念全体（クラス）」が自己紹介するのは不自然ですよね。

### 正しいコード

「自己紹介」は個人の能力なので、`self.` を外してインスタンスメソッドとして定義するのが正しい姿です。

```ruby
class Student
  def introduce
    puts "私の名前は#{@name}です。"
  end
end
```

この修正により、`student.introduce` という呼び出しで、その `student` が持つ `@name` を使って正しく自己紹介できるようになります。
