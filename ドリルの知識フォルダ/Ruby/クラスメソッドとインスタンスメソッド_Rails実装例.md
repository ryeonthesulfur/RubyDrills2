# クラスメソッドとインスタンスメソッド — Rails での実装イメージ

---

## 見分け方

| 呼び方 | 種類 | 使う場面 |
|:-------|:-----|:---------|
| `User.all` | クラスメソッド | クラス全体に対する操作 |
| `user.name` | インスタンスメソッド | 特定の1件に対する操作 |

`User.` で始まる → クラスメソッド  
`user.` で始まる → インスタンスメソッド

---

## クラスメソッドが使われる場面（Rails）

「特定の1人」ではなく「Userというクラス全体」に対して呼ぶ。

```ruby
User.all              # 全ユーザーを取得
User.find(1)          # id=1 のユーザーを取得
User.where(age: 20)   # 条件に合うユーザーを取得
User.new(user_params) # 新しいユーザーのインスタンスを作る
```

---

## インスタンスメソッドが使われる場面（Rails）

「特定の1人」に対して呼ぶ。

```ruby
user = User.find(1)
user.name    # その人の名前を取得
user.save    # その人のデータを保存
user.update(name: "taro")  # その人のデータを更新
user.destroy # その人のデータを削除
```

---

## コントローラーでの流れ（ユーザー登録の例）

```ruby
def create
  user = User.new(user_params)  # クラスメソッド → インスタンスを作る
  user.save                     # インスタンスメソッド → DBに保存する
end
```

1. `User.new` でインスタンスを作る（クラスメソッド）
2. `user.save` でそのインスタンスを保存する（インスタンスメソッド）

---

## ポイント

- Rails のモデルは `initialize` を自分で書かなくていい。`User.new(name: "taro")` と書けば Active Record が裏でやってくれる。
- `attr_accessor` も自分で書かなくていい。カラム名に対してゲッター・セッターが自動で生える。
- ただし「仕組みを知っている」かどうかで、エラーのときに「インスタンス変数がないから読めない」と気づけるかが変わる。
