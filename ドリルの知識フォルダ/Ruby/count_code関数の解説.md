# `count_code` 関数の解説

---

## 問題の目的

与えられた文字列の中に `"code"` という単語が、左から**何文字目**に出てくるかを調べて出力する。

ポイントは「何文字目」という数え方のズレ。

| 数え方 | 開始 | 例：先頭の文字 |
|:-------|:----:|:--------------|
| 人間 | 1から | 1文字目 |
| `index`（プログラム） | 0から | 0番目 |

このズレを吸収するために、`index` が返した位置に `+1` する必要がある。

---

## 元のコードの問題点

```ruby
def count_code(str, count)
  str.index(str, [])
end
```

**① 引数が多い**  
`count` という引数を受け取っているが、必要なのは検索対象の文字列 `str` だけ。

**② `index` の使い方が間違っている**  
- 第1引数には**探したい文字列**（`"code"`）を指定すべきだが、`str`（文字列全体）が指定されている。
- 第2引数には検索開始**位置（数値）**を指定できるが、`[]`（空の配列）が渡されておりエラーになる。

---

## 正しい実装

```ruby
def count_code(str)
  pos = str.index("code")  # "code" が最初に出現する位置（0始まり）を探す

  if pos                    # nil（見つからなかった）でなければ実行
    puts pos + 1            # 1から数える「何文字目」に変換して出力
  end
end

count_code("codexxcode")  #=> 1  （"code" は0番目 → 0 + 1）
count_code("aaacodebbb")  #=> 4  （"code" は3番目 → 3 + 1）
count_code("cozexxcode")  #=> 7  （"code" は6番目 → 6 + 1）
```

### ポイント

- `str.index("code")` は `"code"` が最初に見つかった位置を整数で返す。見つからなければ `nil` を返す。
- `if pos` は `pos` が `nil` でなければ真。Rubyでは `nil` は偽として扱われるので、これだけで nil チェックができる。
- `pos + 1` で人間が読む「何文字目」の数え方に変換する。
