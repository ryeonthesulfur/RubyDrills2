# `times` メソッドと `* 3` の違い

結果は同じに見えることがありますが、**意味が違います。**

---

## `* 3`（文字列の繰り返し）

```ruby
puts "lo" * 3  #=> "lololo"（文字列を3回つなげて1行で出力）
```

- `"lo" * 3` は `"lololo"` という**1つの文字列を生成**して、それを `puts` で出力する。
- 出力は **1行**。

---

## `3.times`（ループ）

```ruby
3.times { puts "lo" }
# => lo
#    lo
#    lo
#    （3行に分かれて出力）
```

- `puts "lo"` という**処理を3回繰り返す**。
- 出力は **3行**。

---

## どちらを使うべきか？

出力例が `'lololo'`（1行）の場合は、`* 3` の方が正確です。

`3.times` で1行にしたい場合は `print` を使えばできますが、`* 3` の方がシンプルです。
