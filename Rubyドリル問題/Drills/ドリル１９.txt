■ 各桁の取り出し
  num / 100                     → 百の位
  num / 10 % 10                 → 十の位（10で割った後、10の余りを取る）
  num % 10                      → 一の位

■ 10の倍数との距離を求めるパターン
  total % 10                    → 合計値の一の位 = 直近の10の倍数から右に何個ずれているか
  num <= 2                      → 右に2以内 → True
  num >= 8                      → 左に2以内（10 - 8 = 2）→ True
  num <= 5                      → 右が近い → num がそのまま差
  else（num 6〜7）              → 左が近い → 10 - num が差

■ こつ：「近い方の距離」の考え方
  % 10 の結果が 0〜9 のどこかに来る
  5 より小さければ右（足し算方向）が近い
  5 より大きければ左（引き算方向）が近い → 10 - num で距離を出す

■ PHP 対応メモ
  num / 100（整数除算）         → PHP では intdiv($num, 100) か (int)($num / 100)
  % 演算子                      → PHP でも同じ書き方で動く

問題.1
3桁の正の整数を入力します。その整数の「百の位・十の位・一の位の和」について、
10の倍数（10,20,30...）からの差が
・2以内であるときは"True"
・それ以外は"10の倍数との差は○です"
と表示されるようにしましょう。

出力例：
near_ten(117)→True
near_ten(123)→10の倍数との差は4です
near_ten(111)→10の倍数との差は3です

百の位・十の位・一の位の和が6などの時に、「10の倍数との差は6です」と出力せずに、
「10の倍数との差は4です」と10の倍数から近い方の差を出力するようにしてください。また、0も10の倍数に含むものとします。

def near_ten(num)
    total = (num/100) + (num/10 % 10) + (num % 10)
    num = total % 10
    if num <= 2 || num >= 8
     puts "True"
    elsif num <= 5
     puts "10の倍数との差は#{num}です"
    else
     puts "10の倍数との差は#{10 - num}です"
end


puts "3桁の正の整数を入力してください。"
input = gets.to_i
near_ten(input)



【PHP版】

function near_ten($num) {
    $total = ($num/100) + ($num/10 % 10) + ($num % 10);
    $num = $total % 10;
    if ($num <= 2 || $num >= 8) {
        echo "True\n";
    } elseif ($num <= 5) {
        echo "10の倍数との差は{$num}です。\n";
    } else {
        $diff = 10 - $num;
        echo "10の倍数との差は{$diff}です。\n";
    }
}




なんでさらに１０割るんだろう

「10の倍数からの距離」を出すためです。

例えば合計が 13 の場合：
13 % 10 = 3  ← 10の倍数（10）から3離れている

合計が 27 の場合：
27 % 10 = 7  ← 10の倍数（20）から7離れている
つまり % 10 することで「直近の10の倍数から右に何個ずれてるか」 が出ます。

それを使って：
num <= 2 → 右に2以内 → True
num <= 5 → 右より左が近い → そのまま num が差
num >= 8 → 左に2以内 → True
else → 左が近い → 10 - num が差
