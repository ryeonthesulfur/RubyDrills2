■ 配列の要素カウント
  配列.count(値)                → 配列内に指定した値が何個あるか返す

■ 10の倍数への近さを判定するパターン
  num % 10                      → 10で割った余り = 一の位の値
  num % 10 <= 2                 → 10の倍数から2以内（例: 10, 11, 12）
  num % 10 >= 8                 → 10の倍数から2以内の手前側（例: 18, 19, 20）
  両方を || でつなぐ            → 「差が2以内」を表現する

■ こつ：一の位で考える
  10の倍数との距離 = 一の位が 0,1,2 か 8,9 かで判定できる

■ PHP 対応メモ
  配列.count(9)                 → PHP では count(array_keys($nums, 9))
                                   array_keys で値が9のキーを取得 → count でその数を数える

【Rubyドリル 問題 34 特定の数値の個数を算出するプログラムの実装】


問題.1
概要
本ドリルでは、複数の数字が格納されている配列に、「9」が何個含まれているかを出力するプログラムを実装します。

問題
以下の要件を満たすarray_count9メソッドを実装しましょう。

配列の中の数字に対して、9の個数を数える
数えた9の個数を出力する


雛形
def array_count9(nums)
  # 処理を記述
end

# 呼び出し例
array_count9([1, 2, 9]) 
出力例
array_count9([1, 2, 9]) → 配列の中には9が1個です
array_count9([1, 9, 9]) → 配列の中には9が2個です
array_count9([1, 9, 9, 3, 9]) → 配列の中には9が3個です

ヒント
countメソッドを使用しましょう。

count
countメソッドは、引数に指定した数字に一致するものの個数を数え、その結果を返すメソッドです。



ary = [1, 2, 4, 2]

ary.count(2)
 # => 2


【Ruby版】

def array_count9(nums)
  puts "配列の中には9が#{nums.count(9)}個です"
end


# 呼び出し例
array_count9([1, 2, 9]) 



【PHP版】

function array_count9($nums) {
    $count = count(array_keys($nums, 9));
    echo "配列の中には9が{$count}個です";
}

【Y_Rubyドリル 問題 35 if,else問題】  難しい

問題.1
2桁の正の整数を入力します。その整数が、
10の倍数（10,20,30...）からの差が
2以内であるときはTrue
それ以外はFalseと出力するメソッドを作りましょう。

出力例：
near_ten(12)→True
near_ten(17)→False
near_ten(19)→True


def near_ten(num)
  # 処理を記述
end

# 呼び出し例
near_ten(12)
near_ten(17)
near_ten(19)



def near_ten(num)
  if num % 10 <= 2 || num % 10 >= 8
    puts "True"
  else
    puts "False"
  end
end


# 呼び出し例
near_ten(12)
near_ten(17)
near_ten(19)
