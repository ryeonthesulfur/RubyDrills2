■ 範囲を指定した繰り返し
  (1..max_num).each do |num|    → 1 から max_num までを順に処理する
  (開始..終了)                  → 範囲演算子（終了値を含む）

■ 文字列の末尾取得
  str.slice(-3..-1)             → 末尾から3文字目〜末尾を取り出す（負のインデックス範囲指定）
  str.slice(-n..-1)             → 末尾 n 文字を取り出すパターン

■ 大文字・小文字変換
  str.downcase                  → 全て小文字に変換
  str.upcase                    → 全て大文字に変換

■ 末尾一致の判定
  str.end_with?("abc")         → 文字列が "abc" で終わるか（true/false）
                                   ※ slice で自前実装するより簡潔でプロ向きな書き方

■ 文字列の長さ
  str.length                    → 文字列の文字数を返す

■ PHP 対応メモ
  str.downcase                  → PHP では strtolower($str)
  str.length                    → PHP では strlen($str)
  str.slice(-n..-1)             → PHP では substr($str, -$n)
  str.end_with?("abc")         → PHP では str_ends_with($str, "abc")（PHP 8.0以降）
  (int)fgets(STDIN)             → PHP での整数入力の受け取り方（intval の代わりにキャスト）

問題.1

例） 1, 2, Fizz, 4, Buzz, Fizz ,,,,

このFizzBuzzを再現できるメソッドを作成してください。
ただし、いくつまでカウントするか、引数で指定できるものとします。

  if

  end
end

ヒント
 範囲を指定して繰り返し
範囲を指定して繰り返しをする場合は、範囲演算子(..)を使用しましょう。
以下のように使用します。

1
(開始する値..終了する値）
具体的には以下のように使用できます。


# 1～6までの範囲を指定して、繰り返し表示
(1..6).each do |num|
  puts num
end



def fizzbuzz(max_num)
  (1..max_num).each do |num|
  if (num % 3 == 0) && (num % 5 == 0)
    puts "FizzBuzz"
  elsif num % 3 == 0
    puts "Fizz"
  elsif num % 5 == 0
    puts "Buzz"
  else
    puts num
  end
 end
end


puts 'いくつまで数えますか？'
num = gets.to_i
fizzbuzz(num)


【PHP版】

function fizzbuzz($max_num) {
    for ($i = 1; $i <= $max_num; $i++) {
        if ($i % 15 == 0) {
            echo "FizzBuzz\n";
        } elseif ($i % 3 == 0) {
            echo "Fizz\n";
        } elseif ($i % 5 == 0) {
            echo "Buzz\n";
        } else {
            echo $i . "\n";
        }
    }
}

echo "いくつまで数えますか？\n";
$num = (int)fgets(STDIN);
fizzbuzz($num);

【Rubyドリル 問題 31 2つの文字列の末尾に対して一致・不一致を判断するプログラムの実装】


問題.1
概要
本ドリルでは、どちらかがもう一方の文字列の末尾にある場合はFalseを出力するプログラムを実装します。

問題
以下の要件を満たすend_otherメソッドを実装しましょう。

メソッドの引数に、任意の2つの文字列を指定する。
引数に指定された2つの文字列のうち、どちらかがもう一方の文字列の末尾にある場合は、Trueを出力する
上記を満たせていない場合は、Falseを出力する
入力された文字が大文字でも小文字でも、同一の文字として処理を行う

end

【あなたの完成させたコード (slice版)】
このコードは問題の要件をすべて満たしており、ロジックとして完全に正解です。

def end_other_slice(a, b)
  a_down = a.downcase
  b_down = b.downcase
  b_length = b_down.length
  a_length = a_down.length
  
  if a_down.slice(-b_length..-1) == b_down
    puts "True"
  elsif b_down.slice(-a_length..-1) == a_down
    puts "True"
  else
    puts "False"
  end
end



【PHP版 (slice版)】

function end_other_php_slice($a, $b) {
    $a_down = strtolower($a);
    $b_down = strtolower($b);
    $b_length = strlen($b_down);
    $a_length = strlen($a_down);

    // substr($string, -length) で末尾から指定した長さの文字列を取得します
    if (substr($a_down, -$b_length) === $b_down) {
        echo "True\n";
    } elseif (substr($b_down, -$a_length) === $a_down) {
        echo "True\n";
    } else {
        echo "False\n";
    }
}



# こちらは、プロの開発現場でよく使われる、よりシンプルで読みやすい書き方です。
# あなたが組み立てたロジックを、Rubyが用意してくれた `end_with?` という一言で表現しています。

def end_other_idiomatic(a, b)
  a_lower = a.downcase
  b_lower = b.downcase

  if a_lower.end_with?(b_lower) || b_lower.end_with?(a_lower)
    puts "True"
  else
    puts "False"
  end
end



【PHP版 (str_ends_with版)】

function end_other_php_idiomatic($a, b) {
    $a_lower = strtolower($a);
    $b_lower = strtolower($b);  // 文字列を小文字に変換

    if (str_ends_with($a_lower, $b_lower) || str_ends_with($b_lower, $a_lower)) {
        echo "True\n";
    } else {
        echo "False\n";
    }
}

# 呼び出し例
end_other_idiomatic('Hiabc', 'abc') 
end_other_idiomatic('AbC', 'HiaBc')
end_other_idiomatic('abc', 'HaIoBc')
