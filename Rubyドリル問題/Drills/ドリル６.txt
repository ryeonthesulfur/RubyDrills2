■ 条件分岐
  if / elsif / else / end       → 複数条件の分岐（条件は上から順に評価される）
  条件を書く順番が重要          → 狭い条件（0以下）を先に、広い条件（10以下）を後に書く

■ 論理演算子
  &&                            → AND：両方が true のとき true
  ||                            → OR：どちらか一方が true のとき true
  短絡評価                      → 左辺で結果が確定した時点で右辺は評価しない
                                   （&& は左辺が false なら右辺を見ない）
                                   （|| は左辺が true なら右辺を見ない）

■ 入力の受け取り
  gets.to_i                     → 入力を整数として受け取る

■ 入れ子配列の each
  配列.each do |name, prices|   → 内側の配列を2つの変数に自動で分解して受け取れる
  fruit[0] / fruit[1]           → インデックスで要素を取り出す方法（別解）
  sum = 0 をループの外に        → 各果物ごとに合計をリセットするために外側ループの中で初期化

■ 配列の合計
  prices.sum                    → 配列の全要素を合計する（Ruby）
  sum += price                  → ループで1つずつ足していく基本パターン

■ PHP 対応メモ
  elsif                         → PHP では else if（または elseif）
  配列.sum                      → PHP では array_sum($配列)
  each do |name, prices|        → PHP では foreach ($fruit as $fruit) で $fruit[0], $fruit[1] を使う
  fgets(STDIN)                  → PHP での標準入力の受け取り方

【Rubyドリル 問題 12 条件分岐】



問題.1
ターミナルから数字を入力して、数字に応じて以下のように出力するプログラムを書いてください。

10以下なら10以下の数字です
10より大きい数値なら10より大きい数字です
10以下でかつ0以下なら0以下の数字です




【Ruby版】

puts "数字を入力してください"
input = gets.to_i

if input <= 0
  puts "0以下の数字です"
elsif input <= 10
  puts "10以下の数字です"
else
  puts "10より大きい数字です"
end



【PHP版】

echo "数字を入力してください\n";
$input = fgets(STDIN);

// PHPの `else if` は `if` のブロックの外に書くのが正しい構文です。
if ($input <= 0) {
    echo "0以下の数字です\n";
} else if ($input <= 10) {
    echo "10以下の数字です\n";
} else {
    echo "10より大きい数字です\n";
}

Y_Rubyドリル 問題 13 eachの入れ子


問題.1
以下のように、果物の名前と値段が入った配列があります。
この配列を用いて、果物の名前とそれぞれの合計額が出力される
コードを記述してください。


fruits_price = [["apple", [200, 250, 220]], ["orange", [100, 120, 80]], ["melon", [1200, 1500]]]


（出力）
appleの合計金額は670円です
orangeの合計金額は300円です
melonの合計金額は2700円です

確かに、この問題は配列の中にさらに配列が入っている「入れ子」の構造なので、少し難しく感じますよね。でも、一つずつ分解すれば大丈夫です！

ポイントは、`each`でループを回すときに、ブロック変数で受け取る中身をどう扱うかです。

`fruits_price`を`each`で回すと、`["apple", [200, 250, 220]]` という配列が丸ごと渡ってきます。
Rubyでは、これをブロック変数を2つ用意することで、自動的に分解して受け取ることができます。


【Rubyの便利な機能を活用した書き方】
fruits_price = [["apple", [200, 250, 220]], ["orange", [100, 120, 80]], ["melon", [1200, 1500]]]

【Ruby版】
fruits_price.each do |name, prices|
  # 1. eachのブロック変数を2つにすると、配列が自動で分解されて便利
  # 2. .sumメソッドで配列の合計を一行で計算できる
  total = prices.sum
  puts "#{name}の合計金額は#{total}円です"
end




【スクールで習った模範解答の解説】
> スクールではこうだった

ご提示いただいたコードですね。こちらももちろん正解です！
おそらくスクールでは、`.sum` のような便利なメソッドに頼らず、「ループ処理の基本構造」をしっかり理解するために、あえてこの書き方を教えているのだと思います。

こちらのコードは、より丁寧で、プログラミングの基礎的な考え方が詰まった良いコードです。

```ruby
fruits_price.each do |fruit| # ① 外側のループ
  sum = 0                    # ② 合計値のリセット
  fruit[1].each do |price|   # ③ 内側のループ
    sum += price             # ④ 合計値の加算
  end
  puts "#{fruit[0]}の合計金額は#{sum}円です" # ⑤ 結果の出力
end
```

1.  **① 外側のループ**: まず`fruits_price`全体をループし、`fruit`変数に`["apple", [200, 250, 220]]`のような配列が一つずつ入ります。
2.  **② 合計値のリセット**: 次の果物の計算を始める前に、必ず`sum`を`0`に戻しています。これが非常に重要です。
3.  **③ 内側のループ**: `fruit[1]`（値段の配列）を取り出し、その中身を一つずつ`price`変数に入れてループします。
4.  **④ 合計値の加算**: 取り出した`price`を`sum`に足し込んでいきます。
5.  **⑤ 結果の出力**: 内側のループが終わった時点での`sum`と、`fruit[0]`（果物の名前）を出力します。

このように、便利なメソッドの裏側では、このような地道なループ処理が動いている、ということを理解するための素晴らしい教材ですね。




【PHP版】
$fruits_price = [["apple", [200, 250, 220]], ["orange", [100, 120, 80]], ["melon", [1200, 1500]]];

foreach ($fruits_price as $fruit) {
  // $fruitには ["apple", [200, 250, 220]] が入っている
  $name = $fruit[0];   // 0番目が名前
  $prices = $fruit[1]; // 1番目が値段の配列

  $total = array_sum($prices); // array_sum()で配列の合計を計算

  echo "{$name}の合計金額は{$total}円です\n";
}


foreach ($fruits_price as $fruit) {
  $name = $fruit[0];
  $prices = $fruit[1];

  $total = array_sum($prices);
  
  echo "{$name}の合計金額は{$total}円です\n";
}

Y_Rubyドリル 問題 14 if,else問題


問題.2
概要
本ドリルでは、指定された数値の範囲による条件と真偽値による条件を組み合わせて処理を行うプログラムを実装します。

問題
以下の要件を満たす in1to10メソッドを実装しましょう。

第一引数のnumが1以上かつ10以下の範囲であればTrueを出力すること
第二引数のoutside_modeがTrueの場合は、第一引数numが条件範囲外でもTrueを出力すること
それ以外はFalseを出力すること

雛形
def in1to10(num, outside_mode)
  # ここに条件式を記述する
end

# 呼び出し例
in1to10(5,false)
in1to10(11,false) 
in1to10(11,true) 
出力例
in1to10(5,false) →True
in1to10(11,false) →False
in1to10(11,true) →True


【Ruby版】

def in1to10(num, outside_mode)
  if (num >= 1 && num <= 10) || outside_mode
    puts "True"
  else 
    puts "False"
  end
end



【PHP版】

function in1to10($num, $outside_mode) {
  if (($num >= 1 && $num <= 10) || $outside_mode) {
    echo "True\n";
  } else {
    echo "False\n";
  }
}



# aもbもtrueの場合にtrue
a && b 

# aかbのどちらかがtrueの場合にtrue
a || b 
なおRubyの論理演算子では、左辺から右辺に条件式を評価します。もし式全体の評価が確定した場合は、その時点で残りの評価を行いません。

したがって、上の例で言えば、a&&bにおいてaがfalseの時点で全体がfalseと確定するため、bの判定は行いません。
また、a||bでは、aがtrueの時点で全体がtrueと確定するため、bの判定は行いません。
