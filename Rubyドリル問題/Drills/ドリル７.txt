■ 繰り返し処理
  input.times do |i| ... end    → input 回だけループする
  output(gets.to_i)             → 入力を受け取りながらメソッドに直接渡す書き方

■ クラスメソッド
  def self.メソッド名 ... end   → クラスメソッドの定義（インスタンスなしで呼べる）
  クラス名.メソッド名           → クラスメソッドの呼び出し方（例: Fruit.fresh）

■ インスタンスメソッド
  def initialize(name, price)   → インスタンス生成時に自動実行。引数を受け取り @変数 にセット
  def introduce ... end         → インスタンスから呼ぶメソッド（例: apple.introduce）
  @name / @price                → インスタンス変数。クラス内のメソッドから参照できる

■ インスタンスの生成
  クラス名.new(引数)            → インスタンスを生成する

■ PHP 対応メモ
  def self.fresh                → PHP では public static function fresh()
  クラス名.メソッド名           → PHP では クラス名::メソッド名()（:: でクラスメソッドを呼ぶ）
  initialize                    → PHP では __construct
  @name                         → PHP では $this->name
  input.times do                → PHP では for ($i = 0; $i < $count; $i++)
  gets.to_i                     → PHP では intval(fgets(STDIN))

【Rubyドリル 問題 15 繰り返し処理のプログラム作成】



問題.1
ユーザーに数字を入力してもらい、その数の回数だけHello!と表示させるコードを記述してください。

雛形
def output()
end

puts "何回表示させますか？"

output()


【Ruby版】

def output(input)
  input.times do |i|
    puts "Hello!"
  end
end

puts "何回表示させますか？"

output(gets.to_i)



【PHP版】

// 以前のコードにいくつか構文エラーがありましたので修正しました。
// 1. for文の変数は $i のように $ が必要です。
// 2. 5回表示させたい場合、ループは 0 から 4 までなので、$i < $count とします。
// 3. fgetsで受け取った値は intval() で整数に変換するのが安全です。

function output($count) {
    for ($i = 0; $i < $count; $i++) {
        echo "Hello!\n";
    }
}

echo "何回表示させますか？\n";
$input = intval(fgets(STDIN));
output($input);

【PHP版】

class Fruit {
    // Rubyのクラスメソッドは、PHPでは `static` をつけて「静的メソッド」として定義します。
    public static function fresh() {
        echo "採れたて新鮮な果実です。\n";
    }

    public function __construct(private string $name, private int $price) {
    }

    public function introduce() {
        echo "{$this->name}は{$this->price}円です\n";
    }
}

$apple = new Fruit("りんご", 120);
$orange = new Fruit("オレンジ", 200);
$strawberry = new Fruit("いちご", 60);

// 静的メソッドは `クラス名::メソッド名()` で呼び出します。
Fruit::fresh();
$apple->introduce();
$orange->introduce();
$strawberry->introduce();
