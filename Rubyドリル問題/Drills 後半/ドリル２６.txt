■ case / when 構文
  case gets.to_i
  when 0 → 処理A
  when 1 → 処理B
  when 2 → exit
  else   → 無効な値の処理
  end                           → if/elsif の代わりに使える。選択肢が多いときに読みやすい

■ 配列にハッシュを追加するパターン
  book = { author: author, title: title, price: price }
  data << book                  → ハッシュを作って配列に追加

■ gets.chomp.to_i の使い分け
  gets.chomp                    → 文字列として受け取る（名前・タイトルなど）
  gets.chomp.to_i / gets.to_i   → 整数として受け取る（選択番号・価格など）

■ each_with_index で一覧表示
  data.each_with_index do |book, index|
    puts "#{index + 1}: #{book[:title]}"
  end                           → 番号付きリストの定番パターン

■ PHP 対応メモ
  case / when                   → PHP では switch / case / break
  data << book                  → PHP では $data[] = $book
  &$data（参照渡し）            → PHP では配列を関数内で変更するときに & が必要
  each_with_index               → PHP では foreach ($data as $index => $book)
  exit                          → PHP では exit()

問題.1

・ [1]を選択した場合は、保存された本の番号とタイトルを出力、選択できるようにする。

・ [2]を選択した場合は、アプリケーションを終了する。

注意
・正しく動作している箇所までが採点対象となるため、必ず動作確認しながら進めること。
・エラーはインターネットで調べるなりして解決すること。
・エラーが出たままその先の実装をしないこと。

def register_book(data)
  puts "著者を入力してください"
  author = gets.chomp
  puts "タイトルを入力してください"
  title = gets.chomp
  puts "価格を入力してください"
  price = gets.chomp.to_i

  book = { author: author, title: title, price: price }
  data << book
end

def show_books(data)
  puts "見たい番号を入力してください"
  data.each_with_index do |book, index|
    puts "#{index + 1}: #{book[:title]}"
  end

  input = gets.to_i
  show_detail(data[input - 1])
end

def show_detail(data)
  puts "著者 #{data[:author]}"
  puts "タイトル #{data[:title]}"
  puts "価格 #{data[:price]}円"
end

data = []
while true do

  puts "番号を入力してください"
  puts "0: 本を登録する"
  puts "1: 本の一覧を見る"
  puts "2: 終了する"

  case gets.to_i
  when 0
    register_book(data)

  when 1
    show_books(data)

  when 2
    exit

  else
    puts '無効な値です'
  end
end




【PHP版】

function register_book(&$data) {
    echo "著者を入力してください\n";
    $author = trim(fgets(STDIN));
    echo "タイトルを入力してください\n";
    $title = trim(fgets(STDIN));
    echo "価格を入力してください\n";
    $price = trim(fgets(STDIN));

    $book = ['author' => $author, 'title' => $title, 'price' => $price];
    $data[] = $book;
}

function show_books($data) {
    echo "見たい番号を入力してください\n";

    foreach($data as $index => $book) {
        echo ($index + 1) . ": {$book['title']}\n";
    }

    $input = intval(trim(fgets(STDIN)));
    show_detail($data[$input - 1]);
}


function show_detail($data) {
    echo "著者 {$data['author']}\n";
    echo "タイトル {$data['title']}\n";
    echo "価格 {$data['price']}円\n";
}

$data = [];
while (true) {
    echo "番号を入力してください\n";
    echo "0: 本を登録する\n";
    echo "1: 本の一覧を見る\n";
    echo "2: 終了する\n";

    $input = intval(trim(fgets(STDIN)));
    switch ($input) {
        case 0:
            register_book($data);
            break;
        case 1:
            show_books($data);
            break;
        case 2:
            exit();
            break;
        default:
            echo "無効な値です\n";
    }
}
