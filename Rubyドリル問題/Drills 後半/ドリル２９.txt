■ アプリの骨格パターン（メニューループ）
  while true
    選択肢を表示
    input = gets.to_i
    if/elsif で処理を振り分け
    exit で終了
  end

■ 複数データ型の入力受け取り
  gets.chomp          → 文字列（名前など）
  gets.chomp.to_i     → 整数（年齢・体重など）
  gets.chomp.to_f     → 小数（身長など）

■ ハッシュで1人分のデータをまとめる
  info = { name: name, age: age, height: height, weight: weight }
  data << info        → 配列に追加して複数人分を管理

■ 一覧表示 → 詳細表示の流れ
  each_with_index で番号付き一覧を表示
  gets.to_i で番号を入力
  data[入力 - 1] で対応するハッシュを取り出す
  別メソッド（show_data）に渡して詳細を表示

■ to_f メソッド
  gets.chomp.to_f     → 入力を小数（Float）として受け取る
  整数と混在する計算（例: BMI）では to_f で精度を保つ

■ PHP 対応メモ
  gets.chomp.to_f     → PHP では (float)trim(fgets(STDIN))
  data << info        → PHP では $data[] = $info

【Rubyドリル 54健康管理アプリケーションの作成1】

問題.1
以下の仕様を満たすアプリケーションの雛形を作成しましょう。

仕様
・実行すると [0] : 登録する, [1] : データを確認する, [2] : 終了する という選択肢を表示し、ユーザーに入力を求め、その入力に従い以下のような処理を行う。
・ [0]の処理
　データの登録という文字列を表示させる
・ [1]の処理
　データの閲覧という文字列を表示させる
・ [2]の処理
　 アプリケーションを終了する
・ [2]でアプリケーションを終了するまで処理を繰り返す
・選択肢以外の値を入力された場合の処理
　無効な値ですと表示し、再度選択肢を表示する

雛形
def register_data
 puts "データの登録"
end

def show_data
  puts "データの閲覧"
end

data = []
while true
  puts "選択してください"
  puts "[0]登録する"
  puts "[1]データを確認する"
  puts "[2]終了する"
  input = gets.to_i

  if input == 0
    register_data(data)
  elsif input == 1
    show_data(data)
  elsif input == 2
    exit
  else

  end
end
