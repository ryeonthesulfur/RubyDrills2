【このファイルで出てくる知識・メソッド・こつ まとめ】
============================================================

■ rand メソッド
  rand(10)                      → 0〜9 のランダムな整数（10は含まない）

■ shuffle メソッド
  配列.shuffle                  → 配列の要素をランダムに並び替えた新しい配列を返す
  ["凶","中吉","吉","大吉"].shuffle → 毎回順番が変わる

■ ハッシュのキー：文字列 vs シンボル
  {"title" => "ハリーポッター"}  → 文字列キー：取り出しは hash["title"]
  {title: "ハリーポッター"}      → シンボルキー：取り出しは hash[:title]
  ※キーの型を間違えると値が取得できないので注意

■ to_sym メソッド
  gets.chomp.to_sym             → 文字列入力をシンボルに変換する
                                   シンボルキーのハッシュを入力で操作するときに必要

■ ハッシュを引数で渡す
  def movie_info(movie, info)
    puts movie[info]             → ハッシュとキーを引数で受け取って値を取り出す
  end

■ PHP 対応メモ
  配列.shuffle                  → PHP では shuffle($array)（破壊的：元の配列を変える）
  rand(10)                      → PHP では rand(0, 9)
  to_sym                        → PHP には不要（キーは最初から文字列）
  gets.chomp                    → PHP では trim(fgets(STDIN))

【Rubyドリル 問題 46 運勢の表示プログラム】



問題.1
誕生日を入力すると、今日の運勢を表示してくれるプログラムを作ってください。
占い結果については、以下のアルゴリズムにて判定することとします。
必ず、メソッドを作成しそれを呼び出すように記述してください。

・引数として誕生日の数字を受け取る(例：4月3日なら403、11月15日なら1115と入力)
・誕生日の数字に、乱数で生成された0 ~ 9の数字のいずれかを掛け算し、その後4で割った時の余りを算出
・シャッフルした占い結果を格納した配列から、上記の数値の順番の値を取り出す
　["凶","中吉","吉", "大吉"]

ヒント
乱数を生成するためには、randを使いましょう。

rand
randは指定した数の範囲の中で、ランダムに数値を生成することができます。


num = rand(100)
puts num
=> 32  # 0~99の範囲でランダムな数字が生成された

num = rand(100)
puts num
=> 74 # 0~99の範囲でランダムな数字が生成された
randの詳細は公式リファレンスを確認しましょう。


また、配列の要素をシャッフルするためにはshuffleメソッドを使用しましょう。
配列に格納された占い結果をシャッフルすることで、余剰が必ず同じになってしまう誕生日の場合でも、ランダムに占い結果を表示することができます。

shuffle
shuffleは配列の要素をランダムにシャッフルし、その結果を配列として返します。


# shuffleメソッドで配列をシャッフルし、変数animalsに代入
animals = ["cat", "dog", "rabbit"].shuffle

puts animals
# => ["rabbit", "cat", "dog"]
shuffleの詳細は公式リファレンスを確認しましょう。



def fortune(birth_day)
 fortune_result = ["凶","中吉","吉", "大吉"].shuffle
 result_num = birth_day * rand(10) % 4
 puts "今日のあなたの運勢は、#{fortune_result[result_num]}だよ！"
end

puts "誕生日を入力してください。(例：4月3日なら403、11月15日なら1115と入力)"

【PHP版】
function fortune($birth_day) {
    $fortune_result = ["凶", "中吉", "吉", "大吉"];
    shuffle($fortune_result);
    $result_num = ($birth_day * rand(0, 9)) % 4;
    echo "今日のあなたの運勢は、{$fortune_result[$result_num]}だよ！\n";
}

echo "誕生日を入力してください。(例：4月3日なら403、11月15日なら1115と入力)\n";
$birth_day = intval(trim(fgets(STDIN)));
fortune($birth_day);

ハッシュを引数としてメソッドに渡す
ハッシュ名[キー名]と記述することで、そのキーに対応するバリューを取り出す事が出来ます。
例えばキーである「title」を指定した場合、対応するバリューの「ハリーポッター」が取り出されます。


【PHP版】

function movie_info($movie, $info) {
    echo $movie[$info] . "\n";
}

$movie = ["title" => "ハリーポッター", "genre" => "ファンタジー", "year" => "2001年"];

echo "以下から一つを選んで入力してください。\n・title\n・genre\n・year\n";

$info = trim(fgets(STDIN));
movie_info($movie, $info);







movie = {title: "ハリーポッター", genre: "ファンタジー",  year: "2001年"}
このようなハッシュからバリューを取得する場合は、movie[:title]のようにキーをシンボルで指定する必要があります。文字列のキーではバリューを取得できません。

```ruby

def movie_info(movie, data)
  puts movie[data]
end

puts "以下から一つを選んで入力してください。
  ・title
  ・genre
  ・year"

info = gets.chomp.to_sym

movie_info(movie, info)
```

to_symというメソッドを用いて、返り値を文字列からシンボルへ変換しています。
仮に、変数infoを文字列のままmovie_infoメソッドに渡した場合、
movie[:title]としてバリューを取り出したいところがmovie["title"]のようになってしまい、指定したキーの値は出力されません。


【PHP版】そのまんま

Ruby	                PHP
gets.chomp.to_sym	    trim(fgets(STDIN))

PHPにはシンボルがないので .to_sym の変換は不要です。キーも値も全部文字列として扱います。

PHPは最初からキーが文字列なので、Rubyみたいに「文字列→シンボルに変換」する必要がありません。
入力した "title" がそのままキーとして使えます。
