■ Time クラス
  Time.new                       → 現在時刻を取得する
  now.year / now.month / now.day → 年・月・日を数値で取得
  now.wday                       → 曜日を数値で取得（0=日, 1=月, ..., 6=土）

■ 曜日配列パターン
  week = ["日曜日", "月曜日", ...]
  week[now.wday]                 → wday の数値を配列のインデックスとして使う

■ %w 記法
  %w[日 月 火 水 木 金 土]      → スペース区切りで文字列配列を作る省略記法
  %w は文字列配列専用（数値には使えない）

■ PHP 対応メモ
  Time.new                       → PHP では new DateTime()
  now.year                       → PHP では $now->format('Y')（または date('Y')）
  now.month                      → PHP では $now->format('n')
  now.day                        → PHP では $now->format('j')
  now.wday                       → PHP では $now->format('w')（または date('w')）

【Rubyドリル 問題 64 日付と曜日を出力する】


問題.1
今日の日付と曜日を出力するコードを作りましょう

出力例：
現在は西暦2020年5月27日（今日の日付が入ります）
水曜日です（今日の曜日が入ります）

ヒント
Time.newメソッドを使用しましょう

 Timeクラス
TimeクラスはRubyの標準ライブラリにあり、時刻を表すクラスです。
以下のように利用します。


# 現在時刻
now = Time.new
puts now


wday は曜日を 数字 で返す（0=日曜, 1=月曜, ... 6=土曜）。


now = Time.new
puts "現在は西暦#{now.year}年#{now.month}月#{now.day}日"

week = ["日曜日", "月曜日", "火曜日", "水曜日", "木曜日", "金曜日", "土曜日"]
puts "#{week[now.wday]}です。"


※この書き方でもOK
puts %w(日 月 火 水 木 金 土)[now.wday] + '曜日です' 
----------------------------------------------------------------
    「%w記法」
%w は「スペース区切りの文字列配列を作る」ための汎用的な記法。どんな文字列でも使える。

fruits = %w[apple banana orange]
#=> ["apple", "banana", "orange"]

colors = %w[赤 青 黄]
#=> ["赤", "青", "黄"]

names = %w[山田 佐藤 鈴木]
#=> ["山田", "佐藤", "鈴木"]



week = %w[日 月 火 水 木 金 土]
puts week[now.wday] + "曜日です"
----------------------------------------------------------------


【PHP版】

```php
$now = new DateTime();

$year  = $now->format('Y');
$month = $now->format('n');
$day   = $now->format('j');
$wday  = $now->format('w');

echo "現在は西暦{$year}年{$month}月{$day}日\n";

$week = ["日", "月", "火", "水", "木", "金", "土"];
$wday  = date('w')  // 曜日を数字で取得する。

echo $week[$wday] . "曜日です\n";
```

対応表：

Ruby	            PHP	                意味
now.year	        date('Y')	        西暦
now.month	        date('n')	        月
now.day	            date('j')	        日
now.wday	        date('w')	        曜日(0〜6)
