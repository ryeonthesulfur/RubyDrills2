■ メソッドへの引数の渡し方
  def multiple(num1, num2)      → 仮引数を2つ受け取るメソッド
  multiple(num1, num2)          → 呼び出し時に実引数を渡す

■ return と puts の使い分け
  return num                    → 値を返すだけ（出力しない）→ 呼び出し元で puts する
  puts "#{num1 * num2}"         → メソッド内で直接出力する（スクールの別解パターン）
  どちらも正解だが return で返す方が汎用性が高い

■ 入力の受け取り
  gets.to_i                     → キーボード入力を整数として受け取る
  2回 gets を使う               → 複数の入力を別々の変数に受け取るパターン

■ PHP 対応メモ
  gets.to_i                     → PHP では intval(trim(fgets(STDIN)))
  "#{num1}と#{num2}"            → PHP では "{$num1}と{$num2}"

【Rubyドリル 問題 42 引数を使いこなそう】

問題
ユーザーが数字を2つ渡すと、それらを掛け算した結果を返すプログラムを作ってください。

定義する変数
2つの数字を、それぞれnum1, num2という変数にgetsメソッドを利用して定義してください。



実行結果の例

#デスクトップに移動
$cd Desktop
#Rubyファイルを実行
$ruby argument_test.rb
最初の数字を入力してください
5
2番目の数字を入力してください
6
5と6をかけた答えは30です！


def multiple(num1, num2)
    num = num1 * num2 
    return num
end

puts "最初の数字を入力してください"
num1 = gets.to_i
puts "2番目の数字を入力してください"
num2 = gets.to_i

num = multiple(num1, num2)

puts "#{num1}と#{num2}をかけた答えは#{num}です！"




【スクールの回答】
def multiplication(num1, num2)
  puts "#{num1}と#{num2}をかけた答えは#{num1 * num2}です！"
end

puts "最初の数字を入力してください"

num1 = gets.to_i

puts "2番目の数字を入力してください"

num2 = gets.to_i

multiplication(num1, num2)




【PHP版】
function multiple($num1, $num2) {
    $num = $num1 * $num2;
    return $num;
}

echo "最初の数字を入力してください\n";
$num1 = intval(trim(fgets(STDIN)));

echo "2番目の数字を入力してください";
$num2 = intval(trim(fgets(STDIN)));

$num = multiple($num1, $num2);

echo "{$num1}と{$num2}をかけた答えは{$num}です！\n";
