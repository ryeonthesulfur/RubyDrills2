■ クラス変数（@@）
  @@type = "犬"                 → クラス全体で共有される変数。全インスタンスで同じ値
  #{@@type}                     → インスタンスメソッド内からもアクセスできる
  クラス変数 vs インスタンス変数 → @@ はクラス全体共有 / @ は各インスタンス固有

■ クラスメソッド
  def self.say ... end          → クラス名から直接呼ぶ（例: Dog.say）
  インスタンス不要で呼べる

■ インスタンスメソッド
  def say_type / def self_introduction
                                → インスタンスから呼ぶ（例: pochi.say_type）

■ PHP 対応メモ
  @@type = "犬"                 → PHP では private static $type = "犬"
  #{@@type}                     → PHP では self::$type（クラス変数へのアクセスは self::）
  def self.say                  → PHP では public static function say()
  Dog.say                       → PHP では Dog::say()（:: でクラスメソッドを呼ぶ）
  @name / @dog_type             → PHP では $this->name / $this->dog_type

【Rubyドリル 問題 60 クラスの定義問題】


問題.1
クラスを使用して以下の表示結果を出力するコードを記述しましょう。

表示結果
ワンワン
わたしは犬です
わたしの名前はマロンで種類はトイプードルです


class Dog
attr_reader :name, :dog_type
    @@type = "犬"

def initialize(name, dog_type)
    @name = name
    @dog_type = dog_type
end

def self.say
    puts "ワンワン"
end

def say_type
    puts "わたしは#{@@type}です。"
end

def self_introduction
    puts "わたしの名前は#{@name}で種類は#{@dog_type}です。"
end
end

pochi = Dog.new("マロン", "トイプードル")
Dog.say
pochi.say_type
pochi.self_introduction




【PHP版】

class Dog {
    private static $type = "犬";
    public function __construct(private $name, private $dog_type) {}

    public static function say() {
        echo "ワンワン\n";
    }

    public function say_type() {
        echo "わたしは" . self::$type . "です。\n";
    }

    public function self_introduction() {
        echo "わたしの名前は{$this->name}で種類は{$this->dog_type}です。\n";
    }
}

$pochi = new Dog('マロン', 'トイプードル');
Dog::say();
$pochi->say_type();
$pochi->self_introduction();
