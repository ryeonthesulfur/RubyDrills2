■ 月の日数配列
  month_days = [31, 28, 31, 30, 31, 30, 31, 31, 30, 31, 30, 31]
  month_days[month - 1]          → 月番号（1〜12）を 0始まりインデックスに変換して取得

■ 閏年判定ロジック（再確認）
  year % 4 == 0 → 閏年候補
  year % 100 != 0 || year % 400 == 0 → 100の倍数でないか、400の倍数なら閏年
  → 2月は 29日、それ以外は 28日

■ 曜日計算のアルゴリズム
  西暦1年1月1日を起点（月曜＝1日目）
  1. 指定年の前年まで全日数を合計
  2. 指定月の前月まで全日数を合計
  3. 日を足す
  4. days % 7 → 配列インデックスで曜日を取得

■ while ループでカウントダウン
  year_index = year - 1
  while year_index > 0 do
    days += 366 or 365
    year_index -= 1
  end                            → 1年ずつ遡って合計日数を積み上げる

■ days % 7 で曜日を出す
  weeks = ["日", "月", "火", "水", "木", "金", "土"]
  weeks[days % 7]                → 総日数を7で割った余りが曜日インデックスになる

■ PHP 対応メモ
  get_days(year, month)          → PHP でも同名関数で同じロジックで書ける
  year % 4 == 0                  → PHP でも $year % 4 == 0
  weeks[days % 7]                → PHP では $weeks[$days % 7]

問題
ある年、ある月、ある日の曜日を取得しましょう。曜日は月曜日なら「月」、火曜日なら「火」というように表示してください。　

本ドリルでは、西暦1年1月1日は月曜日とします。
閏年を考えることもヒントの１つです。

作ってもらうプログラムのひな形は以下です。

def get_days(year, month)
  days = 0
  month_days = [31, 28, 31, 30, 31, 30, 31, 31, 30, 31, 30, 31]

def get_week(year, month, day)
    weeks = ["日", "月", "火", "水", "木", "金", "土"]
    days = 0

    year_index = year - 1
    while year_index > 0 do
      if get_days(year_index, 2) == 29
        days += 366
      else
        days += 365
      end
      year_index -= 1
    end

    month_index = month - 1
    while month_index > 0 do
    month_days = get_days(year, month_index)
    days += month_days
    month_index -= 1
    end

    days += day
    return weeks[days % 7]
end
