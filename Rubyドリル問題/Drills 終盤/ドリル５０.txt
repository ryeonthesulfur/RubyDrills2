■ 範囲演算子で総和を求める書き方
  (n..m).sum                     → 範囲オブジェクトに sum を使うと一発で合計が出る
  (n..m)                         → n 以上 m 以下の整数の範囲

■ while ループで総和を求める書き方
  total = 0
  while n <= m
    total += n
    n += 1
  end                            → n を1ずつ増やしながら total に足していく
  カウンタ変数を使った基本パターン

■ 2つの書き方の比較
  (n..m).sum                     → Ruby らしい簡潔な書き方
  while でループ                 → 他の言語でも共通する基本的な書き方
  どちらも結果は同じ

■ n += 1 のインクリメント
  n += 1                         → n = n + 1 の省略形
  while ループのカウンタを進めるために必須（忘れると無限ループ）

■ PHP 対応メモ
  (n..m).sum                     → PHP では array_sum(range($n, $m))
  while n <= m / n += 1          → PHP でも同じ while ($n <= $m) { $n++; } で動く

【Rubyドリル 問題 77 nからmの数の総和を求めるプログラムの実装】


問題.1
概要
本ドリルでは、与えられた数字n,mについて、nからmまでの数の総和を求めるプログラムを実装します。

問題
以下の要件を満たすsum_numberメソッドを実装しましょう。

第一仮引数をnとし、第二仮引数をmとすること
nからmまでの数を足し合わせていき、その総和を出力すること（例：n=1,m=5の場合、総和は1+2+3+4+5=11）




雛形
def sum_number(n, m)
  amount += (n..m)
end


def sum_number(n, m)
  total = 0
  while n <= m
    total += n
    n += 1
  end
  puts total
end



# 呼び出し例
sum_number(1,10)
出力例
sum_number(1,3) → 6 ＜計算内容：1+2+3＞
sum_number(1,10) → 55 ＜計算内容：1+2+3+4…+10＞
sum_number(5,15) → 110 ＜計算内容5+6+7+8…+15＞
