■ 降順バブルソートと昇順の違い
  昇順: if data[j] > data[j + 1] → 大きい方を右に送る
  降順: if data[j] < data[j + 1] → 小さい方を右に送る
  比較の向きを逆にするだけで昇順↔降順を切り替えられる

■ バブルソートの構造（復習）
  外側ループ: 0..length - 1（パス回数）
  内側ループ: 0..length - 2（隣と比較するので -2 まで）
  data[j], data[j+1] = data[j+1], data[j]  → 多重代入で交換

■ こつ：条件式の向きだけ変える
  ソートの方向を変えたいときはアルゴリズム全体を書き直す必要はなく
  if の比較演算子（> か <）を変えるだけでよい

■ PHP 対応メモ
  if data[j] < data[j + 1]      → PHP では if ($data[$j] < $data[$j + 1])
  多重代入（交換）               → PHP では temp 変数を使う

【Rubyドリル 問題 74 バブルソート問題2】


問題.1
概要
本ドリルでは、配列の要素である数値を、大きい順に並べ替えて出力するプログラムを実装します。

問題
以下の要件を満たすbubble_sortメソッドを実装しましょう。

要素が数値である配列を受け取り、数値の大きい順に並べ替えること
大きい順に並べ替えた結果を出力すること



雛形
def bubble_sort(data)
  length = data.length

  for i in 0..length - 1
    for j in 0..length - 2
      if data[j] < data[j + 1]
        data[j], data[j + 1] = data[j + 1], data[j]
      end
    end
  end
end



# 呼び出し例
number = [1,23,4,6,12,45,79]
bubble_sort(number)
puts number



出力例
79
45
23
12
6
4
1
