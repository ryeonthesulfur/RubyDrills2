■ gsub メソッド（文字列置換）
  str.gsub(/[\s]/, "")          → 半角空白を空文字に置換（= 削除）
  str.gsub(/[\s　]/, "")        → 半角空白 + 全角空白を両方削除
  正規表現を [] で囲むと「どれか1文字」にマッチする

■ 正規表現での空白
  \s                             → 半角スペース・タブ・改行などを表す
  　（全角スペース）             → \s では拾えないので明示的に [] の中に追加する

■ upcase メソッド（大文字変換）
  str.upcase                     → 全ての小文字を大文字に変換する
  "hello".upcase → "HELLO"

■ メソッドチェーンで書く書き方
  text.gsub(/[\s　]/, "").upcase → 2行を1行にまとめることもできる

■ PHP 対応メモ
  gsub(/[\s　]/, "")             → PHP では preg_replace('/[\s　]/', '', $text)
  .upcase                        → PHP では strtoupper($str)

【Rubyドリル 問題 76 文字列からの空白削除と大文字置換問題するプログラムの実装】



問題.1
概要
本ドリルでは、対象の文字列の中に空白が含まれている場合は空白を削除し、さらに小文字が含まれている場合は大文字に置換するプログラムを実装します。

問題
以下の要件を満たすtext_transformメソッドを実装しましょう。

対象となる文字列から空白を削除すること
対象となる文字列が小文字だった場合、大文字に置換すること
空白が含まれない大文字の文字列を出力すること


雛形
def text_transform(text)
  str = text.gsub(/[\s]/, "")

  str = str.upcase
  puts str
end

# 呼び出し例
text_transform("hello world")

出力例
text_transform("hello world") → HELLOWORLD
text_transform("ruby on rails") → RUBYONRAILS
text_transform("a　bc") → ABC #全角空白が含まれている場合も削除される





ヒント
・空白を削除する場合は、gsubメソッドを使用しましょう。

gsubメソッド
gsubメソッドとは、特定の文字を別の文字へ置換するメソッドです。特定の文字を指定する際に、正規表現を使うことができます。

下記の例は、半角と全角の空白を""に置き換える、つまり削除する処理です。
半角の空白は、正規表現では「\s」と表すことができます。しかし全角の空白は含まれないため、追加で「（空白）」を指定しています。

1
2
str = "a　b c "
puts str.gsub(/[\s　]/, "")
gsubメソッドの詳細は公式リファレンスを確認しましょう。

・大文字に変換する場合は、upcaseメソッドを使用しましょう。

upcaseメソッド
upcaseメソッドとは、小文字を大文字に置換するメソッドです。

1
2
3
text = "apple"
puts text.upcase
#=> APPLE
