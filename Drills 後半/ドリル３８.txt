【Rubyドリル 問題 65 じゃんけん問題】


問題.1
プログラムとじゃんけんをするプログラムを作ってください。

また、じゃんけんの結果によって以下のように処理を変えます。

勝った場合 "あなたの勝ちです"と表示させる
負けた場合 "あなたの負けです"と表示させる
あいこの場合 "あいこで"と表示させたあともう一度じゃんけんをさせる


プログラムの実行
ターミナル

最初はグー、じゃんけん...
[0]:グー
[1]:チョキ
[2]:パー
# 入力待ち


出す手を入力したあと(勝った場合)
ターミナル

最初はグー、じゃんけん...
[0]:グー
[1]:チョキ
[2]:パー

あなたの手:グー, わたしの手:チョキ
あなたの勝ちです
----------------------------------------

出す手を入力したあと(あいこの場合)
ターミナル

最初はグー、じゃんけん...
[0]:グー
[1]:チョキ
[2]:パー

あなたの手:グー, わたしの手:グー
あいこで

 def janken

  player_hand = gets.to_i
  program_hand = rand(3)

  jankens = ["グー", "チョキ", "パー"]

  elsif (player_hand == 0 && program_hand == 1)

    return false

  else
    puts "あなたの負けです"
    return false
  end
end

next_game = true

ヒント
乱数の作り方
ヒントとして、乱数の作り方を教えます。乱数を使うとプログラムの出す手をランダムにすることができます。


  rand(欲しい乱数の数)
randメソッドを使うと手軽に乱数を生成できます。randメソッドに引数として数を渡すと「0」から「渡した数 - 1」の間でランダムに数を返します。

  rand(100) # => 0〜99の中から１つ数字をランダムに返す
これを使えばランダムにじゃんけんの手を出すことができます。

function janken() {
  echo "[0]:グー\n[1]:チョキ\n[2]:パー\n";

  $player_hand = intval(trim(fgets(STDIN)));
  $program_hand = rand(0, 2);

  $jankens = ["グー", "チョキ", "パー"];

  echo "あなたの手：" . $jankens[$player_hand] . ", わたしの手：" . $jankens[$program_hand] . "\n";

  if ($player_hand == $program_hand) {
    echo "あいこで\n";
    return true;
  } elseif (($player_hand == 0 && $program_hand == 1) 
      || ($player_hand == 1 && $program_hand == 2) 
      || ($player_hand == 2 && $program_hand == 0)) {
    echo "あなたの勝ちです\n";
    return false;

  } else {
    echo "あなたの負けです\n";
    return false;
  }
}

$next_game = true;

echo "最初はグー、じゃんけん...\n";

while ($next_game) {
  $next_game = janken();
}



【Java版】

import java.util.Scanner;
import java.util.Random;

public class Janken {

  public static boolean janken() {
    System.out.println("[0]:グー\n[1]:チョキ\n[2]:パー");

    Scanner sc = new Scanner(System.in);
    int player_hand = sc.nextInt();

    Random rand = new Random();
    int program_hand = rand.nextInt(3);

    String jankens[] = {"グー", "チョキ", "パー"};

    System.out.println(
      "あなたの手：" 
      + jankens[player_hand] 
      + "、わたしの手：" + jankens[program_hand]
    );

    if (player_hand == program_hand) {
      System.out.println("あいこで");
      return true;
    } else if ((player_hand == 0 && program_hand == 1) 
            || (player_hand == 1 && program_hand == 2) 
            || (player_hand == 2 && program_hand == 0)) {
      System.out.println("あなたの勝ちです。");
      return false;
    } else {
      System.out.println("あなたの負けです。");
      return false;
    }
  }
  
  public static void main(String[] args) {
    boolean next_game = true;
    while (next_game) {
      next_game = janken();
    }
  }
}
