追加機能
BMIを計算して、一覧表示の際に追加表示する

BMIの計算方法
BMI=体重÷身長÷身長

仕様
・実行すると [0] : 登録する, [1] : データを確認する, [2] : 終了する という選択肢を表示し、ユーザーに入力を求め、その入力に従い以下のような処理を行う
・ [0]の処理
1. 名前、年齢、身長、体重を入力させる
2. '身長と体重からBMIを割り出す' 名前、年齢、身長、体重、'BMI'を保存する
・ [1]の処理
1. 投稿された情報から番号と名前で一覧を表示し（例 [1]山田）、見たい個人の番号の入力を求める
2. 入力された個人の名前、年齢、身長、体重、'BMI'を表示する
・ [2]の処理
1. アプリケーションを終了する
・ [2]でアプリケーションを終了するまで、投稿や閲覧ができるように繰り返す

   data << info
end

def calculate_bmi(tall, weight)
    tall_m = tall / 100.0
    bmi = weight / tall_m / tall_m
end

data = []
while true
  puts "選択してください"

function register_data(&$data) {
    echo "各情報を入力してください\n";
    echo "名前を入力してください\n";
    $name = trim(fgets(STDIN));
    echo "年齢を入力してください\n";
    $age = trim(fgets(STDIN));
    echo "身長を入力してください\n";
    $tall = intval(trim(fgets(STDIN)));
    echo "体重を入力してください\n";
    $weight = intval(trim(fgets(STDIN)));

    $info = ['name' => $name, 'age' => $age, 'tall' => $tall, 'weight' => $weight, 'bmi' => calculate_bmi($tall, $weight)];
    $data[] = $info;
}

function calculate_bmi($tall, $weight) {
    $tall_m = $tall / 100;
    $bmi = $weight / $tall_m / $tall_m;
    return $bmi;
}

function show_data_list($data) {
    echo "見たい人の番号を選択してください\n";

    foreach($data as $index => $info) {
        echo ($index + 1) . ": {$info['name']}\n";
    }
    
    $input = intval(trim(fgets(STDIN)));
    show_data($data[$input - 1]);
}


function show_data($info) {
    echo "名前: {$info['name']}\n";
    echo "年齢: {$info['age']}\n";
    echo "身長: {$info['tall']}\n";
    echo "体重: {$info['weight']}\n";
    echo "BMI: {$info['bmi']}\n";
}


$data = [];
