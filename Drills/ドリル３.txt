【Y_Rubyドリル 問題 5 メソッドの使い方】


price = 300

def calculate_price_with_tax(price)
  tax = 0.1
  return price + price * tax
end

puts calculate_price_with_tax(price)

-------------------------------------------------------------------------------------------------------------------------------------

このコードは、税込み価格を計算するメソッドを定義して、それを呼び出しています。
ただ、このまま実行しても、計算結果（330）はどこにも表示されません。なぜだかわかりますか？

【回答】
`calculate_price_with_tax`メソッドは、計算結果の値を`return`で返しているだけで、
その返ってきた値を画面に出力する`puts`や`echo`といった命令が書かれていないからです。


【PHP版】

$price = 300;

function calculate_price_with_tax($price) {
    $tax = 0.1;
    return $price + $price * $tax;
}

echo calculate_price_with_tax($price);

問題.1
"晴れ" という文字列を引数で渡した時に

明日の天気は晴れです

とターミナルに表示されるようなメソッドを作成してください。

呼び出し方：get_weather_forecast("晴れ")


【回答】

def get_weather_forecast(weather)
  puts "明日の天気は#{weather}です"
end

get_weather_forecast("晴れ")


【PHP版】

function get_weather_forecast($weather) {
    echo "明日の天気は{$weather}です";
}

get_weather_forecast("晴れ");

 Dateクラス
DateクラスとはRubyの標準ライブラリの機能です。Dateクラスを使うには以下一文を記述します。

require "date"
次に、Dateクラスを用いて「今日の曜日」を取得する場合は以下のように記述します。

Date.today.wday
wdayは曜日を0(日曜日)から6(土曜日)の整数で取得することができるDateクラスに用意されているメソッドです。

たとえば、以下のように使うことができます。

require "date"

day = Date.today.wday

puts day
これを実行すると、曜日に合わせた数字が出力されます。たとえば、木曜日だとすれば4が出力されることになります。



問題.1
今日の曜日を表示するコードをDateクラスを使用して記述してください。

ただし、金曜日だった場合だけ以下のように表示の内容を変えてください。

（出力内容）
「今日は月曜日」
「今日は金曜日だ ！！！」




【Ruby版】

require "date"

day = Date.today.wday
wdays = ["日曜日", "月曜日", "火曜日", "水曜日", "木曜日", "金曜日", "土曜日"]

if day == 5
  puts "今日は#{wdays[day]}だ ！！！"
else
  puts "今日は#{wdays[day]}"
end


【PHP版】

// PHPのdate関数は標準で組み込まれているため、requireは不要です。
// date("w") で、曜日を0(日)から6(土)の数値で取得できます。

$day = date("w");
$wdays = ["日曜日", "月曜日", "火曜日", "水曜日", "木曜日", "金曜日", "土曜日"];

if ($day == 5) {
  echo "今日は{$wdays[$day]}だ ！！！\n";
} else {
  echo "今日は{$wdays[$day]}\n";
}

問題.1
次のif文をunlessというメソッドを用いて書き換えてください。


if a + b > 0
  puts "計算結果は0より大きいです"
end


【回答】

unless a + b <= 0
  puts "計算結果は0より大きいです"
end

`unless a + b < 0` は、「a+bが0より小さく**ない**場合」という意味になります。
これは、言い換えると「a+bが0**以上**の場合 (`>=`)」と同じです。

元の `if a + b > 0` は「0より大きい場合」なので、`a+b`がちょうど`0`の時に動きが変わってしまいます。

正解は、条件を逆にして `unless a + b <= 0` とすることです。





【PHP版】
PHPには`unless`に直接相当する構文はありません。
そのため、通常の`if`文を使って同じロジックを表現します。

if ($a + $b > 0) {
  echo "計算結果は0より大きいです\n";
}

【解説】`\n` とは何か？

`\n` は「改行コード」と呼ばれる特殊な文字です。
`echo` や `puts` で文字列を出力する際に、この文字があると、そこで改行して次の行の先頭にカーソルが移動します。

例えば、PHPで以下のように書くと...
```php
echo "こんにちは";
echo "さようなら";
```
出力はこうなります。
```
こんにちはさようなら
```

しかし、`\n` を加えると...
```php
echo "こんにちは\n";
echo "さようなら\n";
```
出力はこうなります。
```
こんにちは
さようなら
```
このように、ターミナルでの表示を読みやすくするために使われます。

Rubyの `puts` は自動的に最後に改行コードを付けてくれるので普段は意識しませんが、改行しない `print` を使うとPHPの `echo` と同じ動きになります。
