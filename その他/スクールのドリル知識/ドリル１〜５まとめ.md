# ドリル１〜５ Rubyの知識・メソッド・こつ まとめ

---

## ■ ハッシュ

```
{ one: 1, two: 2 }        → シンボルをキーにしたハッシュの書き方
hash.keys                  → キーだけを配列で取得
hash.values                → 値だけを配列で取得
```

### ネストしたハッシュ・配列

```
u[:user][:profile][:name]       → ネストしたハッシュを順番にたどって値を取得
u.dig(:user, :profile, :name)   → dig メソッドで同じことを1行で書ける（別解）
```

---

## ■ クラス・インスタンス

```
class クラス名 ... end          → クラスの定義
クラス名.new(引数)              → インスタンスの生成（initialize が自動で動く）
@変数名                         → インスタンス変数（クラス内どこからでも使える）
```

### initialize メソッド

```
def initialize(引数) ... end    → .new 時に自動実行される初期化メソッド
引数なしの initialize           → 空の箱を作るだけ。後からセッターで値をセット
initialize(attributes = {})     → ハッシュをまとめて受け取る書き方（Rails の params に対応）
```

### ゲッター・セッター

```
def author; @author; end        → ゲッター（手書き）：外から値を読み取る
def author=(v); @author=v; end  → セッター（手書き）：外から値を書き換える
attr_reader :name               → ゲッターを自動生成
attr_writer :name               → セッターを自動生成
attr_accessor :name             → ゲッター・セッター両方を自動生成
```

### self

```
self.author = 値                → initialize 内でセッターを呼ぶときに使う
                                   （self = 今まさに作られているインスタンス自身）
```

### インスタンスメソッド

```
def show ... end                → クラス内に出力処理を定義する方法
                                   （クラス内は @変数 で直接参照できるのでゲッター不要）
```

### Rails との関係

```
Article.new(article_params)     → コントローラーから initialize を呼ぶ典型パターン
initialize はモデル(M)のインスタンスを組み立てる工場の役割
ActiveRecord::Base に高機能な initialize が内包されているため普段は見えない
```

## ■ メソッドの定義と呼び出し

```
def メソッド名(引数) ... end    → メソッドの定義
return 値                       → 値を返す（返すだけで出力はしない）
puts メソッド名(引数)           → メソッドの戻り値を出力する
```

---

## ■ 繰り返し処理

```
配列.each do |u| ... end        → 配列の要素を1つずつ処理する

10.times do |i| ... end         → 0〜9 の i で10回ループ
i + 1                           → times の i は 0 始まりなので、1〜10 にするには +1 する
sum += i + 1                    → 合計に加算していくパターン
ループの外で puts                → 途中経過を出さず、最後の合計だけ出力するときはループの外に書く
```

### each_with_index

```
配列.each_with_index do |値, インデックス| ... end
                                → 値とインデックス（0始まり）を同時に取得しながらループ
index + 1                       → 0始まりを1始まりに直す
return                          → メソッド内で見つかった時点でループを抜けて終了する
```

## ■ 文字列

### 文字列展開（式展開）

```
"明日の天気は#{weather}です"    → #{} で変数を文字列に埋め込む
```

### 文字列の検索

```
文字列.include?(".")            → 文字列に指定した文字が含まれるか（true/false）
str.include?(" ")               → 半角スペースが含まれるかのチェック
```

### 改行コード

```
\n                              → 改行を表す特殊文字
puts                            → 自動で末尾に改行をつける
print                           → 改行をつけない（PHP の echo に近い動き）
```

---

## ■ 入力の受け取り

```
gets                            → キーボードから1行入力を受け取る（末尾に \n がつく）
gets.chomp                      → 入力の末尾の改行を取り除く（安全な受け取り方）
```

---

## ■ 条件分岐

```
if / elsif / else / end         → 複数条件の分岐パターン
unless 条件                     → 条件が偽のときだけ実行（if !条件 と同じ）
unless a + b <= 0               → 「a+b が 0 以下でない = 0 より大きい」の書き方
```

---

## ■ Date クラス

```
require "date"                  → Date クラスを使うために必要な読み込み
Date.today.wday                 → 今日の曜日を 0（日）〜 6（土）の整数で取得
```

### 配列で曜日名を管理するパターン

```
wdays = ["日曜日", "月曜日", ...] → 配列のインデックスと wday の数値を対応させる
wdays[day]                      → day の数値で曜日名を取り出す
```

---

## ■ 定数

```
Japanese = 80                   → 先頭大文字で定義すると定数扱いになる（変更不可）
※通常の変数は小文字始まりで書く
```

---

## ■ 計算

```
(a + b + c) / 3                 → 整数同士の割り算は小数が出ない（切り捨て）
```

## ■ PHP 対応メモ まとめ

| Ruby | PHP |
|------|-----|
| ハッシュ `{ key: value }` | 連想配列 `['key' => value]` |
| `#{変数}` | `{$変数}`（ダブルクォート内） |
| `/ 3`（整数除算） | `intdiv()` |
| `each` ブロック | `foreach` |
| `initialize` | `__construct` |
| `attr_reader`（ゲッター） | 手書きで `getXxx()` を定義 |
| `attr_writer`（セッター） | 手書きで `setXxx()` を定義 |
| `require "date"` | 不要（`date()` は標準で使える） |
| `Date.today.wday` | `date("w")` |
| `unless` | 対応構文なし。`if ($a > 0)` で代替 |
| `include?(".")` | `str_contains($str, '.')` （PHP 8.0以降） |
| `gets.chomp` | `trim(fgets(STDIN))` |
| `elsif` | `elseif`（PHP に `elsif` はない） |
| `10.times do \|i\|` | `for ($i = 1; $i <= 10; $i++)` |
| `each_with_index` | `foreach ($array as $index => $value)` |
| `as` | 「〜として」。配列の要素を変数に割り当てる |
| 文字列連結 `+` / `#{}` | ドット `.` で連結 |
