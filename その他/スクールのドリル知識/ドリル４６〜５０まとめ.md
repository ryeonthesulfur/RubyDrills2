## ■ バブルソート（昇順）のアルゴリズム

```
隣り合う要素を比べて大きい方を右に送ることを繰り返す
外側ループ: length 回繰り返す（全体をパスする回数）
内側ループ: length - 1 回比較（最後の要素と比べるため -1）

for i in 0..length - 1
  for j in 0..length - 2
    if data[j] > data[j + 1]    → 昇順：左が大きければ交換
      data[j], data[j + 1] = data[j + 1], data[j]
    end
  end
end
```

### 多重代入で値を交換する

```
data[j], data[j + 1] = data[j + 1], data[j]
                                → Ruby では一時変数不要でこの1行で交換できる
PHP/Java では temp 変数が必要
```

### for 文（Ruby）

```
for i in 0..length - 1         → 0 から length-1 まで繰り返す
Ruby では for より times/each が慣習的だが、ソートのような添字操作には for も使われる
```

### 入れ子ループの動き

```
外側1回につき内側が全件回る
外側 i=0 → 内側 j=0,1,2... → 外側 i=1 → 内側 j=0,1,2...
```

## ■ バブルソート（降順）

```
昇順: if data[j] > data[j + 1] → 大きい方を右に送る
降順: if data[j] < data[j + 1] → 小さい方を右に送る
比較の向きを逆にするだけで昇順↔降順を切り替えられる
```

### こつ：条件式の向きだけ変える

```
ソートの方向を変えたいときはアルゴリズム全体を書き直す必要はなく
if の比較演算子（> か <）を変えるだけでよい
```

## ■ gsub メソッド（文字列置換・削除）

```
str.gsub(/[\s]/, "")           → 半角空白を空文字に置換（= 削除）
str.gsub(/[\s　]/, "")         → 半角空白 + 全角空白を両方削除
正規表現を [] で囲むと「どれか1文字」にマッチする
```

### 正規表現での空白

```
\s                              → 半角スペース・タブ・改行などを表す
　（全角スペース）              → \s では拾えないので明示的に [] の中に追加する
```

### メソッドチェーンで書く書き方

```
text.gsub(/[\s　]/, "").upcase  → 2行を1行にまとめることもできる
```

## ■ 範囲演算子で総和を求める

```
(n..m).sum                      → 範囲オブジェクトに sum を使うと一発で合計が出る
(n..m)                          → n 以上 m 以下の整数の範囲
```

### while ループで総和を求める（基本パターン）

```
total = 0
while n <= m
  total += n
  n += 1
end                             → n を1ずつ増やしながら total に足していく
```

### n += 1 のインクリメント

```
n += 1                          → n = n + 1 の省略形
while ループのカウンタを進めるために必須（忘れると無限ループ）
```

### 2つの書き方の比較

```
(n..m).sum                      → Ruby らしい簡潔な書き方
while でループ                  → 他の言語でも共通する基本的な書き方
どちらも結果は同じ
```

## ■ PHP 対応メモ まとめ

| Ruby | PHP |
|------|-----|
| `data[j], data[j+1] = data[j+1], data[j]` | `$tmp = $data[$j]; $data[$j] = $data[$j+1]; $data[$j+1] = $tmp;` |
| `for i in 0..n` | `for ($i = 0; $i <= $n; $i++)` |
| `if data[j] < data[j + 1]` | `if ($data[$j] < $data[$j + 1])` |
| `gsub(/[\s　]/, "")` | `preg_replace('/[\s　]/', '', $text)` |
| `.upcase` | `strtoupper($str)` |
| `(n..m).sum` | `array_sum(range($n, $m))` |
| `while n <= m` + `n += 1` | `while ($n <= $m) { $n++; }` |
