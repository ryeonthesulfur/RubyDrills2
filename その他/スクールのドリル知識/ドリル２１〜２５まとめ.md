## ■ メソッドへの引数の渡し方

```
def multiple(num1, num2)        → 仮引数を2つ受け取るメソッド
multiple(num1, num2)            → 呼び出し時に実引数を渡す
```

### return と puts の使い分け

```
return num                      → 値を返すだけ（出力しない）→ 呼び出し元で puts する
puts "#{num1 * num2}"           → メソッド内で直接出力する
どちらも正解だが return で返す方が汎用性が高い
```

### 複数の入力を受け取る

```
2回 gets を使う                 → 複数の入力を別々の変数に受け取るパターン
```

## ■ rand メソッド

```
rand(10)                        → 0〜9 のランダムな整数を生成（10は含まない）
rand(n)                         → 0 以上 n 未満の整数
```

---

## ■ shuffle メソッド

```
配列.shuffle                    → 配列の要素をランダムに並び替えた新しい配列を返す
["凶","中吉","吉","大吉"].shuffle → 毎回順番が変わる
```

---

## ■ ハッシュのキー：文字列 vs シンボル

```
{"title" => "ハリーポッター"}   → 文字列キー：取り出しは hash["title"]
{title: "ハリーポッター"}       → シンボルキー：取り出しは hash[:title]
※キーの型を間違えると値が取得できないので注意
```

### to_sym メソッド

```
gets.chomp.to_sym               → 文字列入力をシンボルに変換する
                                   シンボルキーのハッシュを入力で操作するときに必要
```

### ハッシュを引数で渡す

```
def movie_info(movie, info)
  puts movie[info]              → ハッシュとキーを引数で受け取って値を取り出す
end
```

## ■ 継承

```
class 子クラス < 親クラス       → 親クラスのプロパティ・メソッドを引き継ぐ
class Student < Person          → Student は Person の initialize と @name / @age を受け継ぐ
子クラスでは親の @変数 にアクセスできる
```

### 継承のメリット

```
共通の処理を親クラスにまとめることで、子クラスに重複して書かなくて済む
Student.new で Person の initialize が動く
```

## ■ 複数文字列の同時チェック

```
str.include?("cat") && str.include?("dog")
                                → AND でつないで「両方含む」を判定
```

---

## ■ メソッド名に ? をつける慣習

```
include_cat_and_dog?(str)       → true/false を返すメソッドには ? をつけるのが Ruby の慣習
```

---

## ■ while true の無限ループ＋exit パターン

```
while true do ... end           → 終了条件が外部入力に依存するときの定番パターン
exit                            → プログラムをその場で終了する
input == 1 で exit              → メニューアプリの終了処理の典型パターン
```

### メニュー選択アプリの基本構造

```ruby
while true do
  選択肢を表示
  input = gets.to_i
  if input == 0 → 処理A
  elsif input == 1 → exit
end
```

## ■ PHP 対応メモ まとめ

| Ruby | PHP |
|------|-----|
| `"#{num1}と#{num2}"` | `"{$num1}と{$num2}"` |
| `rand(10)` | `rand(0, 9)`（最小値と最大値を両方指定） |
| `配列.shuffle` | `shuffle($array)`（破壊的：元の配列を変える） |
| `to_sym` | PHP には不要（キーは最初から文字列） |
| `class Student < Person` | `class Student extends Person` |
| `exit` | `exit()` |
