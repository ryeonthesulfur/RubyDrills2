## ■ 入力値のバリデーション（検証）

```
def power(power)                → 入力値を受け取って検証する専用メソッドを作る
if power > 100                  → 100 超えなら警告を出す
else return power               → 正常値はそのまま返す
punch = power(gets.to_i)        → 入力を検証メソッドに通してから変数に入れる
```

### バリデーションのこつ

```
入力と検証を分離する            → gets.to_i で受け取り → 別メソッドで検証 → 戻り値を使う
不正値のとき nil を返す         → 呼び出し元で nil チェックができる
```

---

## ■ バリデーションを while ループで繰り返す

```
while power > 100
  puts "100以下の数字を入力してください"
  power = gets.to_i
end
return power                    → 正常値になるまで再入力させる（if より while が適切）
```

### こつ：while でバリデーションする理由

```
if だと1回しかチェックできない  → ユーザーが何度でも再入力できるように while を使う
```

## ■ ランク分けパターン

```
total = punch + kick + jump     → 合計を出してから条件分岐
total >= 300 → "A"
total >= 200 → "B"              → 大きい方から順に判定する（小さい方から書くと誤判定）
total >= 100 → "C"
else → "D"
```

### ハッシュ登録時に計算結果を埋め込む

```
{ rank: hero_rank(punch, kick, jump) }
                                → メソッドの戻り値をそのままハッシュの値にできる
```

## ■ クラス変数（@@）

```
@@type = "犬"                   → クラス全体で共有される変数。全インスタンスで同じ値
#{@@type}                       → インスタンスメソッド内からもアクセスできる
クラス変数 vs インスタンス変数  → @@ はクラス全体共有 / @ は各インスタンス固有
```

---

## ■ 「登録 → 一覧 → 詳細」の3層構造

```
register_data   → ハッシュを作って配列に追加
show_data_list  → each_with_index で番号付き一覧 → 番号入力 → 詳細へ
show_data       → 選択されたハッシュの中身を表示
この3つのメソッドが連携するパターンはよく使う
```

### 配列の参照と選択

```
data[input - 1]                 → 1始まりの番号入力を 0始まりのインデックスに変換して取り出す
```

### ハッシュのキー名のつけ方

```
train_name: / length: / passengers:
                                → 複数データをハッシュで管理するとき、キー名は意味が明確なものにする
```

---

## ■ メソッド分離の流れ（4層構造）

```
register_data       → データ登録
confirm_data_list   → 一覧表示 → 番号入力
confirm_data        → 詳細表示 → 追加入力
calculate_xxx       → 計算・出力
複数メソッドが連鎖するパターン → 前のメソッドが次のメソッドを呼ぶ
```

## ■ 燃費計算パターン

```
fuel = distance / train_info[:length]
                                → 走行距離 ÷ km/L で消費ガソリン量を求める
ハッシュから値を取り出して計算  → [:length] で km/L を参照
```

## ■ PHP 対応メモ まとめ

| Ruby | PHP |
|------|-----|
| `&$power_data`（参照渡し） | PHP で配列を関数内で変更するとき必須（ドリル２６〜３０の `&$data` 参照） |
| `power()` が `nil` を返す場合 | `if ($punch === null)` でチェック |
| `while power > 100` | `while ($power > 100)` で同じ構造 |
| `@@type = "犬"` | `private static $type = "犬"` |
| `#{@@type}` | `self::$type` |
| `def self.say` | `public static function say()` |
| `Dog.say` | `Dog::say()`（`::` でクラスメソッドを呼ぶ） |
| `.round(1)` | `round($value, 1)` |
