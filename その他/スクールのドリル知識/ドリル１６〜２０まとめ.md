## ■ 配列の要素カウント

```
配列.count(値)                  → 配列内に指定した値が何個あるか返す
```

---

## ■ 10の倍数への近さを判定するパターン

```
num % 10                        → 10で割った余り = 一の位の値
num % 10 <= 2                   → 10の倍数から2以内の右側（例: 10, 11, 12）
num % 10 >= 8                   → 10の倍数から2以内の左側（例: 18, 19, 20）
両方を || でつなぐ              → 「差が2以内」を表現する
```

### こつ：一の位で考える

```
10の倍数との距離 = 一の位が 0,1,2 か 8,9 かで判定できる
```

---

## ■ 10の倍数との距離を求めるパターン（応用）

```
total % 10                      → 合計値の一の位 = 直近の10の倍数から右に何個ずれているか
num <= 5                        → 右が近い → num がそのまま差
else（num 6〜7）                → 左が近い → 10 - num が差
```

### こつ：「近い方の距離」の考え方

```
% 10 の結果が 0〜9 のどこかに来る
5 より小さければ右（足し算方向）が近い
5 より大きければ左（引き算方向）が近い → 10 - num で距離を出す
```

## ■ 手数料込みの残高チェックパターン

```
balance >= amount + fee         → 引き落とし額 + 手数料が残高以内かチェック
balance - amount - fee          → 残高から引き落とし額と手数料を両方引く
```

## ■ 重複しない要素だけを合計するパターン

```
ネストした each                 → 外側でリストを回し、内側で同じ値の個数を数える
count < 2 なら追加              → 1回しか出てこない数値だけを別配列に集める
sum = 0 → each で加算          → 集めた配列を合計するループ
```

### こつ：重複除外の考え方

```
「同じ値が2個以上あれば除外」= 出現回数が1のものだけ合計する
内側ループで出現回数を数え、2未満なら採用するというロジック
```

## ■ バイナリーサーチ（2分割検索）のアルゴリズム

```
前提: ソート済みの配列に使う
① 左端(left)と右端(right)の中央(center)を求める
② center の値が target と一致 → その位置を返す
③ center の値が target より小さい → 右半分を探す（left = center + 1）
④ center の値が target より大きい → 左半分を探す（right = center - 1）
⑤ left > right になったら見つからない → -1 を返す
```

### 中央インデックスの計算

```
center = (left + right) / 2    → 整数除算で中央位置を求める
```

### 見つからない場合の慣例

```
return -1                       → 「存在しない」を -1 で表すパターン
result == -1 で分岐             → 戻り値で存在チェック
```

## ■ 文字列の複合条件チェック

```
str.include?("xyz") && !str.include?(".xyz")
                                → "xyz" を含む かつ ".xyz" を含まない
! (NOT)                         → 条件を反転させる
```

---

## ■ 絶対値

```
(a - b).abs                     → a と b の差の絶対値（負になっても正に直す）
                                   例: (1 - 3).abs → 2、(3 - 1).abs → 2
```

### 距離の比較パターン

```
x = (a - b).abs                 → a と b の距離
y = (b - c).abs                 → b と c の距離
z = (a - c).abs                 → a と c の距離
それぞれ変数に入れてから条件分岐すると読みやすい
```

## ■ PHP 対応メモ まとめ

| Ruby | PHP |
|------|-----|
| `配列.count(9)` | `count(array_keys($nums, 9))` |
| `balance >= amount + fee` | PHP でも同じ書き方で動く |
| `(left + right) / 2` | `intdiv($left + $right, 2)`（整数除算） |
| `array.length` | `count($array)` |
| `num / 100`（整数除算） | `intdiv($num, 100)` または `(int)($num / 100)` |
| `% 演算子` | PHP でも同じ書き方で動く |
| `str.include?("xyz")` | `str_contains($str, "xyz")` |
| `!str.include?(".xyz")` | `!str_contains($str, ".xyz")` |
| `(a - b).abs` | `abs($a - $b)`（関数として呼ぶ） |
