## ■ 定員チェックと計算メソッドの連続呼び出し

### 定員チェックのパターン

```
if input_passengers < passengers   → まだ乗れる
elsif input_passengers > passengers → 定員オーバー
else                               → ピッタリ
大小と等しい の3パターンを if/elsif/else で網羅する
```

### 計算メソッドを2つ連続して呼ぶパターン

```
confirm_data の中で
  calculate_fuel_consumption を呼ぶ → 燃費計算
  calculate_passengers を呼ぶ       → 定員チェック
1つのメソッドから複数の計算メソッドを順番に呼べる
```

## ■ Time クラス

```
Time.new                        → 現在時刻を取得する
now.year / now.month / now.day  → 年・月・日を数値で取得
now.wday                        → 曜日を数値で取得（0=日, 1=月, ..., 6=土）
```

### 曜日配列パターン

```
week = ["日曜日", "月曜日", ...]
week[now.wday]                  → wday の数値を配列のインデックスとして使う
```

### %w 記法

```
%w[日 月 火 水 木 金 土]        → スペース区切りで文字列配列を作る省略記法
%w は文字列配列専用（数値には使えない）
```

## ■ rand と while 制御パターン（追記）

### メソッドの return で while を制御するパターン

```
def janken ... return true/false end
next_game = janken              → メソッドの戻り値で while を継続するか決める
あいこ → true → while 継続 / 勝ち負け → false → while 終了
```

### じゃんけん勝利条件の書き方

```
(player == 0 && program == 1)   → グーでチョキに勝つ
|| (player == 1 && program == 2) → チョキでパーに勝つ
|| (player == 2 && program == 0) → パーでグーに勝つ
3パターンを || でつなぐ
```

### 配列のインデックスで数値を文字列に変換

```
jankens = ["グー", "チョキ", "パー"]
jankens[player_hand]            → 数値入力を文字列に変換して表示
```

## ■ ハッシュへの動的な代入

```
student = {}                    → 空のハッシュを作ってから
student[:name] = gets.chomp     → キーに直接値を代入していく書き方
ハッシュリテラルで一括定義する書き方と同じ結果になる
```

### 複数キーのハッシュ管理

```
student[:name] / [:age] / [:japanese] / [:math] / [:english]
                                → 1人分のデータを1ハッシュにまとめて管理
```

### 登録 → 一覧 → 詳細の2メソッド構造

```
registration_student → ハッシュ作成 → 配列追加
show_student_name → 一覧表示 → 番号入力 → 詳細表示（1メソッド内で完結）
詳細表示を別メソッドに切り出さず1つにまとめるパターンもある
```

## ■ 合計金額の計算パターン

```
total_price = 0
total_price += cart[:price] * cart[:count]
                                → each の中で各商品の小計を足し込んでいく
```

### empty? メソッド

```
unless cart.empty?              → カートが空でない時だけ [1] を表示する
cart.empty?                     → 配列が空なら true、要素があれば false
```

### return で配列を返して再代入

```
return a_cart
cart = post_item(cart)          → メソッドに配列を渡して中身を追加し、戻り値で受け取る
（参照渡しでも動くが、この書き方は意図が明確）
```

## ■ PHP 対応メモ まとめ

| Ruby | PHP |
|------|-----|
| `Time.new` | `new DateTime()` |
| `now.year` | `$now->format('Y')` または `date('Y')` |
| `now.month` | `$now->format('n')` |
| `now.day` | `$now->format('j')` |
| `now.wday` | `$now->format('w')` または `date('w')` |
| `student = {}` | `$student = []`（PHP に `{}` の空ハッシュはない） |
| `student[:name] = ...` | `$student['name'] = ...` |
| `cart.empty?` | `empty($cart)` |

## ■ Java 対応メモ まとめ

| Ruby | Java |
|------|------|
| `rand(3)` | `new Random(); rand.nextInt(3)` |
| `def janken` | `public static boolean janken()` |
| `students`（配列） | `ArrayList<String>` など |
