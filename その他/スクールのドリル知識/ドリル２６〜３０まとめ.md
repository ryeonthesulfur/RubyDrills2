## ■ case / when 構文

```
case gets.to_i
when 0 → 処理A
when 1 → 処理B
when 2 → exit
else   → 無効な値の処理
end                             → if/elsif の代わりに使える。選択肢が多いときに読みやすい
```

## ■ 平均値の計算パターン

```
total = 0
配列.each { |book| total += book[:price] }
average = total / 配列.length   → 合計 ÷ 個数 で平均を出す
.round                          → 四捨五入（小数を整数に丸める）
```

### round メソッド

```
数値.round                      → 四捨五入して整数を返す
数値.round(n)                   → 小数点 n 桁まで四捨五入
```

### 別メソッドへの切り出し

```
def average_price(books)        → 平均計算を専用メソッドに切り出してスッキリさせる
show_books の中から呼ぶ         → average_price(books) で呼び出して使う
```

## ■ 閏年の判定ロジック（重要）

```
① year % 4 == 0                → 4で割り切れる → 閏年の可能性あり
② year % 100 == 0 && year % 400 != 0
                                → 100で割り切れて400で割り切れない → 閏年ではない（例: 1900年）
③ 上記以外で4の倍数            → 閏年（例: 2000年、2024年）
```

### 覚え方

```
「4の倍数 → 閏年。ただし100の倍数は除く。ただし400の倍数は含む」
```

### 月ごとの日数配列

```
month_days = [31, 28, 31, 30, 31, 30, 31, 31, 30, 31, 30, 31]
month_days[month - 1]           → 月は1始まりなので -1 してインデックスに変換
```

### 条件の入れ子構造

```
month == 2 の場合のみ閏年判定  → 2月以外は配列から直接取得
if の中に if を入れる           → 複雑な条件を段階的に絞り込む書き方
```

## ■ アプリのデータ管理パターン（追記）

### ハッシュで1人分のデータをまとめる

```
info = { name: name, age: age, height: height, weight: weight }
data << info                    → 配列に追加して複数人分を管理
```

### 一覧表示 → 詳細表示の流れ

```
each_with_index で番号付き一覧を表示
gets.to_i で番号を入力
data[入力 - 1] で対応するハッシュを取り出す
別メソッド（show_data）に渡して詳細を表示
```

## ■ BMI の計算パターン

```
tall_m = tall / 100.0           → cm を m に変換（100.0 で割ると小数になる）
bmi = weight / tall_m / tall_m  → 体重 ÷ 身長(m) ÷ 身長(m)
```

### ハッシュ登録時に計算を埋め込む

```
info = { bmi: calculate_bmi(tall, weight) }
                                → 別メソッドの戻り値をそのままハッシュの値に入れられる
```

### 処理の分離パターン

```
register_data → calculate_bmi → show_data_list → show_data
                                → 各処理をメソッドに切り出して呼び合う構造
```

## ■ PHP 対応メモ まとめ

| Ruby | PHP |
|------|-----|
| `case / when` | `switch / case / break` |
| `data << book` | `$data[] = $book` |
| `&$data`（参照渡し） | 配列を関数内で変更するときに `&` が必要 |
| `.round` | `round($value)` |
| `gets.chomp.to_f` | `(float)trim(fgets(STDIN))` |
| `tall / 100.0` | `$tall / 100`（PHP は自動で小数になる） |
