# ドリル１１〜１５ Rubyの知識・メソッド・こつ まとめ

## ■ 配列の検索

```
配列.include?(値)               → 配列に値が含まれるか（true/false）
[1,2,3].all? { |n| 配列.include?(n) }
                                → 全て含まれるかを一行でチェックする別解
```

### all? メソッド

```
配列.all? { |n| 条件 }         → 全要素が条件を満たすとき true を返す
```

---

## ■ 桁の取り出し

```
(num / 10) % 10                 → 十の位を取り出す
num % 10                        → 一の位を取り出す
```

## ■ 複数の戻り値（多値返却）

```
return tens_place, ones_place   → Ruby はカンマ区切りで複数の値を返せる

```

## ■ 文字列・配列の切り出し

```
str.slice(-2, 2)                → 末尾から2文字目を起点に2文字取り出す
                                   負のインデックス = 末尾からの位置（-1 が最後の文字）
str.slice(-3..-1)               → 末尾から3文字目〜末尾を取り出す（負のインデックス範囲指定）
str.slice(-n..-1)               → 末尾 n 文字を取り出すパターン
slice と slice! の違い          → slice は元のデータを変えない / slice! は元を変える（破壊的）
```

### 文字列のインデックス指定

```
str[0]                          → 先頭の1文字
str[0..1]                       → 先頭から2文字（0番目〜1番目）
str[2..-1]                      → 3文字目から末尾まで（-1 は最後の文字）
str[開始..終了]                 → 範囲指定で部分文字列を取り出す
```

### 先頭2文字を末尾に移動するパターン

```
str[2..-1] + str[0..1]          → 3文字目以降 + 先頭2文字 で入れ替え
```

## ■ 文字列の繰り返し

```
文字列 * 3                      → 文字列を3回繰り返す（例: "lo" * 3 → "lololo"）
```

---

## ■ 文字列の結合

```
str1 + str2                     → 文字列を連結する
```

---

## ■ 文字列の変換・判定

```
str.downcase                    → 全て小文字に変換
str.upcase                      → 全て大文字に変換
str.length                      → 文字列の文字数を返す
str.end_with?("abc")           → 文字列が "abc" で終わるか（true/false）
                                   ※ slice で自前実装するより簡潔でプロ向きな書き方
```

---

## ■ 繰り返し処理

```
(1..max_num).each do |num|      → 1 から max_num までを順に処理する
(開始..終了)                    → 範囲演算子（終了値を含む）
while (num <= 100) do           → 条件が true の間ループ
num = num + 1                   → ループ内でカウンタを手動で増やす
```

---

## ■ 小数点の切り捨て

```
数値.floor                      → 小数点以下を切り捨て（例: 3.9 → 3）
全計算が終わった後に floor      → 途中で切り捨てると誤差が出るので最後にまとめてかける
```

---

## ■ boolean 引数の使い方

```
if is_birthday                  → true/false を引数で受け取りそのまま条件に使う
point = point * 5               → 条件が成立した場合だけ追加計算するパターン
```

## ■ FizzBuzz（定番問題）

```
num % 15 == 0 → "FizzBuzz"
num % 3 == 0  → "Fizz"
num % 5 == 0  → "Buzz"         ← 15 の判定を必ず先に書く（3と5の両方に引っかかるため）
```

### % 演算子（モジュロ）

```
num % 3 == 0                    → 3で割り切れる（余りが0）= 3の倍数
```

## ■ PHP 対応メモ まとめ

| Ruby | PHP |
|------|-----|
| `配列.include?(値)` | `in_array(値, $配列)` |
| `return a, b`（多値返却） | `return [$a, $b]`、受け取りは `[$X, $Y] = 関数()` |
| `intval(trim(fgets(STDIN)))` | PHP での整数入力の受け取り方 |
| `str.slice(-2, 2)` | `substr($str, -2)`（末尾2文字を取得） |
| `文字列 * 3` | `str_repeat($str, 3)` |
| `数値.floor` | `floor($point)`（関数として呼ぶ） |
| `str.downcase` | `strtolower($str)` |
| `str.length` | `strlen($str)` |
| `str.slice(-n..-1)` | `substr($str, -$n)` |
| `str.end_with?("abc")` | `str_ends_with($str, "abc")`（PHP 8.0以降） |
| `str[2..-1]` | `substr($str, 2)` |
| `str[0..1]` | `substr($str, 0, 2)` |
| `str1 + str2` | `$str1 . $str2`（ドットで連結） |
