## ■ case/when の応用（追記）

```
case gets.to_i
when 3 → complete(total_price)
when 4 → return                 → case の中でも return でメソッドを抜けられる
```

### 再帰呼び出しで再入力させるパターン

```
def complete(total_price)
  ...
  else
    complete(total_price)       → 金額不足のとき自分自身を呼び出して再入力させる
end
while ではなく再帰で繰り返す書き方
```

### お釣り計算

```
payment >= total_price          → 先に十分かチェック
payment - total_price           → 支払い金額 - 合計金額 = お釣り
合計はメソッドをまたいで使うので引数で渡す
```

## ■ クラス変数で配列を管理する（発展）

```
@@foods = []                    → クラス変数として配列を持つ
@@foods << food                 → どのメソッドからでも引数なしで追加できる
今まで: register_data(cart)    → 引数で配列を持ち回る
今回: @@foods に直接追加        → 引数不要
```

### クラスメソッドでデータ操作

```
def self.input ... end          → Food.input で呼ぶクラスメソッド
def self.show_all_calory        → Food.show_all_calory で呼ぶ
インスタンスを作る処理もクラスメソッド内に書ける
```

### インスタンスを配列に入れるパターン

```
food = Food.new(name, calory)
@@foods << food                 → ハッシュではなくインスタンスを配列に追加
@@foods.each do |food|
  food.name / food.calory       → attr_reader でゲッターを使って取り出す
```

### カロリー合計の計算

```
all_calory = 0
all_calory += food.calory       → each の中でインスタンスの値を足し込む
```

## ■ 曜日計算のアルゴリズム

```
西暦1年1月1日を起点（月曜＝1日目）
1. 指定年の前年まで全日数を合計
2. 指定月の前月まで全日数を合計
3. 日を足す
4. days % 7 → 配列インデックスで曜日を取得
```

### days % 7 で曜日を出す

```
weeks = ["日", "月", "火", "水", "木", "金", "土"]
weeks[days % 7]                 → 総日数を7で割った余りが曜日インデックスになる
```

### while でカウントダウン

```
year_index = year - 1
while year_index > 0 do
  days += 366 or 365
  year_index -= 1
end                             → 1年ずつ遡って合計日数を積み上げる
```

## ■ 商品データをハッシュで管理

```
item = {}
item[:name] = gets.chomp        → 商品名は文字列なので chomp（to_i ではない）
item[:price] = gets.to_i        → 価格は数値なので to_i
item[:cost_price] = gets.to_i   → 仕入れ値も to_i
```

### 利益計算で使うキー設計

```
:price（販売価格）と :cost_price（仕入れ値）を両方保存しておく
利益 = price - cost_price       → 後で計算できるようにデータを持っておく
```

## ■ 利益・利益率の計算

```
item[:profit] = item[:selling_price] - item[:cost_price]
                                → 販売価格 - 仕入れ値 = 利益
item[:profit_rate] = item[:profit].to_f / item[:cost_price].to_f
                                → 整数同士の割り算は to_f で小数にしてから割る
```

### 合計・平均の計算パターン

```
total_profit = 0
total_profit += item[:profit]   → each の中で足し込む
average_profits = total_profit.to_f / total_sales.to_f
(average_profits * 100).round(2) → % 表示のため 100倍して小数点2桁に丸める
```

### to_f で整数を小数に変換（復習）

```
整数 / 整数 は切り捨てになる    → to_f を付けて小数演算にする
.to_f は割られる側か割る側どちらか1つに付けても OK
```

## ■ PHP 対応メモ まとめ

| Ruby | PHP |
|------|-----|
| 再帰呼び出し | PHP でも同じ書き方で動く |
| `@@foods << food` | `self::$foods[] = $food`（`self::$配列[]` でクラス変数配列に追加） |
| `year % 4 == 0` | `$year % 4 == 0` |
| `weeks[days % 7]` | `$weeks[$days % 7]` |
| `total_profit += item[:profit]` | `$total_profit += $item['profit']` |
