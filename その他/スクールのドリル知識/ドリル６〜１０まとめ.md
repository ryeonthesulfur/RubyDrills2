# ドリル６〜１０ Rubyの知識・メソッド・こつ まとめ

---

## ■ 条件分岐のこつ（追記）

```
条件を書く順番が重要            → 狭い条件（0以下）を先に、広い条件（10以下）を後に書く
```

### 複合条件の書き方

```
talking && (hour < 7 || hour > 20)
                                → boolean 引数をそのまま条件に使える
                                → () で OR の範囲を明示してから && でつなぐ
```

---

## ■ 論理演算子

```
&&                              → AND：両方が true のとき true
||                              → OR：どちらか一方が true のとき true
!a                              → NOT：true なら false、false なら true
(a && b) || (!a && !b)          → 「両方 true」または「両方 false」のパターン（一致判定）
```

### 短絡評価

```
短絡評価                        → 左辺で結果が確定した時点で右辺は評価しない
                                   （&& は左辺が false なら右辺を見ない）
                                   （|| は左辺が true なら右辺を見ない）
```

---

## ■ 入力の受け取り

```
gets.to_i                       → 入力を整数として受け取る
output(gets.to_i)               → 入力を受け取りながらメソッドに直接渡す書き方
```

---

## ■ 入れ子配列の each

```
配列.each do |name, prices|     → 内側の配列を2つの変数に自動で分解して受け取れる
fruit[0] / fruit[1]             → インデックスで要素を取り出す方法（別解）
sum = 0 をループの外に          → 各要素ごとに合計をリセットするために外側ループの中で初期化
```

---

## ■ 配列の合計

```
prices.sum                      → 配列の全要素を合計する
sum += price                    → ループで1つずつ足していく基本パターン
```

---

## ■ クラスメソッド

```
def self.メソッド名 ... end     → クラスメソッドの定義（インスタンスなしで呼べる）
クラス名.メソッド名             → クラスメソッドの呼び出し方（例: Fruit.fresh）
```

---

## ■ 文字列の削除・破壊的メソッド

```
str.slice!(n - 1)               → n番目（1始まり）の文字を元の文字列から直接削除する
                                   ! がつく「破壊的メソッド」：元のデータ自体を変える
n - 1                           → slice! はインデックス（0始まり）なので -1 して合わせる
```

### 破壊的メソッド（!）

```
メソッド名!                     → 元のデータ自体を変更する（非破壊版は新しい値を返すだけ）
slice! / gsub! など             → ! なしは元のデータを変えず、! ありは直接変更する
```

---

## ■ 文字列の検索・カウント

```
str.scan("hi")                  → 文字列内の "hi" を全て探して配列で返す
str.scan("hi").length           → 見つかった数を取得（配列の要素数）
str.index("code")               → "code" が最初に出現する位置を 0 始まりで返す
                                   見つからない場合は nil を返す
```

### nil チェックのパターン

```
if pos                          → pos が nil でなければ実行（nil は false 扱い）
pos + 1                         → index は 0 始まりなので +1 で「何文字目」に変換
nil + 1                         → エラーになるので nil チェックは必須
```

---

## ■ 偶数判定・カウントのパターン

```
数値.even?                      → 偶数なら true、奇数なら false を返す
数値 % 2 == 0                   → even? と同じ意味

count = 0
配列.each do |n|
  count += 1 if n.even?
end                             → 条件を満たす要素の数を数える基本パターン
```

## ■ PHP 対応メモ まとめ

| Ruby | PHP |
|------|-----|
| `elsif` | `else if`（または `elseif`） |
| `配列.sum` | `array_sum($配列)` |
| `fgets(STDIN)` | PHP での標準入力の受け取り方 |
| `def self.fresh` | `public static function fresh()` |
| `クラス名.メソッド名` | `クラス名::メソッド名()` |
| `@name` | `$this->name` |
| `gets.to_i` | `intval(trim(fgets(STDIN)))` |
| `str.slice!(n - 1)` | `substr_replace($str, '', $n - 1, 1)` |
| `str.scan("hi").length` | `substr_count($str, "hi")` |
| `str.index("code")` | `strpos($str, "code")`（見つからなければ `false`） |
| `if pos` | `if ($pos !== false)`（`=== false` で厳密比較） |
| `数値.even?` | `$n % 2 == 0` |
| `true / false / && / \|\|` | PHP でも全く同じ書き方で動く |
