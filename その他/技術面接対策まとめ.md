## 1. 繰り返し文の種類

Rubyの繰り返し文には主に4種類ある。

| 構文 | 使いどころ |
|---|---|
| `while` | 条件が真の間ループ。回数が決まってないとき |
| `for` | 範囲や配列を順番に処理するとき |
| `times` | 決まった回数だけ繰り返すとき |
| `each` | 配列・ハッシュの要素を1つずつ処理するとき |

```ruby
# while
i = 0
while i < 3
  puts i
  i += 1
end

# for
for i in 1..3
  puts i
end

# times
3.times do |i|
  puts i
end

# each
[1, 2, 3].each do |n|
  puts n
end
```

> 実務では `each` や `times` がよく使われる。配列を扱うときは `each` が基本。

## 4. クラス・インスタンス関連

### クラスとインスタンスの違い

- **クラス**：設計図
- **インスタンス**：設計図から作った実体（`.new` で生成する）

```ruby
class Dog
  def initialize(name)
    @name = name
  end
end

pochi = Dog.new("ポチ")  # インスタンス
koro  = Dog.new("コロ")  # 別のインスタンス
```

変数（例: `pochi`）にはインスタンスへの**参照（住所）**が入っている。

---

### initialize とは

`.new` を呼んだ瞬間に**自動で実行される初期化メソッド**。  
コンストラクタとも呼ばれる。

```ruby
def initialize(name)
  @name = name  # インスタンス生成と同時に初期値をセット
end
```

---

### インスタンスメソッドとクラスメソッドの違い

```ruby
def greet        # インスタンスメソッド：インスタンスから呼ぶ
def self.greet   # クラスメソッド：クラスから直接呼ぶ
```

---

### attr_reader / attr_writer / attr_accessor の違い

インスタンス変数（`@name`）は外から直接触れない。  
だからゲッター・セッターを使う。

```ruby
attr_reader :name    # 読み取りだけ（外から値を見られる）
attr_writer :name    # 書き込みだけ（外から値を変えられる）
attr_accessor :name  # 両方（読み取りも書き込みもできる）
```

| 書き方 | 読む | 書く |
|---|---|---|
| `attr_reader` | ○ | ✗ |
| `attr_writer` | ✗ | ○ |
| `attr_accessor` | ○ | ○ |

> 一言で言うと：reader = 見るだけ、writer = 変えるだけ、accessor = 両方

---

### クラス変数（`@@`）とは

**「そのクラスから作った全インスタンスで共有される変数」**

```ruby
class Dog
  @@count = 0        # クラス変数：全員で共有

  def initialize(name)
    @name = name     # インスタンス変数：そのインスタンスだけのもの
    @@count += 1
  end

  def self.count
    @@count
  end
end

pochi = Dog.new("ポチ")
koro  = Dog.new("コロ")

Dog.count  #=> 2
```

| 変数 | 誰のもの？ |
|---|---|
| `@name` | そのインスタンスだけのもの |
| `@@count` | クラスから作った全インスタンスで共有 |

## 5. よく聞かれる用語

### カプセル化

**「データと操作をクラスの中に閉じ込めて、外から直接触れないようにすること」**

```ruby
class BankAccount
  def initialize(balance)
    @balance = balance  # 外から直接触れない
  end

  def deposit(amount)   # 窓口を通してしか操作できない
    @balance += amount
  end

  def show
    puts "残高: #{@balance}円"
  end
end

account = BankAccount.new(1000)
account.deposit(500)  # ○ メソッド経由でOK
account.@balance      # ✗ 直接触れない
```

> なぜやるか：外から直接 `@balance` を書き換えられると、残高がマイナスになるなど意図しない操作ができてしまうから。

---

### コンストラクタ

`initialize` のこと。インスタンス生成時に自動で動くメソッド。  
Java / PHP での呼び方で、Rubyでは `initialize` という名前で固定されている。

---

### nil とは

値がない状態。`false` と違って「存在しない」を表す。

```ruby
array = [1, 2, 3]
array[10]  #=> nil（存在しないインデックス）
```

---

### 破壊的メソッド

元のデータ自体を変えるメソッド。`!` がつくことが多い。

```ruby
str = "hello"
str.upcase   #=> "HELLO"（strは変わらない）
str.upcase!  #=> "HELLO"（str自体が"HELLO"になる）
```

## 6. 配列とハッシュの違い

```ruby
array = [1, 2, 3]          # 配列：順番で管理
hash  = { name: "阿部" }   # ハッシュ：キーと値のセットで管理
```

| | 配列 | ハッシュ |
|---|---|---|
| 管理方法 | 番号（順番）で管理 | 名前（キー）で管理 |
| 取り出し方 | `array[0]` | `hash[:name]` |
| 向いてるもの | 順番のあるリスト | 属性情報（名前・年齢など） |

---

## 7. シンボルとは

`:name` のような `:` で始まる識別子。ハッシュのキーによく使われる。

```ruby
person = { name: "阿部" }
person[:name]  #=> "阿部"
```

| | シンボル | 文字列 |
|---|---|---|
| 書き方 | `:name` | `"name"` |
| 変更 | できない | できる |
| 用途 | ハッシュのキー、識別子 | テキストデータ |

> 「シンボルは `:` で始まる識別子で、文字列と違い変更できません。ハッシュのキーによく使われます」
