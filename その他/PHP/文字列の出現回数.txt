件名：PHPで特定の文字列の出現回数を数える方法（count_hi関数の解説）

こんにちは！

ご指定いただいた `count_hi` 関数のPHP版コードについて、分かりやすく丁寧に解説します。

## 元のコード

```php
function count_hi($str) {
    // substr_count()は、文字列内に指定した部分文字列が何回出現するかを数えます。
    // これがRubyの scan(...).length に最も近い関数です。
    $count = substr_count($str, "hi");
    echo $count . "\n";
}

// 呼び出し例
count_hi('abc hi ho'); // -> 1
count_hi('ABChi hi');  // -> 2
count_hi('hihi');      // -> 2
```

## このコードがやっていること

この `count_hi` 関数は、与えられた文字列（`$str`）の中に、 "hi" という文字列が何回出現するかを数えて、その回数を出力するものです。

## 重要なポイント：RubyとPHPのアプローチの違い

この処理は、RubyとPHPでアプローチが少し異なります。

*   **Ruby の場合 (`scan().length`)**
    1.  `scan("hi")` で、まず文字列に一致する部分をすべて探し出し、それらを要素とする**配列**を作成します。（例: `["hi", "hi"]`）
    2.  `.length` で、その配列の要素数を数えることで、出現回数を取得します。
    これは「①見つけてリストアップ → ②そのリストの長さを数える」という2段階の処理です。

*   **PHP の場合 (`substr_count()`)**
    1.  `substr_count()` は、「文字列の出現回数を数える」という目的のためだけに作られた**専門の関数**です。
    2.  この関数一つで、文字列の検索とカウントを同時に行い、結果の数値だけを返します。
    途中で配列を作ったりはせず、より直接的に目的を達成します。

## `substr_count()` 関数の徹底解説

この処理の心臓部が `substr_count()` 関数です。

**書式:**
`substr_count(検索対象の文字列, 検索する文字列);`

今回のコード `substr_count($str, "hi");` を見てみましょう。

1.  **第1引数: `$str`**
    *   検索対象となる、元の文字列です。英語では "haystack"（干し草の山）と呼ばれたりします。

2.  **第2引数: `"hi"`**
    *   検索したい部分文字列です。英語では "needle"（針）と呼ばれます。「干し草の山から針を探す」という比喩ですね。

この関数は、`$str` の中から `"hi"` を探し、見つかった回数を数値として直接返してくれます。

## まとめ

*   PHPで文字列の出現回数を数えるには、専用の `substr_count()` 関数を使うのが最もシンプルで効率的です。
*   Rubyの `scan().length` と同じ結果を得られますが、PHPの方がより直接的なアプローチを取ります。

この解説で、コードの動きがより明確になれば幸いです。
