## 入力・型変換

### [`trim(fgets(STDIN))`](「trim(fgets(STDIN))」.txt)
- PHPでターミナル入力を受け取る決まり文句
- `fgets(STDIN)` でキーボード入力を取得
- `trim()` で前後の空白・改行を除去
- Rubyの `gets.chomp` に相当

### [`intval()`](「intval()」.txt)
- 文字列を整数に変換する関数
- `fgets(STDIN)` と組み合わせて数値入力を安全に扱う
- 小数は切り捨て、数字以外は `0` を返す
- 数値を扱う前の「お清め」として使う

## 文字列操作

### [substr_replace — 文字列の一部を削除する](substr_replaceメソッド.txt)
- `substr_replace(文字列, '', 開始位置, 文字数)` で特定文字を削除
- PHPには Rubyの `slice!` のような破壊的メソッドがない
- 代わりに「新しい文字列を作って返す」アプローチ
- 「N番目」→ `$n - 1` のインデックス調整が重要

### [文字列の出現回数 — substr_count](文字列の出現回数.txt)
- `substr_count($str, "hi")` で "hi" の出現回数を数える
- Rubyの `scan("hi").length` に相当
- PHP は配列を作らず直接カウントするより直接的なアプローチ

### [strpos vs Ruby の index — 比較解説](RubyのindexとPHPのstrposの比較解説.txt)
- 両者とも「文字列が最初に現れる位置（0始まり）」を返す
- **最大の違い**：見つからない時の戻り値
  - Ruby `index` → `nil`
  - PHP `strpos` → `false`
- PHP では `if ($pos !== false)` の厳密比較が必須（`if ($pos)` は NG）
- `var_dump()` で型まで確認できる

### [count_code 関数 — PHP版・Ruby版の解説](PHP版_および_Ruby版_count_code関数の解説.txt)
- "code" が文字列の何文字目にあるかを返す関数
- インデックス（0始まり）を人間向けの数え方（1始まり）に `+1` する処理
- Ruby の `index` と PHP の `strpos` それぞれの実装比較
- PHP での `!== false` 判定の理由を詳しく解説

### [Rubyの slice! — 破壊的メソッド](Rubyのslice!メソッド解説.txt)
- `!` 付きメソッドは「元のデータを直接変更する破壊的メソッド」
- `slice!` は指定位置の文字を取り除き、取り除いた文字を返す
- 非破壊的な `slice`（元データを変えない）との比較

## オブジェクト指向（クラス）

### [コンストラクタ — `__construct`](コンストラクタ.txt)
- Rubyの `initialize` に相当するPHP版コンストラクタ
- `new` でインスタンスを作った瞬間に自動実行される
- `__`（ダブルアンダーバー）から始まる = マジックメソッド
- たい焼きの比喩：`class`=金型、`new`=発注、`__construct`=初期セット

### [private・ゲッター・`$this`](「private,ゲッター,$this」.txt)
- `private` = 外部からの直接アクセスを禁止するバリア
- PHPには `attr_reader` がないため、ゲッターは手書きで作る
- `$this->変数名` = Rubyの `@変数名` に相当
- `$this->メソッド名()` = Rubyの `self.メソッド名` に相当
- RubyとPHPの `private` の使われ方の違い（変数 vs メソッド）

### [クラスメソッド — 静的メソッド `static`](PHPのクラスメソッド解説.txt)
- Rubyの `self.メソッド名` に相当するのが PHP の `static` メソッド
- 定義：`public static function メソッド名()`
- 呼び出し：`クラス名::メソッド名()`（インスタンス不要）
- 静的メソッド内では `$this` は使えない

## Ruby vs PHP 早見表

| やりたいこと | Ruby | PHP |
|:---|:---|:---|
| ターミナル入力 | `gets.chomp` | `trim(fgets(STDIN))` |
| 文字列→整数変換 | `.to_i` | `intval()` |
| 文字位置を探す | `str.index("sub")` → `nil` | `strpos($str, "sub")` → `false` |
| 出現回数を数える | `scan("hi").length` | `substr_count($str, "hi")` |
| 文字を削除する | `str.slice!(n)` | `substr_replace($str, '', $n-1, 1)` |
| コンストラクタ | `def initialize` | `def __construct` |
| インスタンス変数 | `@name` | `$this->name` |
| クラスメソッド呼び出し | `Fruit.fresh` | `Fruit::fresh()` |
