【クラスメソッド vs インスタンスメソッド 詳細解説】

このガイドでは、Rubyのクラスにおける「クラスメソッド」と「インスタンスメソッド」の重要な違いについて、それぞれの役割と正しい使い方を詳しく解説します。

==================================================
1. 登場人物の紹介（クラスとインスタンス）
==================================================

まず、基本となる2つの登場人物を理解しましょう。

- **クラス (Class)**: 設計図です。例えば「`Student`」というクラスは、「学生」という概念の設計図になります。
    「学生は名前（`@name`）を持つ」といった情報を定義します。

- **インスタンス (Instance)**: 設計図から作られた「実体」です。
`student = Student.new` のようにして作られた `student` は、山田さんや鈴木さんのような、具体的な一人の学生を表します。
インスタンスはそれぞれが独立したデータ（名前など）を持つことができます。

==================================================
2. インスタンスメソッド（個人の能力）
==================================================

インスタンスメソッドは、**インスタンス（個々の学生）が使う能力**です。

```ruby
class Student
  # これはインスタンスメソッド
  def set_name(name)
    @name = name
  end

  # これもインスタンスメソッド
  def introduce
    # インスタンス変数 @name を使える
    puts "私の名前は#{@name}です。"
  end
end

# インスタンス（実体）を作る
student = Student.new

# インスタンスの能力を使う（initialize じゃないので、データを入れる際は、このように分けて記述する。）
student.set_name("山田太郎")


student.introduce #=> 私の名前は山田太郎です。
```

### 特徴
- **所属**: インスタンス（個々の実体）に所属します。
- **役割**: そのインスタンスが持つデータ（`@name`のようなインスタンス変数）を操作したり、使ったりします。
            山田さんの`introduce`は山田さんの名前を言い、鈴木さんの`introduce`は鈴木さんの名前を言います。
- **呼び出し方**: `インスタンス.メソッド名` のように、インスタンスから呼び出します。
- **定義方法**: `def メソッド名` のように、普通に定義します。

==================================================
3. クラスメソッド（組織全体の能力）
==================================================

クラスメソッドは、**クラス（組織全体）が使う能力**です。個々の学生ではなく、「学生という概念全体」に関する能力です。

```ruby
class Student
  # これはクラスメソッド
  def self.description
    puts "このクラスは学生の設計図です。"
  end
end

# クラスの能力を使う
Student.description #=> このクラスは学生の設計図です。
```

### 特徴
- **所属**: クラス（設計図）そのものに所属します。
- **役割**: クラス全体に関わる処理を行います。例えば、「今までに何人の学生インスタンスが作られたか」を記録・表示する、などです。
            **個々のインスタンスのデータ（`@name`など）は知りませんし、使えません。**
              
- **呼び出し方**: `クラス名.メソッド名` のように、クラスから直接呼び出します。
- **定義方法**: `def self.メソッド名` のように、`self.` を付けて定義します。



==================================================
4. なぜエラーが起きたのか？
==================================================

ご提示いただいたエラーコードを再確認しましょう。

```ruby
# エラーになるコード
class Student
  # ...
  def self.introduce # クラスメソッドとして定義されている
    puts "私の名前は#{@name}です。" # クラスメソッド内からインスタンス変数を使おうとしている
  end
end

student = Student.new
student.introduce # インスタンスからクラスメソッドを呼び出そうとしている
```

エラーの原因は、ご指摘の通り、以下の3つの矛盾点です。

1.  **定義の矛盾**: `self.introduce`は「クラス全体」の能力として定義されています。
                    しかし、その中で「個人の名前（`@name`）」を使おうとしています。クラス全体には特定の個人の名前はないため、`@name`は`nil`（空っぽ）になってしまいます。

2.  **呼び出しの矛盾**: `student.introduce`は、「個人の能力」として`introduce`を呼び出そうとしています。
                        しかし、`self.introduce`は「クラス全体の能力」なので、個人の`student`は「そんな能力は知らない」となります。
                        これが`NoMethodError`（メソッドが見つからないエラー）の直接的な原因です。

3.  **役割の矛盾**: 「自己紹介（introduce）」は、山田さんや鈴木さんといった「個人（インスタンス）」が行うべき行動です。
                    「学生という概念全体（クラス）」が自己紹介するのは不自然ですよね。

### 正しいコード

「自己紹介」は個人の能力なので、`self.`を外してインスタンスメソッドとして定義するのが正しい姿です。

```ruby
class Student
  def introduce
    puts "私の名前は#{@name}です。"
  end
end
```

この修正により、`student.introduce`という呼び出しで、その`student`が持つ`@name`を使って正しく自己紹介できるようになります。
