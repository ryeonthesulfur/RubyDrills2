【クラスメソッド vs インスタンスメソッド 詳細解説 (Ruby & PHP)】

このガイドでは、RubyとPHPのクラスにおける「クラスメソッド」と「インスタンスメソッド」の重要な違いについて、それぞれの役割と正しい使い方を詳しく解説します。

==================================================
1. 登場人物の紹介（クラスとインスタンス）
==================================================

まず、基本となる2つの登場人物を理解しましょう。これはRubyもPHPも共通の考え方です。

- **クラス (Class)**: 設計図です。例えば「`Student`」というクラスは、「学生」という概念の設計図になります。
                      「学生は名前を持つ」といった情報を定義します。

- **インスタンス (Instance)**: 設計図から作られた「実体」です。
                            `student = Student.new` のようにして作られた `student` は、山田さんや鈴木さんのような、具体的な一人の学生を表します。
                            インスタンスはそれぞれが独立したデータ（名前など）を持つことができます。


==================================================
2. インスタンスメソッド（個人の能力）
==================================================

インスタンスメソッドは、**インスタンス（個々の実体）が使う能力**です。

### Ruby版
```ruby
class Student
  # これはインスタンスメソッド
  def set_name(name)
    @name = name
  end

  # これもインスタンスメソッド
  def introduce
    # インスタンス変数 @name を使える
    puts "私の名前は#{@name}です。"
  end
end

# インスタンスの能力を使う
student = Student.new
student.set_name("山田太郎")
student.introduce #=> 私の名前は山田太郎です。
```


### PHP版
```php
class Student {
    private $name;

    public function setName($name) {
        $this->name = $name;
    }

    public function introduce() {
        echo "私の名前は{$this->name}です。\n";
    }
}

$student = new Student();
$student->setName("山田太郎");
$student->introduce(); //-> 私の名前は山田太郎です。
```

### 特徴
- **役割**: そのインスタンスが持つデータ（インスタンス変数）を操作したり、使ったりします。
- **呼び出し方**: `インスタンス.メソッド名` (Ruby) や `$インスタンス->メソッド名` (PHP) のように、インスタンスから呼び出します。




==================================================
3. クラスメソッド（組織全体の能力）
==================================================

クラスメソッドは、**クラス（組織全体）が使う能力**です。個々の実体ではなく、「概念全体」に関する能力です。
PHPでは**静的メソッド (static method)** と呼ばれます。

### Ruby版
```ruby
class Student
  # これはクラスメソッド
  def self.description
    puts "このクラスは学生の設計図です。"
  end
end

# クラスの能力を使う
Student.description #=> このクラスは学生の設計図です。
```



### PHP版
```php
class Student {
    // クラスメソッド（静的メソッド）
    public static function description() {
        echo "このクラスは学生の設計図です。\n";
    }
}

// クラスの能力を使う (:: を使う)
Student::description(); //-> このクラスは学生の設計図です。
```

### 特徴
- **役割**: クラス全体に関わる処理を行います。**個々のインスタンスのデータ（名前など）は知りませんし、使えません。**
- **呼び出し方**: `クラス名.メソッド名` (Ruby) や `クラス名::メソッド名` (PHP) のように、クラスから直接呼び出します。
- **定義方法**: `def self.メソッド名` (Ruby) や `public static function メソッド名` (PHP) のように定義します。




==================================================
4. なぜエラーが起きたのか？
==================================================

ドリルで出てきたエラーは、この役割分担を間違えたために起きました。

```ruby
# エラーになるRubyコード
class Student
  def self.introduce # クラスメソッドとして定義されている
    puts "私の名前は#{@name}です。" # クラスメソッド内からインスタンス変数を使おうとしている
  end
end

student = Student.new
student.introduce # インスタンスからクラスメソッドを呼び出そうとしている
```

エラーの原因は、以下の3つの矛盾点です。

1.  **定義の矛盾**: `self.introduce`は「クラス全体」の能力なのに、中で「個人の名前（`@name`）」を使おうとしています。
                    クラス全体には特定の個人の名前はないため、エラーになります。

2.  **呼び出しの矛盾**: `student.introduce`は「個人の能力」を呼び出そうとしていますが、
                      `self.introduce`は「クラス全体の能力」なので、個人である`student`は「そんな能力は知らない」となります。

3.  **役割の矛盾**: 「自己紹介」は、山田さんや鈴木さんといった「個人（インスタンス）」が行うべき行動です。
                      「学生という概念全体（クラス）」が自己紹介するのは不自然です。


これはPHPでも全く同じです。静的メソッドの中でインスタンスのプロパティ（`$this->name`）を使おうとしたり、
インスタンスから静的メソッドを呼び出そうとすると、同様にエラーや意図しない動作の原因となります。



### 正しいコード

「自己紹介」は個人の能力なので、インスタンスメソッドとして定義するのが正しい姿です。

**Ruby**
```ruby
class Student
  def introduce
    puts "私の名前は#{@name}です。"
  end
end
```

**PHP**
```php
class Student {
    public function introduce() {
        echo "私の名前は{$this->name}です。\n";
    }
}
```

この修正により、インスタンスが持つ名前を使って正しく自己紹介できるようになります。
