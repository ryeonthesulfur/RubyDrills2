【解説】PHPのクラスメソッド（静的メソッド）

Rubyのクラスメソッドに相当するものを、PHPでは「静的メソッド（static method）」と呼びます。
インスタンスを生成しなくても、クラスから直接呼び出せるメソッドのことです。

Rubyの `self.fresh` をPHPで再現したコードを見てみましょう。

```php
<?php

class Fruit {
    // インスタンスメソッド（コンストラクタ）
    public function __construct(private string $name, private int $price) {
    }

    // ★★★ 静的メソッド（クラスメソッド） ★★★
    // `static`キーワードをつけることで定義します。
    public static function fresh() {
        // 静的メソッドの中では、インスタンス変数($this->nameなど)は使えません。
        // なぜなら、どのインスタンスにも属していないからです。
        echo "採れたて新鮮な果実です。\n";
    }

    // インスタンスメソッド
    public function introduce() {
        // こちらはインスタンスに属するので、$thisが使えます。
        echo "{$this->name}は{$this->price}円です\n";
    }
}

// --- 実行部分 ---

// 静的メソッドの呼び出し
// インスタンスを作らずに、クラス名::メソッド名() で呼び出す
Fruit::fresh();

// インスタンスの生成と、インスタンスメソッドの呼び出し
$apple = new Fruit("りんご", 120);
$apple->introduce();

```

### ポイント解説

1.  **定義の仕方: `public static function ...`**
    メソッドの前に `static` というキーワードを付けるだけで、そのメソッドは静的メソッドになります。

2.  **呼び出し方: `クラス名::メソッド名()`**
    Rubyの `Fruit.fresh` と同じように、インスタンスを `new` で作らなくても、
    `Fruit::fresh()` のように「クラス名」と「`::`（スコープ解決演算子）」を使って直接呼び出せます。

3.  **インスタンスメソッドとの違い**
    *   **インスタンスメソッド (`introduce`)**:
        *   `$apple` のような**特定のインスタンス**に属し、`$this` を使ってそのインスタンスのプロパティ（名前や値段）にアクセスできます。
    *   **静的メソッド (`fresh`)**:
        *   特定のインスタンスではなく、**クラスそのもの**に属します。
            そのため、インスタンス特有の情報（名前や値段）を必要としない処理に使われ、`$this` を使うことはできません。
