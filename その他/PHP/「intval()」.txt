【解説】PHPの `intval()` 関数について

`intval()` は、渡された値（特に文字列）を「整数（integer）」に変換するための、非常に重要な関数です。


■ 1. 基本的な動き

・数値を表す文字列を、計算に使える整数に変換します。
・小数点以下は、問答無用で切り捨てられます（四捨五入ではありません）。

```php
$num_string = "123";
$integer_val = intval($num_string); // $integer_val の中身は、数値の 123 になる

$float_string = "99.9";
$integer_val2 = intval($float_string); // $integer_val2 の中身は、数値の 99 になる
```

■ 2. 文字列が混ざっている場合の動き

・文字列の**先頭から**数字を読み取り、数字でなくなった時点で処理を終えます。
・文字列が数字で始まっていない場合は、`0` を返します。

```php
intval("5回");      // 5 になる
intval("100円です"); // 100 になる
intval("残り10個"); // 0 になる（先頭が数字ではないため）
```

■ 3. なぜ `fgets(STDIN)` と一緒に使うのか？

ターミナルからの入力 `fgets(STDIN)` は、
たとえユーザーが `10` と入力しても、プログラムの中では文字列の `"10\n"` として扱われます。

`$input = fgets(STDIN);`

このまま `$input > 5` のような比較をすると、PHPが自動で型変換を試みますが、意図しない動きをすることがあります。

そこで `intval()` を使うことで、

`$input = intval(fgets(STDIN));`

と書けば、ユーザーが入力した `"10\n"` という文字列を、確実に**数値の `10`** に変換してから変数 `$input` に代入できます。
これにより、その後の数値比較や計算が安全かつ正確に行えるようになります。

**結論：外部から来るデータ（特にユーザー入力）を数値として扱いたい場合は、`intval()` を使って「お清め」をするのがプログラマーの作法です。**
