# 【解説】PHPの日付・時刻取得（`date()` 関数と `DateTime` クラス）／Rubyの `%w` 記法に相当するもの

※ Rubyとの比較付き

---

## 1. PHPには日付の取得方法が2種類ある

| | 特徴 |
|:---|:---|
| `date()` 関数 | タイムスタンプ（数値）を渡して文字列を作る、ただの関数 |
| `DateTime` クラス | インスタンスを作り、メソッドで値を取り出す。Rubyの `Time.new` に近い |

---

## 2. `date()` 関数

**書き方:** `date(フォーマット文字, タイムスタンプ)`

タイムスタンプ（現在なら `time()` で取得できる数値）を渡し、指定したフォーマットの文字列を返す。

```php
$now = time();  // 現在のタイムスタンプ（数値）ここで計算すれば、現在時刻以外の時刻も出せる。これがないと、基本的に「date() 関数」は現在時刻の取得のみ行う。現在時刻のみなら、このタイムスタンプは不要。

$year  = date('Y', $now);  // 2026
$month = date('n', $now);  // 6
$day   = date('j', $now);  // 20
$wday  = date('w', $now);  // 0〜6（0=日曜）

echo "現在は西暦{$year}年{$month}月{$day}日\n";
```

タイムスタンプを省略すると、自動的に現在時刻が使われる。

```php
echo date('Y');  // time()を省略してもOK
```

---

## 3. `DateTime` クラス

**書き方:** `new DateTime()` → `$obj->format(フォーマット文字)`

Rubyの `Time.new` と同じ感覚で、オブジェクトに対してメソッドを呼ぶ書き方。

```php
$now = new DateTime();

$year  = $now->format('Y');
$month = $now->format('n');
$day   = $now->format('j');
$wday  = $now->format('w');

echo "現在は西暦{$year}年{$month}月{$day}日\n";
```

文字列補完の `{}` の中でメソッド呼び出しも直接書ける。

```php
echo "現在は西暦{$now->format('Y')}年{$now->format('n')}月{$now->format('j')}日\n";
```

---

## 4. RubyとPHPの対応関係

| やりたいこと | Ruby | PHP（`date()`） | PHP（`DateTime`） |
|:---|:---|:---|:---|
| 現在時刻を取得 | `now = Time.new` | `$now = time();` | `$now = new DateTime();` |
| 年 | `now.year` | `date('Y', $now)` | `$now->format('Y')` |
| 月 | `now.month` | `date('n', $now)` | `$now->format('n')` |
| 日 | `now.day` | `date('j', $now)` | `$now->format('j')` |
| 曜日（0〜6） | `now.wday` | `date('w', $now)` | `$now->format('w')` |

**使い分けの目安：**
- 表示するだけなら `date()` で十分（シンプル）
- 日付の計算（◯日後など）やオブジェクトとして持ち運びたいなら `DateTime` が向いている

---

## 5. Rubyの `%w` 記法に相当するPHPの書き方

### Rubyの `%w`

スペース区切りで文字列配列を簡単に作れる記法。

```ruby
week = %w[日 月 火 水 木 金 土]
#=> ["日", "月", "火", "水", "木", "金", "土"]
```

### PHPには `%w` 自体は存在しない

PHPでは通常通り `""` と `,` を使って配列を書く。

```php
$week = ["日", "月", "火", "水", "木", "金", "土"];
```

どうしても「スペース区切りの文字列から配列を作る」という動きを再現したい場合は `explode()` を使う。

```php
$week = explode(' ', '日 月 火 水 木 金 土');
//=> ["日", "月", "火", "水", "木", "金", "土"]
```

`explode(区切り文字, 文字列)` は「文字列を指定した区切り文字で分割して配列にする」関数。Rubyの `%w` ほど短く書ける専用記法はないので、基本は素直に `[]` で配列を書くのがPHPの標準的なやり方。

## 6. 曜日名を表示するところまでつなげる

`date('w')` や `format('w')` は曜日を**数字（0〜6）**で返すだけなので、日本語の曜日名にするには配列と組み合わせる必要がある。

```php
$week = ["日", "月", "火", "水", "木", "金", "土"];
$wday = date('w');        // 今日の曜日を数字で取得（例: 1）

echo $week[$wday] . "曜日です\n";   // $week[1] → "月" → "月曜日です"
```

`DateTime` を使う場合も同じ流れ。

```php
$now  = new DateTime();
$week = ["日", "月", "火", "水", "木", "金", "土"];

echo $week[$now->format('w')] . "曜日です\n";
```

**流れの整理：**
1. `date('w')` / `$now->format('w')` で曜日を**数字**として取得
2. その数字を `$week[]` の**添字**として使い、曜日**名**を取り出す

---

## 7. 見分け方のまとめ

似た見た目だが役割が違う3つ。

| 名前 | 種類 | 呼び方 | 役割 |
|:---|:---|:---|:---|
| `date('Y')` | 関数 | `date(...)` （`->` なし） | タイムスタンプを文字列に変換する |
| `DateTime` | クラス | `new DateTime()` | 日付・時刻のインスタンスを作る |
| `format('Y')` | メソッド | `$now->format(...)` （`->` あり） | `DateTime` インスタンスから値を取り出す |

`->` がついているかどうかで「関数」か「メソッド」かを見分けられる。`DateTime` はクラスなので `new` を伴って初めて使える。

---

## 8. まとめ

- PHPの日付取得は **`date()` 関数**（シンプル）と **`DateTime` クラス**（オブジェクト指向、Rubyの `Time.new` に近い）の2系統がある
- Rubyの `%w` のような専用の配列リテラル記法はPHPにはなく、`[]` で書くか `explode()` で代用する
- 曜日を**数字**で取得 → 配列の**添字**として使って曜日**名**に変換、という2段階の処理が必要
