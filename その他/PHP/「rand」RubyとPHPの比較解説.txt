【解説】乱数生成：RubyのrandとPHPのrandの比較

---

## 基本的な役割は同じ

どちらも「ランダムな数値（乱数）を生成する」関数です。
ただし、書き方と動作に重要な違いがあります。

---

## Ruby の `rand`

**書き方:** `rand(n)`

- 引数に整数 `n` を渡すと、`0` 以上 `n` 未満の整数をランダムに返します。
- 引数なしで呼ぶと、`0.0` 以上 `1.0` 未満の小数を返します。

```ruby
rand(10)   #=> 0〜9 のどれかの整数
rand(6)    #=> 0〜5 のどれかの整数（サイコロなら +1 する）
rand       #=> 0.0〜1.0 未満の小数（例: 0.5423...）
```

---

## PHP の `rand`

**書き方:** `rand($min, $max)`

- 引数に「最小値」と「最大値」を渡すと、その範囲内（両端含む）の整数をランダムに返します。
- 引数なしで呼ぶと、非常に大きなランダムな整数を返します。

```php
rand(0, 9);   //-> 0〜9 のどれかの整数
rand(1, 6);   //-> 1〜6 のどれかの整数（そのままサイコロとして使える）
rand(0, 10);  //-> 0〜10 のどれかの整数
```

---

## 最大の違い：範囲の指定方法

| 項目 | Ruby | PHP |
|:---|:---|:---|
| **書き方** | `rand(n)` | `rand($min, $max)` |
| **範囲** | `0` 以上 `n` **未満** | `$min` 以上 `$max` **以下**（両端含む）|
| **1〜10を出したい時** | `rand(10) + 1` | `rand(1, 10)` |
| **0〜9を出したい時** | `rand(10)` | `rand(0, 9)` |

---

## 具体例で比較

### 「1〜6のサイコロ」を作る場合

```ruby
# Ruby
dice = rand(6) + 1   # rand(6) は 0〜5 なので +1 する
puts dice            #=> 1〜6
```

```php
// PHP
$dice = rand(1, 6);  // 最小値と最大値をそのまま指定できる
echo $dice . "\n";   //-> 1〜6
```

### 「0〜9のランダムな数」を作る場合

```ruby
# Ruby
num = rand(10)   # 0〜9
puts num
```

```php
// PHP
$num = rand(0, 9);  // 0〜9
echo $num . "\n";
```

---

## まとめ

- Ruby は「上限（含まない）」だけ指定する → 下限は常に0
- PHP は「下限」と「上限（含む）」の両方を指定する → より直感的に範囲を指定できる
