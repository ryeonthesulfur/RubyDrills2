【PHPのstrtolower関数とは？】

`strtolower()` は、PHPに標準で組み込まれている関数の一つで、
引数に指定した文字列に含まれるアルファベットを**すべて小文字に変換**して返します。

Rubyの `.downcase` メソッドと全く同じ役割を果たします。

==================================================
使い方
==================================================

```php
$string = "Hello WORLD";
$lower_string = strtolower($string);

echo $lower_string; // "hello world" と出力される
```

==================================================
なぜ使うのか？（end_otherメソッドでの例）
==================================================

`end_other`メソッドには、「大文字でも小文字でも、同一の文字として処理を行う」というルールがありました。

例えば、`'AbC'` と `'HiaBc'` という2つの文字列を比較する場合、
そのままでは別の文字列として扱われてしまいます。

そこで、比較を行う前に `strtolower()` を使って両方の文字列を `'abc'` と `'hiabc'` というように、
すべて小文字に変換します。これにより、大文字・小文字の違いを無視して、意図通りに文字列を比較できるようになります。

このように、ユーザーの入力が大文字か小文字かわからない場合や、
大文字・小文字を区別せずに処理したい場合に非常に役立つ関数です。

==================================================
【PHPのstrlen関数とは？】
==================================================

`strlen()` は、PHPに標準で組み込まれている関数の一つで、
引数に指定した文字列の**長さ（文字数）**を整数で返します。

Rubyの `.length` や `.size` メソッドと全く同じ役割を果たします。

==================================================
使い方
==================================================

```php
$string = "Hello";
$length = strlen($string);

echo $length; // 5 と出力される
```

==================================================
なぜ使うのか？（end_otherメソッドでの例）
==================================================

あなたが`slice`版の`end_other`メソッドを実装した際、`b_length = b_down.length` のように、
比較対象の文字列の長さを取得する必要がありました。

PHPで同じロジックを組み立てる際に、この「文字列の長さを取得する」役割を果たすのが `strlen()` です。

`substr()` で末尾から何文字切り出すかを決めるために、`strlen()` で相手の長さを正確に知る必要があった、というわけです。

==================================================
【PHPのstr_ends_with関数とは？】
==================================================

`str_ends_with()` は、PHP 8.0から導入された比較的新しい関数で、ある文字列が、指定した別の文字列で終わっているかどうかをチェックします。

Rubyの `.end_with?` メソッドと全く同じ役割を果たします。

==================================================
使い方
==================================================

```php
$string = "Hello World";

var_dump(str_ends_with($string, "World")); // bool(true) と出力される
var_dump(str_ends_with($string, "Hello")); // bool(false) と出力される
```

==================================================
なぜ使うのか？（end_otherメソッドでの例）
==================================================

あなたが`slice`版のロジックを組み立てた後、よりシンプルでプロフェッショナルな書き方として紹介されたのがこの`str_ends_with()`です。

`substr()`と`strlen()`を組み合わせて「文字列の末尾を切り出して比較する」という複雑なロジックを、`str_ends_with()`を使えば「〜で終わるか？」という一言で、直感的かつ安全に表現できます。

このように、特定の目的のために用意された関数を使うことで、コードはより読みやすく、間違いにくくなります。
