# 【徹底比較】Rubyの式展開 vs PHPの変数展開

Rubyの `#{...}` とPHPの `echo "..."`。どちらも文字列の中に変数の値を埋め込む機能ですが、その能力には大きな違いがあります。

なぜPHPでは `echo "{$index + 1}"` のような書き方ができず、Rubyでは `puts "#{index + 1}"` が許されるのでしょうか？
この違いを、両言語の設計思想と共に深く解説します。

---

### 結論：展開できるものが違う

| 言語 | Ruby | PHP |
| :--- | :--- | :--- |
| **できること** | **式**の展開 | **変数**の展開 |
| **記法** | `#{...}` | `$var` or `{$var}` |

- **Ruby**: `#{...}` の中には、**ほぼ全てのRubyコード（式）**を書けます。
- **PHP**: `""` の中には、**単純な変数**しか書けません。計算式などは書けません。

### 1. Ruby: 自由自在な「式展開」

Rubyの `#{...}` は「式展開（Expression Interpolation）」と呼ばれます。その名の通り、`{}` の中には変数だけでなく、計算式やメソッド呼び出しなど、**値を持つ任意のRubyの式**を自由に書くことができます。

```ruby
index = 0
book = { title: "Ruby入門" }

# 変数、式、メソッド呼び出し、何でもOK！
puts "#{index + 1}冊目: 『#{book[:title].upcase}』は素晴らしい本です。"
#=> 1冊目: 『RUBY入門』は素晴らしい本です。
```

これは非常に強力で、プログラマーが考えた通りに直感的にコードを書けるようにするという、Rubyの設計思想の表れです。

### 2. PHP: ルールがある「変数展開」

一方、PHPのダブルクォート文字列 `""` の機能は「変数展開（Variable Parsing）」と呼ばれます。これはあくまで**変数の値を文字列に埋め込む**ための機能です。

#### 基本ルール

```php
$name = "ゆき";
echo "こんにちは、 $name さん"; //-> こんにちは、 ゆき さん
```

#### 複雑な変数の場合

配列の要素やオブジェクトのプロパティなど、少し複雑な変数を展開したい場合は `{}` で囲む必要があります。

```php
$book = ['title' => 'PHP入門'];
echo "本のタイトルは {$book['title']} です。"; //-> 本のタイトルは PHP入門 です。
```

#### 【最重要】PHPの `{}` には「式」は書けない

ここがRubyとの決定的な違いです。PHPの `{$...}` は、あくまで「ここまでが変数名ですよ」とコンパイラに教えるための区切り記号であり、**中に計算式を書くことはできません。**

```php
$index = 0;

// NG: { } の中に + 1 という式は書けない
// echo "{$index + 1}冊目"; //-> Parse error (構文エラー)
```

### 3. では、PHPではどう書くのか？

式の結果を文字列に含めたい場合、PHPでは一度文字列の外に出して、**文字列連結演算子 `.`** を使って結合するのが最も一般的で確実な方法です。

```php
$index = 0;
$book = ['title' => 'PHP入門'];

// OK: 式を文字列の外で計算し、結果を `.` で連結する
echo ($index + 1) . "冊目: " . $book['title'] . "\n";
//-> 1冊目: PHP入門
```

`($index + 1)` という計算を先に実行し、その結果（この場合は数値の `1`）を前後の文字列と連結しています。

### まとめ

| 項目 | Ruby (`"#{...}"`) | PHP (`"..."`) |
| :--- | :--- | :--- |
| **名称** | 式展開 | 変数展開 |
| **展開できるもの** | **任意の式** (計算、メソッド呼び出し等) | **単純な変数** (配列要素、プロパティ等) |
| **`index + 1` のような式** | `puts "#{index + 1}"` (OK) | `echo "{$index + 1}"` (NG) |
| **推奨される書き方** | `puts "#{index + 1}: #{book[:title]}"` | `echo ($index + 1) . ": " . $book['title'];` |

この違いは、言語の成り立ちと設計思想の違いから来ています。Rubyは表現の自由度を重視し、PHPは元々のテンプレート機能から発展してきた歴史的経緯を持っています。それぞれの「文化」を理解すると、よりコードが書きやすくなります。
