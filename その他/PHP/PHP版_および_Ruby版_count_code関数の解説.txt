PHP版 および Ruby版 count_code関数の解説

こんにちは！

`count_code` 関数の実装についてですね。元のコードがうまく動かない理由と、正しい書き方をRubyとPHPそれぞれで解説します。

## 問題の目的

この問題は、「与えられた文字列の中に "code" という単語が、左から何文字目に出てくるか」を調べて出力するものです。

ポイントは「何文字目」という数え方です。
*   人間：「1文字目、2文字目...」と1から数える
*   プログラム：`index`や`strpos`は「0番目、1番目...」と0から数える

この違いを吸収するために、プログラムが見つけた位置（インデックス）に `+1` する必要があります。

## 元のRubyコードの問題点

```ruby
def count_code(str, count)
  str.index(str, [])
end
```

このコードには、いくつか修正すべき点があります。
1.  `def count_code(str, count)`: メソッドが `str` と `count` の2つの引数を取りますが、実際に必要なのは検索対象の文字列 `str` だけです。
2.  `str.index(str, [])`: `index` メソッドの使い方が間違っています。
    *   第1引数には**探したい文字列**（今回は `"code"`）を指定すべきですが、`str`（文字列全体）が指定されています。
    *   第2引数には検索を開始する**位置（数値）**を指定できますが、`[]`（空の配列）が指定されており、エラーの原因になります。

## 正しい実装

### 【Ruby版】

```ruby
def count_code(str)
  # indexメソッドで "code" が最初に出現する位置（0から始まるインデックス）を探します。
  pos = str.index("code")

  # posがnil（見つからなかった）でなければ、という条件分岐です。
  if pos
    # 問題の出力例は「何文字目」という1から始まる数え方なので、+1して出力します。
    puts pos + 1
  end
end

count_code("codexxcode") #=> 1  ("code"は0番目なので 0 + 1)
count_code("aaacodebbb") #=> 4  ("code"は3番目なので 3 + 1)
count_code("cozexxcode") #=> 7  ("code"は6番目なので 6 + 1)
```

### 【PHP版】

PHPでは、Rubyの `index` に相当する `strpos` 関数を使います。

```php
function count_code($str) {
    // strpos()で "code" が最初に出現する位置（0から始まるインデックス）を探します。
    $pos = strpos($str, "code");

    // strpos()は、見つからない場合に false を返します。
    // 0番目に見つかった場合(falseではない)も正しく処理するため、$pos !== false で判定します。
    if ($pos !== false) {
        // 1から始まる数え方にするため +1 して出力します。
        echo ($pos + 1) . "\n";
    }
}

count_code("codexxcode"); //-> 1
count_code("aaacodebbb"); //-> 4
count_code("cozexxcode"); //-> 7
```

### PHPでの注意点 `($pos !== false)`

PHPの `strpos` は、文字列が先頭（0番目）で見つかった場合に `0` を返します。PHPでは `0` は `false` と似たような扱いをされることがあるため、`if ($pos)` のように書いてしまうと、先頭で見つかった場合に条件が満たされず、うまく動きません。

そのため、型まで含めて厳密に「`false`ではない」ことを確認する `!==` を使うのが定石です。

この解説で、コードの動きがより明確になれば幸いです。
