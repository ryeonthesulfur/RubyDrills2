件名：RubyとPHPの文字列操作の比較解説 (slice/substr, */str_repeat)

こんにちは！

Rubyの `slice` や `*` 演算子と、PHPの `substr` や `str_repeat` 関数は、似たような目的で使われますが、書き方や考え方に少し違いがあります。
ドリル12の「末尾の2文字を3回繰り返す」という問題を例に、それぞれの違いを分かりやすく丁寧に解説します。

---

### 1. 文字列の一部を取り出す： `slice` vs `substr`

どちらも文字列から一部分を切り出すための機能です。

#### 【Ruby】 `slice` メソッド
Rubyでは、文字列オブジェクトが持っている `slice` という**メソッド**を使います。

**書き方:** `文字列.slice(開始位置, 取り出す文字数)`

```ruby
str = 'Hello'
# 後ろから2文字目(-2)から、2文字分を取り出す
last_two = str.slice(-2, 2)
puts last_two #=> "lo"
```
*   `slice`は、元の文字列(`str`)にくっつけて`.slice(...)`と書くのが特徴です。
*   負の数を指定すると、文字列の末尾から数えます。

#### 【PHP】 `substr` 関数
PHPでは、`substr` という**組み込み関数**を使います。

**書き方:** `substr(対象の文字列, 開始位置, [取り出す文字数])`

```php
$str = 'Hello';
// 後ろから2文字目(-2)から、最後までを取り出す
$last_two = substr($str, -2);
echo $last_two; //-> "lo"
```
*   `substr`は、関数名が先に来て、引数として対象の文字列(`$str`)を渡します。
*   第3引数（文字数）を省略すると、開始位置から文字列の最後までをすべて取り出します。今回のケースでは、末尾2文字なので結果的に同じになります。

---

### 2. 文字列を繰り返す： `*` vs `str_repeat`

切り出した文字列を複数回繰り返す処理です。

#### 【Ruby】 `*` 演算子
Rubyでは、文字列に対して `*`（アスタリスク）という**演算子**を使うことで、簡単に文字列を繰り返せます。

**書き方:** `文字列 * 回数`

```ruby
puts "lo" * 3 #=> "lololo"
```
*   見た目が算数の掛け算のようで、直感的で分かりやすいのが特徴です。

#### 【PHP】 `str_repeat` 関数
PHPでは、`str_repeat` という**組み込み関数**を使います。

**書き方:** `str_repeat(繰り返したい文字列, 回数)`

```php
echo str_repeat("lo", 3); //-> "lololo"
```
*   "string repeat" (文字列を繰り返す) という名前の通り、その目的専門の関数です。

---

### 補足：Rubyの `times` メソッドと `* 3` の違い

ご質問にあった `times` メソッドとの違いは重要です。

*   `"lo" * 3` **（文字列の繰り返し）**
    *   `"lololo"` という**1つの新しい文字列を生成**します。
    *   `puts "lo" * 3` は、生成された `"lololo"` を1回だけ出力します。

*   `3.times { ... }` **（ループ処理）**
    *   `{}` の中の処理を3回**繰り返します**。
    *   `3.times { puts "lo" }` は、「`puts "lo"` という処理を3回行う」という意味です。結果として、"lo"が3行にわたって出力されます。
        ```
        lo
        lo
        lo
        ```
    *   `'lololo'` という1行の出力を期待する今回のドリルでは、`* 3` を使うのが適切です。

### まとめ表

| 役割 | Ruby | PHP | 種類 |
|:---|:---|:---|:---|
| 末尾2文字を取得 | `str.slice(-2, 2)` | `substr($str, -2)` | メソッド / 関数 |
| 文字列を3回繰り返す | `"lo" * 3` | `str_repeat("lo", 3)` | 演算子 / 関数 |

### 「substr」や「str_repeat」は自分で決める名前？

いいえ、これらはPHPに最初から用意されている**組み込み関数**です。
Rubyの `slice` メソッドや `*` 演算子と同じように、プログラマーが自分で定義しなくても最初から使える便利な道具です。名前はPHPによって決められています。

*   `substr` → "**sub str**ing"（部分文字列）の略
*   `str_repeat` → "**str**ing **repeat**"（文字列の繰り返し）の略

このように、言語ごとに用意されている道具（メソッドや関数）を正しく使い分けることが、プログラミングの第一歩となります。
